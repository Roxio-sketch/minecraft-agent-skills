# 第一人称飞行特效

御剑拖尾原先统一使用实体中心后方 0.85 格作为挂点，与飞剑模型自身长度、显示变换及 visualScale 不一致。现在从当前烘焙模型读取尾端，并应用与实体渲染相同的模型居中、显示旋转、缩放和飞行姿态；固定 tick 历史与插值头部共用该挂点。几何读取结果有容量限制的缓存，不逐帧重新扫描。

境界御空原先直接跳过本地玩家第一人称。现在保留世界空间拖尾，并沿用近相机渐隐；元婴的独立能量头部仍在第一人称隐藏，避免贴脸遮挡。化神及以上仍使用原拖尾形态。

背包 → 设置 → 界面显示：

- 御剑飞行特效：沿用已有剑迹开关，关闭后停止历史采样和绘制。
- 境界御空特效：新增独立保存的客户端开关，默认开启，关闭后停止特效历史更新并释放待绘制缓冲。与特殊御空/原版飞行模式、飞行速度、灵力消耗独立。
