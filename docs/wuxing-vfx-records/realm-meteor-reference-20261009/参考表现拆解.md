# 遁光参考与本次实现

参考来自用户提供的两段本地视频及最新遁光图 `codex-clipboard-6ec331b9-77f5-4334-9642-e05e9ca22b48.png`。已保存视频时间标注的关键帧与联系表，来源、分辨率、时长及取帧时间见 `reference-videos.json`。以下是画面观察，不据参考推断对方的源码、着色器或粒子库。

## 画面中值得采用的表现

《九寸灵台》8–24 秒有飞行者与地面观察者的并排画面。近处能分辨人物和绕身流丝，远处主要看见集中亮点及细长轨迹；20 秒的弯曲轨迹保留了之前的位置。52 秒近景的光效是有缺口的细线和短光雾，没有均匀填满人物周围的实体外壳。

《修仙具象化》约 90 秒的侧面轮廓最接近这次的流星目标：前端集中发白，后方拖长、逐渐散开，头部与尾部具有明显亮度差。140 秒近景可见数条亮丝汇聚在一个前端。需要学习的是汇聚和流动关系；它的独立长丝数量不直接照搬，因为本模组此前已有“几道平行拖尾”的反馈。

## 当前实现的差距

旧版虽然只有一条中心路径，但三层不同宽度分别计算三个固定偏移亮丝，能映射成几条互不汇合的平行光带。围身部分的横向发光位置固定、纵向支撑太长，低速时方向又混入世界竖直方向，产生转弯时不自然的长光柱。

本次保留元婴原来的青色尾迹材质；围身纵向范围缩短，流丝加侵蚀和沿程变化，朝向通过固定 tick 的有限角速度及平行传递来平滑更新。直接反向飞行使用稳定旋转轴，避免归一化插值在 180 度时永远指向旧方向。

化神以上采用单条真实世界路径、单张主尾迹几何。在同一个横向坐标内生成有断续门控的窄亮丝、蓝色或对应境界的外鞘，以及卷流和碎光。最大的截面与亮区放在人物周身，包裹头、躯干与双腿；尾迹不再在身后2格展开成大团，而是从周身光流收窄、减亮，再向远端消散。玩家周身采用弯曲、断续的流丝，身体区域保留空隙；已经删除独立的前置点源。薄流丝延伸至头部外侧，同时保持横截面中心空隙，不产生额外实心光球。围身流丝和 Bloom 均受当前不透明场景深度裁剪。

动作根据用户追加的裁剪参考，改成身体上仰12度、头高脚低的俯身姿态（根pitch78度），双腿直并，手臂略向后掠并向外展开约10度，头部反向补偿使脸朝实际飞行方向。速度方向按固定tick平滑，根矩阵围绕真实模型骨盆0.7040625格旋转，保持身体在流光中。转向相对yaw跨180度时保留连续分支，悬停及退出恢复站姿。攻击和使用物品保留原来的手臂动作。高级尾迹横向轴依次与相邻截面对齐，避免转弯时横向UV突然翻转。飞行控制和服务器权限没有修改。上仰回归精确验证躯干与航向的点积为cos12度、与航向上方法向的点积为sin12度，涵盖水平、斜飞及垂直飞行。

第一轮最新动作实拍发现自身后方第三人称过曝遮住腰腿。最终渲染对自己的尾迹乘0.28、周身场乘0.50，其他飞行者保留完整强度；光带与碎光在镜头0.6～3格内平滑淡出。这只影响观看位置的透明度，原来的长度、宽度、坐标和飞行速度不变。第一人称仍不绘制自身遁光。修改前的截图保存在`reference-native-before-viewfade`和`reference-solas-before-viewfade`；姿态近水平版本保存在三项`reference-*-before-tilt`目录，均不作为最终源码的通过证据。

实拍中的锐利斜向切口来自光带在人物中心以全宽、非零透明度终止。地仙加速时端面半宽约2.635格，大于周身流丝的主要横向半径。最终新旧尾迹靠身1.8格的透明度从零平滑渐入，让周身流丝覆盖过渡，避免端面露出直边。

用户随后指出大团光效仍集中在身后，最终将高级周身最大半径平台放在局部z=-0.6～0.5，亮度包络峰位z=0.08，前后轴支撑缩至-1.45～1.20。外层主流丝、内层独立细丝和前脸流丝分散包裹腿、躯干、脸侧；中心r≤0.24保持零密度。高级尾迹取消身后肩部膨胀，宽度乘0.36、基础透明度从0.95降至0.55，使所有高级档的尾迹最大半宽都小于周身最大半径。五档三相位的独立数学扫描显示最亮截面位于实际身体内、身体长度内密度占65.5%～80.8%；这只验证场定义，实际外观仍用新客户端截图确认。调整前的三项客户端在`reference-*-before-body-wrap`，不作为最终通过证据。

## 境界递进

| 境界 | 轮廓与动态差别 | 常速 / 冲刺尾迹长度上限 |
| --- | --- | --- |
| 元婴 | 保留青色轻光，围身改为短流丝和平滑转向 | 18 / 36 格 |
| 化神 | 蓝白绕身光，两组流线和单个渐细尾迹 | 20 / 38 格 |
| 炼虚 | 紫蓝卷流，增加短的回卷细丝和第三组头部流线 | 24 / 42 格 |
| 合体 | 金色遁光，加入沿尾迹流动的短波纹和前端弧光 | 28 / 48 格 |
| 大乘 | 紫金辉光，额外流线、星芒碎光，更丰富的波纹 | 34 / 54 格 |
| 地仙 | 白色尾核、青金和蓝紫边辉，最长尾迹与最密的短碎光 | 40 / 60 格 |

尾迹来自实际移动历史；表格是长度上限，不会在悬停时凭空拉出整条光带。元婴仍沿用原来的长度参数。粒子数量、显眼程度和轮廓同时变化，不靠单纯换色定义不同境界。

御剑另用剑气材质：白色剑脊、卷纹、破碎蓝色羽缘和少量碎光；固定 tick 的真实移动历史保留弯道。根据实机截图加宽、降低年龄衰减强度并加入抗锯齿，接入只提取剑气的深度约束局部 Bloom；强化状态保留原来的螺旋逻辑。控制、飞行速度、法力消耗和剑模型不在本次特效修改范围内。

御剑实拍联系表是固定0.65格/tick的慢速场景，未达到剑的加速视觉阈值；三档直线名义长度为4、5.2、9.6格。它验证三种状态的主带、后处理、Bloom和固定tick路径正常，不代表高速或惊鸿增强的完整视觉验收。慢速的窄白核与较弱外鞘应按实际截图理解，不能用此联系表声称复刻了遁光参考图。
