# 境界御空：连续流焰设计

本文件是拟议设计，不代表已修改、构建或安装的游戏效果。可交互预览使用原创三维路径的二维投影近似，帮助审视形态与动态；不是 Forge 着色器或游戏截图。游戏源码和已安装 JAR 本轮保持不变。

## 共同轮廓

以玩家为中心建立一股连续流焰。前方是饱满的椭球能量体，包裹头、肩与身体；内部有发光密度，外围没有闭合玻璃外壳、固定亮环或独立点光团。以化神当前合适的白光为前端基准，化神至地仙不增加前端的总发光能量、尺寸和泛光预算。白光淡染当前境界颜色，避免统一泛蓝；不同颜色按相同亮度预算校准。

从鼻端到身体后4格共用基准配方。鼻端最集中，肩部约70%、腰部45%、脚后25%，身体后8格约16%，继续平滑融入长尾。这些百分比是主流焰的设计权重，不等于最终屏幕像素亮度；半透明叠加和 Bloom 需要实机校准。前端不会增加第二个比化神更亮的白核。

原来的短半椭球独立绘制与管形尾根容易产生接缝。拟改为共同包络控制位置、宽度、颜色、密度和发光。前端向后开放，通过8格过渡区进入尾焰，曲线至少一阶连续；材质的细节噪声不能制造整截面的透明缺口。包裹层保留玩家外观可辨识度。

玩家正常身体上仰20°，高速允许稍压低；双臂向外并后掠，转弯内外臂与身体侧倾联动。开始御空且实际身体前倾后周身层渐入；恢复站姿时周身层先退出，已有尾迹按年龄自然消散。头部采用有界旋转、连续航向和最短角度过渡，不能用循环 Euler 值直接乘入归位权重。

## 六境界形态

| 境界 | 轮廓与主要运动 | 尾长普通/加速 |
| --- | --- | --- |
| 元婴 | 保留轻薄细尾。周身短丝向后汇聚，留空较大，没有高阶雾层。 | 18 / 30格 |
| 化神 | 基准流星。一股饱满、连续的主尾，少量短青白流纹从身侧汇入尾焰，主体平稳。 | 28 / 44格 |
| 炼虚 | 内卷。中后段更紧凑，局部流丝在横截面内交错卷入主尾，节段不断合流；不能变成两根全长轨道。 | 32 / 50格 |
| 合体 | 叠浪。主尾内部有较宽的薄能量褶，数个不同速度的流段追赶、合并；外形保持柔软，宽窄变化来自流段。 | 36 / 56格 |
| 大乘 | 回卷残辉。直飞时保留叠浪和疏薄外晕，转弯时外侧流纹舒展、内侧收束，原弯道留下短暂淡雾。 | 40 / 62格 |
| 地仙 | 复合流焰。低频大卷流、中频薄褶、快速细丝和稀疏星芒协同；细节从身后展开，远处仍只有一颗流星和一条主尾。 | 44 / 68格 |

色彩沿用当前六阶色意：青、青蓝、紫蓝、金、紫、青碧。颜色只辅助辨识，去色后至少能看出轻薄、内卷、叠浪、转弯残辉、复合层次的差别。高级的“更多细节”不等同于“全段更亮”。

## 从两段参考视频提取的表现

九寸灵台8～24秒：近处可分辨人物与绕身流动，远处主要是集中的亮点和曲线；20秒旧轨迹保留弯道。修仙具象化115～155秒：多个局部光流汇聚在前端，前端与长尾形成明显层次。吸收汇聚、尺度变化、历史弯道的关系，避免复制多条独立贯穿的亮线。画面观察不能推断参考模组内部算法。

## 实装路线

1. 先做化神标准形。统一前端和前8格密度包络；先关闭泛光检查实体光流的轮廓，再开启受限的泛光。不在整个长尾上做高成本体积步进。
2. 给炼虚和合体独立的局部流动规则，区别在卷入和追赶，不继续仅通过 style 对同一个正弦函数增幅。
3. 大乘和地仙接入历史曲率、弯道外侧与短残辉。残辉依附历史位置，停止后失效；不能在当前朝向画出未来路径。
4. 最后校准色彩、距离LOD和碎光，近处看细节，远处合并成清楚的单股轮廓。

保留现有 RealmMeteorPath 的固定tick采样、平行传递坐标架、瞬移和维度清理；材质使用累计弧长保持流动连续。继续保留真实场景深度裁剪、原生/光影材质一致和完整GL状态恢复，避免第三人称黑屏。局部短流丝共享路径，不建立四条额外尾迹实体。

## 验收边界

先提供化神、炼虚、合体同机位的直飞与转弯视频；确认去色后确有差异，再完善大乘、地仙。验证夜间不过曝、白天可见、F5/恢复动作正常、尾迹无闪断；原生、Oculus关闭光影和开启Solas分别验收。头部强度比较关闭与开启Bloom两种状态，禁止根据检查数量宣称视觉达标。

本轮预览只用于确认设计方向；动画、颜色与光晕均为示意，未证明 Minecraft 的实际效果或性能。
