# 炉底火焰定位与进一步优化

修复左右移动时底火相对炉体滑动：原版走路晃动会在投影中加入位移，旧火焰射线却仍从物理相机起算。现在从炉体局部投影重建虚拟视点、射线和场景深度，统一炉体、火焰与遮挡的坐标。

原版与 Solas V3.7b 各18张真实客户端运动捕获通过，含左右平移、四向、远近、高低与实际按键步行。旧算法实际步行射线偏移最大0.09425格，新算法最大0.000055格；炉子世界锚点误差0，事件矩阵与shader数据来自同一帧。截图及诊断见 motion-native、motion-solas。

## 保留画质的优化

保留完整1280×900分辨率、400次采样位置、九种异火配方及渐变。普通噪声复用重复乘法；燃床两组噪声缓存原始格点哈希，仍执行原插值与密度公式；射线只跳过严格无贡献的八角边缘及炉底遮挡区域，不重新分布采样位置。

| 环境与时钟 | 旧底火GPU绘制 | 新底火GPU绘制 | 九种火焰耗时降幅中位数 |
| --- | ---: | ---: | ---: |
| 原版，用户存档时间339277.95秒 | 20.737ms | 15.364ms | 25.92% |
| Solas，同存档时间 | 20.983ms | 15.691ms | 25.34% |
| 原版，更长时间600000秒 | 20.740ms | 15.342ms | 25.84% |

RTX4060Ti，每种火焰交替测量两版各24次；数值为单次底火绘制，不是整游戏FPS。27组RGBA32F配对全画面比较最大通道差均为0。比较程序使用旧安装版原火焰公式，仅同步修正射线坐标以公平比较性能。

缓存按需创建，每种37.3125MiB，十种全部出现上限约373MiB，退出世界/重载释放；不支持OpenGL4.3时计算原公式。分配/计算GL错误时释放并禁用该缓存至重启，避免每帧重试卡顿。五个相邻整数层容纳老存档浮点取整差异；严格误差保护仍可能在极长时钟下回退原公式，保留画质，最快现有预设约792k秒触发边界。
