# 第一人称御空气流稳定性与御剑隔离

日期：2026-10-14；平台：Forge 1.20.1 / Java 17；协议仍为80。

## 修复

- 原材质将累计时间乘以当前移动速度和冲刺倍率。加速、减速、转向和升降改变速度时，会重新定位整个噪声场，造成跳变。现在在客户端固定游戏刻连续累积流动位置，渲染帧只插值相邻快照。
- 强度、流动速度和冲刺倍率采用短过渡。移动阈值加入迟滞，避免临界速度反复开关。方向仍由当前视角立即决定，没有增加转向滞后。
- 静止后短暂淡出并归零，没有新增浮空光效。关闭设置、退出飞行、换世界、换玩家均清空状态。
- 完全移除御剑第一人称的境界御空气流入口；骑乘时不绘制此材质。御剑视角和第三人称拖尾未改。
- 原来的四周覆盖范围、密度材质、颜色和16顶点单次绘制保持一致。

## 验证

- 完整build通过，新增连续性检查覆盖20000刻反复加减速和冲刺切换，以及移动阈值波动、停止、重置。
- verified-realm-ui/result.json：12张真实客户端截图、2321项检查通过；连续转向、跳跃上升、下降、冲刺、减速期间保持显示、流动相位单调连续。静止不显示，第一人称起飞/退出视角保持一致；无OpenGL错误。
- 首轮realm-ui是未修正测试度量的记录：绕圈返回起点导致直线净位移低于阈值，截图停顿导致跨多个游戏刻的变化超过固定帧上限。最终版改为统计实际路径距离，并按实际经过游戏刻约束相位增量。最终证据使用verified-realm-ui。
- sword-ui/captures.json：6张实机截图检查通过，御剑第一人称的境界御空气流顶点始终0；站剑相机挂点检查通过，无OpenGL错误。
