# 麻痹、肉身与御空体型修复

- 元神出窍现在与移魂寄魄一样生成独立 SoulBodyEntity。肉身留在发动位置，复制装备但不掉落物品；收束沿用原有清除与返回逻辑。
- 境界御空光头、外壳及拖尾以身体中心为缩放轴，按实际实体高度比例缩放。法天象地五倍体型对应五倍特效尺寸。
- 新增 `wuxingxiantu:paralysis` 麻痹状态：服务端固定生效位置并清除速度，客户端禁止方向输入与跳跃。固定位置包含竖直方向，因此空中麻痹会暂时悬停。状态消失后解锁。跨维度重新建立锚点。
- 电弧复用闪电 skill 的 OrbitField / LightningRender：固定 UUID seed，12 道、24段的短电弧沿身体纵轴分布，最多显示16名48格内玩家。采用实际体型缩放。与劫雷共存时共享光影延后合成队列。
- 雷劫由虚空伤害改为原版 `lightningBolt()`，基础伤害表不变，实际结算进入原有护甲、道心雷伤倍率、天雷淬体与万雷领域免疫逻辑。未自动给劫雷增加麻痹。

测试指令（需要作弊/管理员权限）：
```
/effect give @s wuxingxiantu:paralysis 10 0 true
/effect clear @s wuxingxiantu:paralysis
```

服务端七项集成测试通过，新增测试覆盖麻痹锁定/解除、元神离体肉身与归位清理、闪电伤害标签；原有雷伤与地面破坏测试继续通过。御空巨体视觉仍需用户实际光影环境复核。
