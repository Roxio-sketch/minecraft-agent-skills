# 灵植与内视图标更新

修为、灵力图标在内视页和背包修炼概览同步替换为用户最新提供的纹样。内视保留黑色原图；背包使用透明底浅金色版本，匹配深色面板。

- 功德添加用户提供的莲星纹样；经脉、体质、生命、攻击替换为用户提供的纹样。功德和攻击通过 imagegen 去除背景，其他黑色原图直接保留；修为和灵力的背包浅金色版本通过 imagegen 生成。渲染时排除透明留白并按比例缩放。
- 清心莲物品右键射线选择普通水源或灵液水源，植株放在液面上方，水源不被替换；不再接受土壤或浅水土底种植。液体撤走后植株脱落。
- 普通培养介质保持基础生长概率；灵壤和清心莲脚下的灵液采用同一倍率（概率分母减半，最低 1）。清心莲普通水每随机刻 1/7，灵液 1/3，成熟 AGE=5。灵壤原先只控制培养门槛，本次补上与灵液共用的加速判定；其他环境偏好继续生效。
- 新增离线灵植外观工作台，14 种灵植、41 个模型、40 张实际贴图，支持生长阶段、旋转、原图中线和镜像叠加检查。原版 cross 父模型补入其交叉面几何。工作台不模拟游戏光照和粒子。

验证：完整构建；16 项服务端 GameTest（包含真实物品右键种植两种液体、消耗一株而保留液体、旱地拒种、排水脱落、两种生长概率）。图标由实际客户端截图检查；工作台资源和脚本检查通过，通过本机 127.0.0.1:8769 提供工作台资源，已在内置浏览器检查清心莲 WebGL 深度显示与布局，错误日志为空。
