# 重力、地形与概览边缘补丁

概览面板原先保留右侧和底部各3 GUI像素的内缩。现背景与金色边框直接延伸至窗口边界，消除内外两条边框之间的留白；内容位置保留。

麻痹只固定水平坐标和视角，取消主动操作；不再固定高度、不再持续清零竖直速度。服务端及客户端保留负向竖直速度、恢复重力，沿原水平位置下落，按正常方块碰撞落地。正常摔落伤害保留。

早期破坏硬度上限原为0.5，只能击碎软土，站在石头上看不到坑。现首雷上限1.5，可击碎普通石头；随劫数增长，各境界最终硬度上限为2、2.5、3、3.5、4、4.5、5、6。原有范围/深度递进及火焰保留。滞空修复也允许玩家在坑形成后继续落地，后续命中重新触发地形破坏。真正空中命中仍不向远处地面制造破坏。

参考用户提供配方：八境主雷宽度采用0.004至0.00505，白芯增益3.8，光晕增益2.4，光晕宽度0.155。核心纯白，渐变仅作用于光晕，保留八境各自的渐变配色和分支形态；终劫集束同步这些材质参数。工作台八境预设同步更新。未将所有境界统一为参考配方的紫/青配色。

验证：14项服务端GameTest通过，包括麻痹实体实际下落及碰撞落地；客户端麻痹捕获中高度从208.85降到184.92，水平锁定仍有效。概览边缘已在实际游戏截图中检查。

预告闪电新增局部天空亮晕：沿该闪电端点铺设28至48格软边蓝白光晕，沿用Skill的光晕合成、深度遮挡与光影桥接，复用同一闪电的生命周期和2至3次闪烁时序。仅增强该处天空的画面亮度，不改全世界光照。最新版19张GPU捕获GL错误均为0，包含sky-warning-lit.png。
