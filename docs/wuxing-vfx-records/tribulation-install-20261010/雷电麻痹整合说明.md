# 雷电与麻痹接入记录（2026-10-10）

真实渡劫命中使用 Minecraft 闪电伤害源；伤害被取消或完全免疫时不施加麻痹。麻痹禁止移动、跳跃、攻击、挖掘、交互、使用物品、丢弃物品、背包及模组技能请求；保留暂停、聊天及管理员救援命令。

命中会中断御剑、境界御空、滑翔、骑乘、正在使用的物品和当前神通；停止领域。元神出窍会先回到肉身再固定位置。中断状态不会自动重启。

工作台预览已迁移：主雷宽度55%，主雷光晕与核心增益保留原值，分支宽度恢复原比例；短电弧随机分布头部、躯干、四肢，160–220ms，16条发射通道；以僵直姿态为底，约每0.95秒短促抽动，优先覆盖原版移动/攻击/使用姿态。全身电流按tick缓存，有16实体和48格距离预算。非人形生物使用按体高缩放的近似电流，暂未适配各生物专用骨骼动作。

终劫替换光柱为技能集束落雷：9、11、13、15、17、19、21、23束；直径3、4.5、6、7.5、9、10.5、12、13.5格，深度方向为80%。这是一道终劫内的视觉束数，原81等伤害计数保持原方案。

天雷领域：使用中等曲折的9束集束落雷，原有被动触发、费用、目标筛选与伤害保留；命中追加按领域品质的短麻痹。

雷霆万钧：同一集束算法，15+境界束，范围直径8+境界×0.5格、核心和光晕增益×1.15；原功法伤害×1.35，改为带施法者归属的闪电伤害；麻痹30+功法品阶×4 tick。费用和冷却保留。每次施法一组领域中心集束，空目标仍有演出。

空中预告：准备与落雷阶段持续，每组30 tick（1.5秒），闪烁2或3次，共用同一几何；36 tick发下一组，留6 tick间隔。覆盖距玩家40–120格区域，横向雷长60–130格；渡劫结束/失败/停止清除全部该试炼演出并转晴。

只有触地才显示击地放电；真实落雷保留逐级浅坑/深坑与周边原版火焰，纯预览不伤人、不破坏、不麻痹。原版雨雪受生物群系规则影响。

测试命令 `/tribulationtest 练气` 到 `/tribulationtest 大乘`，也可使用1–8；默认真实。添加 `预览` 得到纯演出。`/tribulationtest stop` 终止雷劫；已有短麻痹自行到期。管理员救援 `/effect clear @s wuxingxiantu:paralysis`。

验收：10项服务端集成测试，正式构建资源/协议/平衡检查；独立客户端GPU捕获。未验证多人联机及用户所用光影包下的最终画面。

2026-10-10 配色更新：八境劫雷、云中预告与终劫集束统一使用纯白核心（#FFFFFF），沿程渐变仅作用于光晕（gradientTarget=glow）。宽度、核心/光晕增益、渐变两端颜色与比例保持原值。领域及雷霆万钧共用的集束配方同步调整；麻痹电流配方保持原样。

光晕截白修复：原RGB逐通道clamp在glowGain>1时会把渐变色截成白色；改为按最大通道等比例压缩，保留色相。八境与共享集束光晕宽度增加40%，渐变端点饱和度至少65%，最大颜色亮度不变。核心宽度及增益不变。
