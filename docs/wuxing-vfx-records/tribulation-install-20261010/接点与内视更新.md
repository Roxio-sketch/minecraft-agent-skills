# 接点、配方和内视更新

已读取着色器项目的「skill转mod」聊天（01a10955-2d7f-7620-aad4-55dd09f0087f），核对其中核心近轴投影、独立凸段、圆接点、分叉预算及 CPU 优化记录。

核心和光晕均使用逐路径 MAX 覆盖并集，再合成到场景。核心不再直接叠加线段与圆接点，工作台也移除旧核心 miter。仅光晕渐变时保留白核心的原加法增益；光晕使用逐通道增益，八境光晕采用同色系高饱和渐变，避免所有通道一起截白。宽度、核心增益、光晕增益及几何预算未降低。

用户的 63 字段配置保留为可选「白核心 · 紫青光晕」配方，参数包括 .004 主雷宽度、3.8 核心增益、2.4 光晕增益与 #FF00FF 底色。未把这一专用配方覆盖为 skill 的通用默认。正式 skill 与 E:/着色器渲染/skill/minecraft-lightning 同步了渲染源码、着色器、工作台与接入说明。

内视的领域、异火、修炼操作合并到右下角；渡劫与凝晶并排。灵根栏移至左下角，腾出的空间保留空白。原操作条件及消耗移入按钮提示。

境界、体质、心法图标在背包和内视均替换；背包为淡金色，内视使用原黑色透明图。内视护甲图标替换为用户盾形图。按钮底图分为回纹与菱形两款，游戏动态绘制文字与状态；分片时固定角饰和中间菱形宽度，避免随按钮拉长。

灵植工作台简化为一张贴图的左/右半边镜像补全，取消 A/B 独立编辑、复制与模型 JSON 导出。两张交叉面同步预览。切换半边重新读取原始或导入图片；奇数宽保留中心列。导出同名 PNG，仍可恢复原图。Node 测试验证左右镜像、切换使用原始数据、中心列与恢复。

验证：MOD build、skill lightningCheck/build、两套工作台材料与几何检查通过。游戏截图用于验证实际 UI 和 lightning shader，不能外推为全部第三方光影或多人兼容认证。
