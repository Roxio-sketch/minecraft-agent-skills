# 2026-10-10 终劫、素材掉落与背包修复

终劫集束落雷持续30 tick（1.5秒），在0、5、10、15、20、25 tick施加闪电伤害，总量保留原终雷预算。有效伤害会刷新麻痹，至少覆盖剩余终劫时间；高境界麻痹可能延续至终劫结束之后。进度保存到试炼存档，恢复时不重新执行已消耗的伤害阶段。纯预览仍不伤人、不麻痹。

破坏强度由25%随劫数非线性增加至100%；可击碎硬度从0.5递增到各境界上限1.5、2、2.5、3、3.5、4、4.5、5。半径上限2、2.75、3.5、4.25、5、6、7、8格；深度上限2至9格。普通落雷仍须实际触地；终劫若最初击中地面，持续场固定在该地面继续掘坑。原有保护方块、流体、方块实体过滤及周围火焰保留。

麻痹原模型被打坐模型的安装覆盖，现直接接入打坐模型的动画入口，优先于打坐、飞行、云上及灵剑动作。采用进入状态后的局部时钟，进入即开始抽动，约每0.6秒短促抽动；固定低头、抬臂僵直姿势覆盖行动动画，衣服和电流同步姿态。

雷劫开始前三秒逐渐加深雨量与雷暴强度，完成过渡才出现空中预告；预告继续贯穿雷劫。雷光缩窄模糊外晕并收紧核心边缘，保留细白核心、彩色渐变光晕与原增益。

素材问题有两处原因：挖矿品质直接取幸运等级，幸运3以上固定极品；雷劫内部破坏事件也调用挖矿掉落。现内部破坏不产灵材，正常挖矿5%出灵材的概率保留，品质改为独立抽取。幸运0时下/中/上/极品为70%/23%/6%/1%；幸运3时59.5%/27.5%/9.6%/3.4%；幸运增益上限5。已获得的合法素材保留。

背包背景边框内采用不透明底色，导航与内容背景衔接；宽屏药水栏整体向右8 GUI像素，拖条向右5 GUI像素，拖动命中区与新位置一致。

验证：正式构建通过，13项服务端GameTest通过，包含30 tick终劫、存档恢复、早期土层/后期石层差异、天气过渡与麻痹控制。实际客户端18张捕获GL错误均为0；麻痹模型日志确认手臂约-0.55弧度的固定姿势及随时刻变化的抽动，背包/内视截图已检查。多人及第三方光影未验证。
