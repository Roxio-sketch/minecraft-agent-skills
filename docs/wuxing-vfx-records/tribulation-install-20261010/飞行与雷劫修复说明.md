# 御剑拖尾与雷劫修复

本轮将以下改动合并进同一 MOD：

- 御剑拖尾在 `AFTER_TRANSLUCENT_BLOCKS` 保存云层写入前的世界深度；启用云层时走延后合成通道。拖尾与光晕仍使用地形、实体及玻璃深度约束，保留前景遮挡。未重建第三方体积云的透明度或自定义深度。
- 没有御剑历史时提前返回，不创建该帧拖尾矩阵与缓冲；渲染遍历最多 32 把已采样飞剑，而非逐帧扫描整个实体列表。客户端固定 tick 采样仍负责发现飞剑。
- 高速拖尾节点改为一次批量移除前缀，避免循环 `ArrayList.remove(0)` 的反复搬移；保留 256 节点、22 格长度、22 tick 寿命与固定 tick 轨迹。
- 第一人称不再执行第三人称相机的八次碰撞射线。
- 飞行移动先对整段包络作一次有预算的无障碍检测；失败后执行原本 0.2 格细分 sweep。阻挡、未加载区块和超预算路径不走捷径，不主动创建区块，不更改速度。
- 御剑装备的一秒同步改为仅数据变化时发送；仍支持飞行锁定期间灵剑养成数据更新。移动快照维持正常 20 Hz，不通过削减快照制造抖动。
- 雷电主干和圆形接点先在独立缓冲作 MAX 覆盖并集，再合成到画面；消除同一路径接点重叠产生的额外亮度，保留配方宽度、增益与渐变。
- 雷暴与转晴显式发送降水状态、雨强度及雷暴强度包，避免直接改服务端雨量绕过原版按帧差值同步。
- `/tribulationtest 境界` 或数字 1–8 默认真实雷劫，会扣血和破坏可破坏方块；末尾 `真实` 仍可使用，末尾 `预览` 才是无伤演出。创造模式仍遵循原版免伤。

验收：完整构建与既有数值/资源回归通过。五项服务端 GameTest 实际执行通过，覆盖真实指令、无伤预览、伤害、方块破坏/恢复、雷暴/转晴，空中雷击仍扣血但不生成击地效果/不破坏远处地形，以及飞行空中移动、碰墙、遁虚穿墙和未加载区域阻挡。客户端实测记录雷暴期间 `raining=true, thundering=true`。

性能结论来自具体代码路径与回归，不是平均 FPS 提升承诺。光晕仍有半分辨率四次模糊，显卡负载和多人、高速生成新区块造成的外部压力仍可能影响流畅性。未完成用户 Oculus 光影包下的专门回放验收。

新的八境终劫落雷场预设已放在 `deliverables/tribulation-final-rain-20261010/` 的 skill 工作台。按用户“先给预设”的要求，本次游戏包仍保留已实装的终劫光柱；落雷场替换待下一步接入。

击地判定由服务端实际脚下碰撞面决定，不依赖可能陈旧的 onGround 或创造/骑乘标记。空中雷体仍显示且正常扣血；不生成击地电弧、环与火花，不播放击地声，不破坏脚下远处地形。末期光柱的扩散环也遵循同一判定。
