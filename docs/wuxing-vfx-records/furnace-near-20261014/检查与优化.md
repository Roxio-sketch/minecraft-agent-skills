# 炉底火焰近距离性能

原因是全分辨率体积积分在贴近炉底时覆盖大量屏幕像素。被炉体深度截短的可见气体区间仍使用400个积分点；近距离负载随可见像素增长，区别不在第一人称控制逻辑本身。

本轮保留长射线的原采样预算；仅当可见气体厚度小于0.4格时，按最大1毫米步距选择48至400次采样（用户预算更低时仍遵守用户预算）。不降低屏幕分辨率，不改火焰密度、运动、细节噪声、配色、透明度或模型避让。积分点变化意味着浮点结果不是逐像素完全相同。

验收对同一机位、同一深度、同一时刻及同一九火配色运行新旧着色器：RTX4060Ti、1280×900，每个版本24次交替GPU查询。记录的是单次底火绘制耗时，不是整机游戏帧率。原版体积后端原有噪声缓存全部保持，基线启用与新版本相同的缓存。

近距离九火基线约74–90ms，调整后约68–83ms，降低约8%。最大实际混合颜色误差上界0.003010，小于1/255；该度量同时计入预乘颜色与透明度变化，避免把几乎透明像素的未预乘RGB差异误当成屏幕可见误差。原缓存等价检查要求未预乘RGBA逐像素一致，因此首次试验未通过；改积分精度的试验使用实际混合误差进行质量验证。九种异火均通过，GL错误为0。测试是固定时刻与机位，不能保证所有时刻/硬件都具有相同误差或提升。

目前近距离仍然过重，这轮不是彻底解决。推荐后续用固定炉体的曲面火苗与炽燃燃床替代外沿体积步进。保持九火配色与卷曲层次，先在同一近距离机位验证画面和耗时；方案详见 ../cold-sun-colors-20261014/炉底新方案.md。本轮尚未实现该替代管线。
