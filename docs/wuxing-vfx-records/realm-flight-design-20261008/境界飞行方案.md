# 境界飞行速度与特效待审方案

本文件是设计提案，未修改飞行速度、消耗或现有动画。此前授权的愈魂室、修炼概览、踏罡步斗修改已另行实装。本次不构建、不启动游戏。

## 源码现状

- 境界顺序：练气、筑基、金丹、元婴、化神、炼虚、合体、大乘、地仙；鬼仙是最后一档的另一身份。
- CultivationTicker.updateFlight：元婴（realm=3）解锁原版能力飞行；元婴、化神飞行消耗25灵力/秒，炼虚（realm>=5）起不收常态飞行费用。
- 当前普通境界飞行没有按境界设置速度表，0.05是若干退出分支的复原能力值；它不是实测的格/秒速度。
- RealmFlightVisuals已经实现悬停起伏、速度驱动的横向飞行姿态和转弯倾斜，支持原版动画偏好。当前没有完整分境界气流、拖尾和起落特效。
- 御剑默认基础速度源码为1.74格/tick，疾行2.61格/tick，按20TPS折合目标34.8/52.2格/秒；实际还受配置、剑的阶段、加速及碰撞影响。方案将裸身飞行上限控制在这一运输基准下，不改御剑或筋斗云。

## 建议速度

以下为20TPS下、直线稳定飞行的目标速度，初期数值。需要通过实际位移验证，不能把getFlyingSpeed直接当作格/tick。

|境界|巡航 格/秒|疾行 格/秒|上升/下降上限 格/秒|飞行1000格巡航时间|
|---|---:|---:|---:|---:|
|元婴|8|12|4|125秒|
|化神|11|16|5|91秒|
|炼虚|14|21|6|71秒|
|合体|18|27|8|56秒|
|大乘|23|34|10|43秒|
|地仙/鬼仙|28|42|12|36秒|

- 同境界中期、后期、巅峰分别乘1.04、1.08、1.12，平滑过渡；地仙巅峰31.36/47.04格/秒。
- 双击跳跃起飞保留；普通方向输入巡航，飞行中疾跑输入切到疾行，松开恢复巡航；跳跃上升、潜行下降保持现有习惯。
- 0.8秒达到巡航，0.6秒切入疾行；松开方向后0.35～0.5秒减速到悬停。斜向输入归一化，不能靠斜飞突破上限。
- 精确落地、狭窄洞穴和近障碍场景提供低速操控：贴近碰撞面时限速、保留碰撞，不用穿墙或直接传送代替移动。
- 服务器决定速度档、资源消耗和是否允许飞行；客户端预测与纠偏，能力数据只在档位变化时同步。神通、御剑、附身和创造模式具有独立入口，退出后复原相应状态。

## 灵力建议

保留元婴/化神巡航25/秒，疾行50/秒；炼虚及以上常态飞行仍免费。建议高阶疾行消耗最大灵力的0.5%/秒，避免免费无限最高速；这一新增消耗须与速度方案一起审视。耗尽先退出疾行，再沿现有规则判断是否停止飞行。

## 视觉语言：御气凌空

整体采用青白薄气流，随境界增加结构和稳定感，不随境界堆积浓烟或增大遮挡。

|境界|巡航形态|疾行形态|
|---|---|---|
|元婴|腰身至脚踝的一层淡青气纱，短星屑|两条短气流线，约1～2格余迹|
|化神|双侧流线、脚踝薄弧，气流更连贯|约2～3格细流线，零星青白节点|
|炼虚|内外双层细丝，一层稀疏符纹|约3～4格淡尾迹，偶发细碎空间星点|
|合体|双螺旋气脉与贴身柔光，运动方向明显|约4～5格三束光丝，转弯时弧线随真实路径弯曲|
|大乘|淡金点缀青白主色，清晰而稀疏的符文节点|约5～6格气流长带、短暂收束尾光|
|地仙|白金薄纱与少量金色星芒|约6～7格轻云丝带，间隔出现细环脉冲|
|鬼仙|同速度、同预算；青紫魂纱和冷白星点|青紫幽气细带，保留空气感，避免黑烟遮挡|

悬停时保持人物直立，脚下直径约0.7～1.0格的短弧轻轻转动、少量上升细丝。巡航时沿用当前平滑姿态与转弯倾斜；疾行加强流线和尾长，第一人称仅显示侧下方稀疏气流，不在屏幕中心画光环。默认不增加镜头抖动，额外FOV最多3度并可关。

起飞0.35～0.5秒脚下轻扩圈，约12～20颗短星屑；落地0.3秒收束并向外散开。切入疾行只做一次短脉冲，不能每tick爆发。特效跟随实际运动轨迹；零速不积累拖尾，瞬移或跨维度立即断带。

## 接入与预算

- 复用RealmFlightTracking的服务端资格与现有偏好入口，新增视觉档和疾行状态；只有状态变化和低频校正需要广播，不逐粒子发包。
- 客户端固定20Hz模拟，渲染插值；每个近处飞行者约40～100颗同时存活粒子，全局软上限1200。32格外减半、64格外只保留姿态和短流线。
- 连续气流采用trails-beams的真实路径、弧长UV、短寿命带状几何；气纱采用energy-vfx的细丝、柔边与低覆盖率思路。先复用现有运行库和材质，避免无必要的额外依赖。
- 普通绘制测深度、不写深度；Oculus路径参考现有御剑和新踏罡贴图桥接，使用世界深度快照、合成后提交。第一人称排除身体中心的气团，不用全屏Bloom。
- 验收分别覆盖各境界、鬼仙、多人围观、F1、原版偏好、昼夜、水中/坐骑/附身排除、墙体遮挡、瞬移、退出及不同光影包。当前概念预览不证明这些场景已通过。

## 待审决定

重点确认巡航8→28、疾行12→42的梯度，以及是否采用高阶疾行0.5%灵力/秒。视觉推荐御气凌空的薄气纱与真实路径拖尾；可调整金色占比和高阶尾长，不影响速度方案。
