# 流星御空

按最终用户澄清，玩家身体和手继续正常显示。移除此前境界飞行粒子发射器及横飞、摇摆等旧视觉姿态入口，替换为身体周围半透明青白光壳、软光晕与连续三层拖尾。鬼仙光晕为淡紫色。没有隐藏人物，没有改飞行数值或资格逻辑。

主体以玩家插值位置和身体中点为中心，半径约1.05格，三维球壳为低透明度网格，外层光晕面向相机。近处透过光壳可见玩家，远处呈带尾的发光团。第一人称省略本人的光壳和拖尾，防止覆盖视野；其他观察者和第三人称能看到。

拖尾按20Hz采样实际移动路径，最多24个点，约0.9秒寿命，长度最多18格；采用宽晕、青色光带、细白芯三层连续几何，按年龄和长度渐隐、收窄。停下后尾迹自然消退，传送与跨维度清理历史。每帧不新增历史点。没有任何粒子发射。

沿用已有光影兼容绘制桥：常规场景测深度、不写深度，光影开启时提交到已有后置通道并使用场景深度。此处的光晕是几何和透明材质效果，不是额外场景照明或屏幕Bloom。

完整Forge build通过；资源与协议等工程检查随build通过。具体流星观感、第三人称和光影包仍需游戏内看图验收，不能用构建代替视觉实测。
