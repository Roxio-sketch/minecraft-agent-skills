# 飞行、状态栏与踏罡步斗修复

- 境界御空：新增服务器校验的双空格切换请求；客户端在两次跳跃按下相隔不超过7 tick时请求切换，不再只依赖原版自动切换。刚起飞时保留向上速度，站在地面且没有下降输入时给予0.16格/tick离地速度，避免飞行加速度清零后仍贴地而被原版取消飞行。近障碍检测缩小碰撞盒0.02，避免将脚下地板当成贴近障碍而持续限速。低境界灵力要求及神通、御剑、创造模式隔离仍保留。
- 状态栏：短名称后直接显示 `Lv.等级`，时间单独在第二行，详细效果说明保留在悬停提示中。
- 功德：使用和护甲同一右半列，文字横坐标对齐；保留20像素图标列，目前不绘制图标。
- 踏罡步斗：七个星位的水平布局及阵环范围扩大至此前5倍，高度保持不变；踩点判定仍要求实际走至目标星位。服务端记录1200 tick期限，60秒后清除未完成步阵与特效，保存期限避免重新追踪刷新时间。完成七步仍立即触发原有天气切换和收束特效。说明文案已同步修改为60秒。
- 明显度：增大星点、符文和地面气纹，增粗连接线，未完成连接线透明度从0.12提高至0.6，未完成星点透明度从0.23提高至0.65，同时强化外围符环和柔光。
