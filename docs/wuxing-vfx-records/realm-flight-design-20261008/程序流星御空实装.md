# 程序流星御空初版

恢复特殊飞行姿态入口，移除上一版光团状态对RealmFlightVisuals的排除。配置默认仍为特殊御空，已有用户选择的原版模式继续保留。

新增realm_meteor与realm_meteor_post两套GLSL程序及注册入口。主体使用相机朝向的解析圆形光壳，片元计算旋转细丝、边缘亮弧、弱内部光与径向柔边；人物保持可见。此次是程序光壳初版，尚未实现设计提案中的三维椭球法线/Fresnel材质，也没有独立Bloom缓冲。

拖尾仍由真实位移历史生成三层连续几何，UV横向坐标控制柔边和白芯，纵向采用累计弧长控制流动条纹，不再绑定或采样图集。停下、传送和跨维度保留过期清理。长度上限24格，实际长度受0.9秒历史寿命和移动速度影响。现阶段保留24个历史点，尚未加入曲线细分和远距离LOD升级。

普通绘制使用专用程序材质；光影路径通过扩展御剑TrailShaderBridge，绑定专用程序着色器并读取已捕获世界深度。不改其他剑气及踏罡材质。用户选定光影包下的实机视觉兼容性尚待验证。

验证：GLSL150着色器主体经适配为GLSL ES300，在Edge WebGL2编译、链接通过；完整Forge build与reobfJar及工程检查通过。首次reobfJar遇到系统内存提交不足，降低构建JVM至512MiB后成功。编译与构建不代替运行时视觉验收。

安装到此前指定测试实例的mods目录，旧包备份于实例mod-backups目录。重启游戏后验证第三人称巡航、疾行、转弯及远处观察效果。
