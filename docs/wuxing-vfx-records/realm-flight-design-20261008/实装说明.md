# 境界飞行实装

已按获准方案加入元婴至地仙/鬼仙的六档飞行速度、四阶段倍率和疾行消耗。巡航目标为 8/11/14/18/23/28 格每秒，疾行为 12/16/21/27/34/42，阶段倍率为 1/1.04/1.08/1.12；垂直速度上限为 4/5/6/8/10/12，同样采用阶段倍率。

双击跳跃仍由原版能力入口负责。方向、升降输入统一归一化，直接控制有碰撞的正常 travel 速度，不传送移动。巡航加速16 tick，疾行档位过渡12 tick，制动8 tick；靠近碰撞面时目标速度降至四分之一。实际飞行会受转弯、碰撞、服务器 TPS 等影响，表格是20 TPS下的无障碍稳定目标。

服务端接收的消息只含方向和疾行意图，方向长度限制为1；超过10 tick未收到输入便制动。服务端决定境界、阶段、消耗及资格；客户端运行同一运动核预测，位置仍由原版移动协议与纠偏处理。并未另外实现专用飞行反作弊或位置快照系统。元婴/化神巡航25、疾行50灵力每秒；炼虚起巡航免费、疾行每秒消耗最大灵力的0.5%。灵力不足时先退出疾行；低境界不足巡航一个 tick 的费用时关闭飞行。开销逐 tick 结算，沿用已有灵力恢复逻辑。

特效在已有半透明粒子通道中使用 wind_streak、wind_curl、spark_soft、meridian_knot、prism_glint、ruyi_cloud 等现有库素材，满亮度、低覆盖率。按实际位置位移生成两股/三股细丝，高境界增加螺旋和金色点缀，鬼仙采用紫青色；起落和进入疾行时产生脉冲，悬停时产生足下气纹。第一人称省去中心气纹、云纹与起落脉冲，仅保留侧后方细丝。32格外减半发射频率，64格外四分之一并简化为一股，128格外不发射。每人最多100个本效果粒子，全局最多1200个；传送、维度变化和离开追踪范围断开路径。粒子寿命最低4 tick，因此高速时拖尾长度是近似目标；当前没有连续带状网格或按弧长展开的UV。

保留原有悬停、横飞、转弯姿态及镜头设置。御剑、筋斗云、元神出窍、移魂寄魄、变化附身、创造模式均排除出普通境界飞行控制。没有新增相机震动，也没有引入新渲染依赖。

消息协议更新至69，保留已有ID，新增73号飞行输入消息。70号视觉消息增加境界、阶段、鬼仙身份与疾行字段，旧测试已更新。

验证：实际运动核CPU测试通过24组境界/阶段轨迹，覆盖速度表、16 tick加速、8 tick制动、斜向上限、12 tick疾行过渡和费用公式；74条消息协议契约、14项资源测试与入口UI检查通过。完整Forge构建包含GameTest源码编译及reobfJar。游戏内速度实测、视觉验收和具体光影包兼容性尚未执行；不能用构建或CPU验证代替这些结果。

本次构建也包含此前已实装的愈魂室六面32×32贴图与文字位置、修炼概览贴合框架、踏罡步斗效果和元神出窍时左上角UI保留。
