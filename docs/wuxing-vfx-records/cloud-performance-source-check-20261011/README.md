体积积分使用半分辨率目标，最大 960×540；视线采样最多 24 步，光照最多 2 步。只计算低分辨率辐射与透射率，随后以深度加权四邻点重建，在全分辨率场景上合成。保存原 GL 状态，仅保存实际触及的三个纹理单元。

云层与闪电统一通过已有晚绘制桥接器：先合成劫云，后绘制闪电。闪电使用捕获的场景深度，保留地形遮挡，不受云层颜色二次压暗。

只在世界绘制云层的时间段临时把原版云设为关闭，粒子阶段和帧结束恢复原设置；异常帧、退出和世界卸载也有恢复入口，不保存选项文件。Fabulous 设置回调会清空云缓冲，修改前后恢复帧缓冲和视口。光影包自带云不在此控制范围。

独立 javac 检查通过，输出只在 reports 内。14 项资源检查通过。WebGL2 转换后的实际 GPU 编译、零密度场景恒等、零密度 L/T 与合成恒等通过，GL error=0。
