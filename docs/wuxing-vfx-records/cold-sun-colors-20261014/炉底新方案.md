# 炉底新方案（设计，尚未替换现有渲染）

当前瓶颈仍是逐像素体积步进。缓存可以降低每步成本，却不能消除大量深度采样和透明区域的重复计算。

推荐采用“炽燃燃床＋固定炉体的曲面火苗”：

- 缝隙内部增加贴合炉底的燃床表面，遮住未燃烧的底部；用暗色底、热裂纹和缓慢流动的亮区表现持续燃烧，避免整块发白。
- 外沿用固定在炉体坐标的多层曲面火苗取代体积步进。曲面沿炉壁排列，通过动态遮罩产生卷曲、撕裂和翻涌；保留深度遮挡，避开炉腿和金属结构，不随相机转向。
- 远处使用更少的曲面层与相同色板，近处保留交错层次。避免额外粒子填满整个底部。
- 九种异火使用独立配色与运动参数；涅槃神火保留整体轮转色。枯骨冷火采用冷银灰/灰紫，大日圣火采用暖白/日金。

验收先做同机位的新旧对照和 GPU 耗时测量，再决定替换。重点检查近距离缝隙、侧向移动、炉腿遮挡、九种异火和 Solas 光影。设计不能保证与体积火焰完全一致，也不能在测量前承诺具体帧率提升。
