# 第一人称四周流动

用独立的程序气流材质替代原来只在曲线上改变透明度的光带。水平边缘场向左右流动，垂直边缘场向上下流动，四角平滑混合；时间驱动的坐标卷曲、两层密度噪声、细丝与消散共同形成变化，不是静态光带的闪烁。

上方、两侧、四角与下方均覆盖。下方维持相近范围，中央矩形观察区不绘制。气流随画面即时显示，不读取历史世界轨迹，因此转向无历史拖尾延迟。普通移动显示、冲刺增强；实际速度≤0.025格/tick不绘制，不新增浮空光效。境界配色、独立第一人称开关及视角一致性规则保留。

一次绘制、四个不重叠条带、16顶点，无体积步进、离屏缓冲或全屏模糊。片元着色器比旧颜色渐隐材质复杂，未测GPU耗时，不能据顶点数推断整体帧率改善。采用本地模拟时钟，避免旧世界时间或服务器校时影响流动。

完整build通过。化神、炼虚、地仙12张昼夜实机截图及344项帧/状态检查通过，包括静止不显示、普通/冲刺强度、起飞和退出视角一致性；GL错误为空。外部光影包未启用。最初的放射细线/闭合环状试验未发布，最终预览仅使用 verified-ui 目录。
