# 境界御空第三人称黑屏：修复与验收

2026-10-09，已完成源码修复、实际客户端验收、构建和安装。

## 根因和修复

在独立客户端复现了首次第三人称背面/正面切换后世界变黑、HUD 仍显示的故障。最初第一人称正常；故障出现后返回第一人称也可能继续黑屏。隐藏 HUD 后恢复。

特效只还原了实际 OpenGL 混合状态，未还原 `BlendMode.lastApplied`。原版暗角先设置 `ZERO / ONE_MINUS_SRC_COLOR`，随后 `position_tex` 着色器因缓存失配，重新设置 `SRC_ALPHA / ONE_MINUS_SRC_ALPHA`。暗角纹理 alpha 为 1，其黑色中心因此直接覆盖世界。仅修改缓存恢复后，同场景从黑屏恢复为正常；原始截图对照已保留。

最终改动：

- `MeteorBloomRenderer.State` 同时保存并恢复混合缓存、实际程序、纹理单元、FBO、视口、裁剪矩形、清屏颜色及颜色写入掩码；异常退出也失效程序缓存。
- 原版路径的御空拖尾提交使用同一状态作用域。
- `TrailShaderBridge` 合成还原混合缓存，深度捕获固定使用纹理单元 0，FBO 恢复经过 Minecraft 的状态管理器。
- Access Transformer 只新增 `BlendMode.lastApplied` 的访问权限，SRG 字段 `f_85499_`。

最终 `build runGameTestServer -PrealmFlightOnly` 成功，7 项御空 GameTests 全部通过；资源检查及已有回归检查通过。之前移动失效修复的 `RealmFlightControl.java`、`RealmFlightMovement.java` SHA-256 保持一致。

测试范围为上述独立客户端组合。AFTER_PARTICLES 的全事件观察包含御剑等其他监听，深度和纹理变化仅作为观察；精确恢复断言在单独的 `State` 作用域验证。Solas 初轮截图排队中断，修正测试脚本等待真实截图后重跑通过；生产代码未为此改动。诊断失败记录均保留。
