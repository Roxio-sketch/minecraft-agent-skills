# 护盾破碎、御体世界显示与四级云篆

本轮接入「能量护盾」聊天及 `minecraft-stylised-shield` Skill 更新的破碎效果，并优先修复用户报告的灵力御体仅背包可见、御剑拖尾消失问题。平台为 Minecraft 1.20.1 / Forge 47.4.10 / Java 17。

## 灵力护盾

血量耗尽的一击保留零盾值红色壳体，下一次独立受击发送服务端确认的破碎事件。耗尽同一支箭的超额伤害不会误触发下一击；接触推离和紧随的近战去重。零盾值壳体不再拦截伤害或推离生物，破碎之后原伤害按正常规则结算。

原球面精确裁切成110块曲面 Voronoi 碎片，边界只绘制实际碎片轮廓，裂纹按来袭位置向外传播。碎片保留原始材质坐标，独立旋转、飞散、下落并在2.4秒内淡出，伴随64个火星。破碎原点固定在受击位置，不跟随玩家移动；完整球壳不会叠在飞散碎片上。再次受击不重播，重新施法会清除旧碎片。

纯几何分割采用单后台线程和有界任务队列，避免首次裁切占用渲染线程。完成回调验证世界、实体、原始事件身份及寿命；换世界、重施和过期时丢弃旧结果。计算期间保留红壳，动画时间不重新开始。

独立服务器10项 GameTest通过：耗尽保留壳、后续近战/箭击破碎、同箭余伤排除、创造箭接触、碰撞与近战去重、重施恢复。真实客户端39张截图通过，包含24帧破碎过程、重击不重播、动画结束、动画途中重施、墙体遮挡及两个Shader重载，所有GPU检查为GL=0。首轮客户端测试碰到新玩家的原版复生保护，测试等待保护自然结束后才进行伤害；未改生产免伤规则。报告：`gametest.log`、`runtime-validation.json`，原始截图：`../shield-shatter-client/`。

## 灵力御体世界显示

Oculus的世界实体缓冲会延后绘制，`FullyBufferedMultiBufferSource.endBatch(RenderType)` 是空操作；启用外部着色器时也可能返回普通 `MultiBufferSource` 包装。因此原先要求具体 `BufferSource` 并在装备层内立即绘制的路径既会漏捕获，也会被随后提交的基础护甲覆盖。

现在通过通用 `MultiBufferSource` 捕获当帧真实装备顶点、UV、法线和受击信息，在基础实体缓冲刷新后的 `AFTER_PARTICLES` 阶段绘制。保存原捕获矩阵，匹配原版护甲的视图深度偏移，保持墙体与上层装备遮挡。背包继续即时绘制。每帧清空队列，玩家移动不会留下旧装备位置的残影。底材、透明裁切、染色和普通附魔槽保留。

独立兼容客户端装入用户使用的 Embeddium 0.3.31 和 Oculus 1.8.0，外部光影包关闭。39张实际截图验证F5本人正常世界与背包预览、移动后停止、正背侧动态、受击、槽位隔离、墙体遮挡和Shader重载。全部GL=0，世界确实使用FullyBuffered缓冲。记录见 `../guard-world-fix-20261013/runtime-validation.json`。

## 灵力御体 I～IV 级

每件装备按自身的 `spirit_guard` 附魔等级选取专用遮罩与参数，不使用全身最高等级统一覆盖。超过IV的特殊NBT等级按IV外观显示。

| 等级 | 常态纹路 | 流光循环 | 受击波纹 |
|---|---|---|---|
| I 初护 | 稀疏主C单笔，8笔 | 4.8秒 | 小范围主环 |
| II 成纹 | 双笔回旋与必要侧纹，18笔 | 4秒 | 主环与弱回波 |
| III 云篆 | 保留原完整云篆，25笔 | 3.6秒 | 更清晰的局部双环 |
| IV 护篆 | 追加8处细护笔，共33笔 | 3秒，增加窄第二道流光 | 较强主环、双回波 |

四级保持淡蓝色、1024×512数据遮罩和0.32像素窄抗锯齿边缘。纹路数量与流动层次随等级变化，不靠模糊或大面积染色提升等级。仅调整外观，附魔减伤与灵力消耗数值不变。任意第三方自定义护甲UV继续保留原附魔外观，局部受击使用实际捕获的几何。

原创可重建资产与四级说明：`../../source-assets/spirit-guard-cloud-20261013/levels/`。真实四档13帧验收及每槽混装对比：`../guard-tier-client/`，最终预览与验证：`../guard-tier-20261013/`。

## 御剑拖尾

用户测试(1)实例的 `config/wuxingxiantu-flight-client.toml` 中 `trails = false`，该设置会清空历史并停止采样、绘制。已备份配置并恢复为true，保留其他参数，未强制覆盖源码中的用户开关。

独立真实客户端以生产御剑输入包触发功法/装备判定、服务器挂载及同步飞剑移动。250 tick检查常规、后期和自动云层三条路径均提交可见拖尾；关闭开关时全部归零。6张GPU截图GL=0。证据：`../sword-trail-client/captures.json`。输入为生产网络包测试，不声称做了操作系统键盘注入。
