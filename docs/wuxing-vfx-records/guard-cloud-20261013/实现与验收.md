# 灵力御体：B 云篆护纹

用户确认采用B云篆护纹接入游戏，随后要求减少模糊。本版使用原创起伏粗细的云篆笔形，在真实穿戴的目标附魔护甲表面逐笔显现、错峰收笔。保留原护甲的纹理、染色、饰纹及动作；停止原来围绕人物自动生成的御体粒子，取消皮肤模型受击层。御体消耗灵力、减伤等功能不变。

按装备槽分别判断灵力御体：只附魔靴子时，头盔和胸甲没有云篆，普通附魔护腿继续使用原附魔分支。法袍隐藏的装备槽仍隐藏；打坐、飞行、铸剑使用实际分段护甲骨骼的顶点。隐身人物的可见装备也保留云篆。

首次实机图的笔画过软，后改为1024×512原创数据遮罩，将边缘抗锯齿范围收至0.32像素，shader增加窄亮芯并压缩透明柔边；受击环也缩窄。游戏图来自实际GPU采集，没有重绘或增强其颜色。

实现位于 SpiritGuardArmorRenderer、SpiritGuardArmorRenderType、RobeArmorLayer；SpiritGuardLayer只保存服务端确认的受击时间与方向。复用原armor draw的实际顶点及UV，先绘制原装备依赖，再以独立、立即提交的批次绘制附魔光纹，避免多件装备共享uniform串色。原护甲透明像素裁切光纹，保留深度测试与仅写颜色。受击在实际incoming侧的护甲四边形求交点，局部波纹0.8秒结束，不在整个人物皮肤上画环。

云篆周期3.6秒，亮头沿原创笔形前进，旧筆画从尾部退出。G/B通道保存预乘覆盖率的笔画进度和簇相位；取样后还原，避免线性过滤改变簇相位。源曲线、轮廓、生成器和合同验证见 source-assets/spirit-guard-cloud-20261013/ 与 tools/generate_guard_cloud_mask.py。

完整Gradle build通过，包括项目资源、专项检查、回归与GameTest编译。最终日志为build-final.log，exit为0。独立Forge1.20.1/47.4.10客户端采集30帧，确认铁甲/下界合金甲、前后侧动态、目标槽隔离、两个真实服务端受击包、局部波纹、夜景、资源重载替换shader和零GL错误。第一次箭击测试被不可见相机盔甲架截住；测试fixture将箭出生点移到相机前方后，第二次真实箭击通过，不修改生产伤害逻辑。

墙体完全遮挡时没有蓝光像素，开关效果的墙体差异全部是灰度变化，没有蓝色附魔穿墙。具体检查见runtime-validation.json、原始采集元数据reports/cloud-glyph-client/captures.json。画面回放与对照为cloud-glyph-game-motion.gif、cloud-glyph-game-review.png。

已安装到测试 (1) 实例，替换旧guard-buff-glow版本。安装记录与SHA256见installation.json。旧版本在deliverables/installed-mod-backups/保存，可回退。运行中的客户端需要重启加载新版。

边界：当前覆盖玩家穿戴护甲的渲染，背包图标、手持或掉落护甲物品的foil未改。第三方自定义UV护甲保留原glint，受击可使用捕获的实际几何；未验收外部着色器包。打坐等自定义动作的兼容由实际骨骼捕获保证，但本次GPU场景未单独采集全部动作。
