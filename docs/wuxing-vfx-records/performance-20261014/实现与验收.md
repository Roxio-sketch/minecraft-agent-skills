# 本轮性能与界面修复

本轮保留特效的分辨率、射线采样数量、颜色、火焰形态和动画参数。原版与 Solas V3.7b 的九种异火均进行了同一画面、同一深度、同一参数的配对 GPU 测量。

## 底火性能

| 渲染环境 | 原绘制耗时中位数 | 新绘制耗时中位数 | 九种火焰耗时降幅中位数 |
| --- | ---: | ---: | ---: |
| 原版 | 33.523 ms | 20.067 ms | 40.32% |
| Solas V3.7b | 33.543 ms | 19.725 ms | 41.20% |

测试硬件为 RTX 4060 Ti，画面 1280×900；每种火焰交替测量两版各24次，另有预热。上述耗时为底火单次绘制的 GPU 时间，不是整场景帧率。RGBA32F 全画面比较，最大浮点通道差为原版0.00000155、Solas 0.000000984，远低于一个8位颜色档位；所有捕获 GL 错误为0。

具体改动：

- 编译专门的底火程序，排除未启用的炉口、丹气等分支；提前跳过数学上贡献为零的炉底遮挡区域。
- 将旋涡噪声一个格点的八个原始角值打包为两次 RGBA32F 读取。缓存的是原哈希值，火焰密度、导数、三次流动计算和完整射线积分仍实时执行。
- 用核心方块加载登记替代每帧遍历全部可视区块，保持原有炉子遍历顺序和显示预算；颜色与参数数组复用。
- 缓存按实际出现的火焰类型创建，每种12 MiB，最多十种120 MiB；资源重载/退出世界释放。OpenGL 4.3 不可用时使用原精度计算程序。
- 噪声缓存格点范围覆盖允许的炉火半径、高度、湍流、三次中点流动与四格复用余量。缓存不对场密度做低分辨率插值。

参数文件与旧安装版本逐字节比较：`recipe.json`、`nine-flames.json` 完全保留。试验中更慢的单通道缓存和超出像素误差要求的额外分支跳过方案均未保留。

数据：[原版配对计时](paired-gpu.json)、[Solas配对计时](solas/paired-gpu.json)。

## 界面与交互

- 背包体质、当前心法、当前领域和当前异火悬停，共用内视页的说明；灵力条两页共用余额和当前回复速度提示。
- 雷/异变灵根中心改为原生菱形渐变绘制，去掉原图中文字的矩形背板。
- 灵力损耗记录增加玩家独立开关并保存到存档。关闭后实际扣灵力照常，但不追踪来源、不新增记录、不持续发送记录包。开启时使用惰性栈遍历、256项来源缓存和版本变化同步；界面不再每帧复制NBT历史。
- 炼丹炉的储量和每次注灵量按六档品质递增：储量对应120/180/240/300/360/420秒本档燃耗，每次注灵对应2/4/6/8/10/12秒燃耗，仍每4 tick一次，保持灵力守恒与上限。菜单燃料值拆分同步，避免超过16位时截断。
- 中心未成丹图标灰色，成丹显示原色；点击中心通过服务器将实际丹药放入背包。背包放不下的余量保留，重复领取不复制物品。客户端核心方块数据迟到时会从临时对象切换到实时结果对象。
- 铁砧模板选择、每种模板参考成品放到左栏，标注“预览仅供参考”；名称输入框同步移动，翻页保留名称输入，点击左栏不被当成界面外丢弃物品。

## 筋斗云和铁砧

筋斗云取消高速被当成瞬移后跳向下一tick位置的锚点，使用与相机一致的插值端点；正常加速、急转弯保留连续轨迹，真正瞬移清除旧尾迹。保留现有云体、密度和32段容量，复用上传数组及光影绘制缓冲。

原版与Solas分别验证实际飞行1234格，含18/24格每tick、跨256格渲染原点、转弯、瞬移和关闭。诊断要求云体锚点误差为0、没有未来时间采样、连续高速轨迹存在、瞬移清尾成功。驱动同时更新相机和人物模型的上一帧端点，使用真实F5路径；不会修改玩家存档。

极限速度压测会进入尚未载入的客户端区块，这些帧以云体锚点和人物插值坐标的诊断比对为依据，不能作为完整地形/人物画面验收。原有已加载场景的深度与黑屏验证仍保留。

模板登记在原版主手事件消费点击前检查两手，兼容副手与潜行；登记保存在该方块所在维度的存档，不消耗模板。加宽后的模型碰撞/选择范围同步，外侧台阶不再点穿。模板选择同步用1～64库索引，避免物品注册ID被16位截断。保留原版升级与饰纹配方、材料消耗、修复附魔和灵力费用。

铁砧发光遮罩补齐暗蓝纹和淡青色亮芯，所有烘焙面参与，包括底座；黑铁及金属包角不作为自发光区域。原版与Solas分别夜间从四向观察并验证实际提交发光绘制，光影路径读取场景深度。

预览：[底座夜景](anvil-native/anvil-night-north.png)、[Solas底座](anvil-solas/anvil-night-south.png)、[九阶底火](solas/furnace-tier-9.png)。
