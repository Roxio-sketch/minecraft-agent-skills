# 临时御空特效切换

重启实例加载新包后，先进入实际境界御空，再切换第三人称观察。指令只切换本地玩家的视觉，不授予飞行权限、不改实际境界、速度、灵力消耗或Buff等级，也不会同步给其他玩家。无需开启作弊。退出世界自动恢复。

| 指令 | 效果 |
| --- | --- |
| `/wuxing flightfx 1` 或 `/wuxing flightfx 元婴` | 元婴 |
| `/wuxing flightfx 2` 或 `/wuxing flightfx 化神` | 化神 |
| `/wuxing flightfx 3` 或 `/wuxing flightfx 炼虚` | 炼虚 |
| `/wuxing flightfx 4` 或 `/wuxing flightfx 合体` | 合体 |
| `/wuxing flightfx 5` 或 `/wuxing flightfx 大乘` | 大乘 |
| `/wuxing flightfx 6` 或 `/wuxing flightfx 地仙` | 地仙 |
| `/wuxing flightfx next` | 下一个境界，循环切换 |
| `/wuxing flightfx off` | 恢复真实境界外观 |

临时实现集中在 RealmFlightPreviewCommands，预览只接入渲染外观及尾长选择，方便之后删除。构建、回归与打包核验通过，本轮未进行实机指令及颜色观感验收。
