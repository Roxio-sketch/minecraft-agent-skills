# 飞行视角与第一人称流光

两种飞行默认视角均为第三人称后视。背包 → 设置 → 界面显示新增境界御空/御剑飞行默认视角选择，支持第一人称、第三人称后视、第三人称前视。进入飞行时应用一次，途中 F5 仍可切换；退出时恢复进入前的视角。

境界御空第一人称特效新增独立保存开关，默认开启。它只控制自己的第一人称流光；第三人称世界特效及其他玩家效果不读取该开关。已有全局境界御空特效开关仍保留。

第一人称不再绘制自己的历史世界拖尾。替换为固定在视野两侧和下缘的连续流光：八条光带、三层柔光与细芯、动态亮区，保持中央观察区域清晰。流光的起点和方向直接使用当前画面坐标，不使用历史采样点或转向平滑，因此不会在转弯时等待旧轨迹，也不会把身后弯曲拖尾显示到眼前。御剑第一人称也采用同一套视野流光。

第一人称御剑镜头从剑面站立点沿剑的局部上方向计算眼睛位置，随俯仰和横滚移动，取消第三人称的距离/螺旋抬高偏移；横滚与实际剑面一致，仍保留观察方向。第三人称模型与真实世界轨迹保留。

第一人称流光每帧一个绘制批次、2688 顶点，无体积步进及轨迹缓存。御剑第一人称停止本地历史采样与不必要的拖尾深度拷贝。隐藏 HUD 时仍显示流光；背包或其他界面打开时暂停该覆盖层。

验证范围：真实服务端批准的北斗剑飞行；第一人称开/关、转向、剑面镜头位置误差小于0.0001格；化神、炼虚、地仙昼夜第一人称画面。测试文件沿用旧的native/post/side/front名称，第一人称实际绘制的是新覆盖层，不能据此宣称三条旧世界拖尾路径仍在第一人称绘制。外部光影包未启用。
