# 境界御空流星特效：最终交付

交付时间：2026-10-08。最终版本是单束羽流；早期椭圆罩、多股平行光带与旧截图均不代表此版本。

## 最终行为

- 人物和装备保留。移动时沿实际速度方向横飞，悬停回到直立姿态；低境界巡航也能进入横飞。
- 尾部只有一个共用中心的羽流。外围薄光、主体和内部短亮丝是同一束尾焰的材质层，不再分别绕人物偏移成三至五条拖尾。
- 身周使用三维程序密度积分。厚光面、前端封闭罩与整团鼓胀被移除，改为有缺口、向后流动的辉光和短亮峰。
- 头部和尾焰均使用 GLSL；没有用一张流星图片替代玩家或技能效果。
- 尾焰沿 20 Hz 世界轨迹生成，最多保留 48 个样点；转弯保留原位置，沿曲线重新计算弧长。巡航最大截取 18 格，疾行 36 格，实际尾长由已移动距离决定。
- 停止、退出时旧尾焰在约 0.9 秒内消散。传送、换维度和异常位置会断开路径。
- 第一人称隐藏本地自身的能量几何；其他御空玩家仍可见。旁观者使用原版飞行偏好时也不会让远程玩家的技能特效消失。
- 共享浮点发光缓冲、深度约束泛光与场景深度裁剪保留。Bloom 合成增益为 .62，避免白光盖住玩家和内部层次。
- 高质量头部预算为最近四名玩家；更远处降低积分样点。轨迹实例上限 32，128 格外不绘制。

## 独立 Minecraft 实机验证

Forge 1.20.1 / 47.4.10，Java 17，RTX 4060 Ti。测试使用独立生成的世界，没有操作用户正在运行的游戏或存档。

| 环境 | 结果 | 证据 |
|---|---|---|
| 普通 Minecraft 渲染 | 22 个场景通过，GL 错误为空 | `final-normal/meteor-client-result.json` |
| Oculus 1.8.0 + Embeddium 0.3.31 + 实际启用 Solas V3.7b | 22 个场景通过，GL 错误为空 | `final-solas/meteor-client-result.json` |

场景涵盖悬停、巡航、疾行、转弯连续帧、远处旁观、实际本地第一/第三人称飞行、侧后观察、四名同时御空、夜间、退出淡出、石墙遮挡、资源重载、窗口尺寸变化，以及关闭自定义泛光后的形态对照。

四名远程人物是独立测试客户端中的观察实体，使用真实生产渲染器和 20 Hz 轨迹；这证明多对象绘制，不等同于四台联网客户端的完整联机压测。普通环境的后期场景还强制验证了深度合成入口；Solas 场景使用真实光影检测，不依靠强制标志。

记录的整客户端 FPS 受 60 帧上限约束。Solas 的本地第三人称与四人场景采样均约 59–60 FPS；这不是 GPU 独立计时，也不代表任意硬件或任意光影。Solas 白天浓雾会降低远处蓝色尾焰的对比度；关闭自定义泛光的远距图专门保留了此情况。

展示优先使用 `final-solas/captures/22-local-third-person-oblique-side.png`，该图是实际本地御空玩家和实际夜间光影的游戏截图。转弯动画由原始游戏帧编码，没有重新绘制特效。
