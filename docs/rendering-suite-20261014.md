# Minecraft Rendering Suite · 2026-10-14

公开完整的 Minecraft 渲染与特效开发集合，并把五行仙途中的相关优化经验整理为可复用维护资料。

- **23 个渲染/性能 Skill**：天空与天气、体积云雾、黑洞/白洞、Cosmic 材质、彩色 glint、碎晶折射、玻璃边光、Halo、原画线稿、物品内三维场景、局部异空间/区域材质、动态照明、选择性 Bloom、粒子、闪电、护盾、拖尾/光束、动态模型材质适配和体积性能优化。
- **32 个工作台/预览/研究入口**：完整总入口自动选择本机空闲端口；包括异火、炼丹炉和御体护纹的项目专用工作台。研究页面与游戏运行库分别说明。
- **18 组开发源码目录与 51 组五行仙途记录**：保留原验证范围、失败尝试、性能测量及视觉限制。
- **最新 Photon 自动化 Skill**：与既有 AXO 启动器一同保留，仓库总计 25 个 Skill。
- **中英文说明与公开维护依据**：完整功能目录、安装步骤、来源许可、验证证据、贡献说明、API 维护计划及申请填写稿。

## 下载

- `minecraft-rendering-suite-20261014-source.zip`：整个仓库的源码、Skills、工作台、模型、文档与记录，保持 `skills/` 和 `rendering/` 同级。
- `minecraft-rendering-suite-20261014-skills.zip`：25 个 Skill 的完整安装资源；其中 23 个为渲染/性能方向。
- `SHA256SUMS.txt`：发布包哈希。

完整源码解压后，运行 `python rendering/启动全部工作台.py`。需要 Python 3.10+ 和支持 WebGL2 的现代浏览器；Forge 工程主要面向 Minecraft 1.20.1 / Java 17，具体依赖及项目专用适配见说明。
