# 全天空材质与光影扩展

2026-10-06。本项目已完成研究后的第一阶段实现：原创解析大气、晨昏晚霞、程序太阳/月面/月相、动态远景薄云，与原程序宇宙共用 GLSL、工作台和 Forge 1.20.1 入口。

工作台升级为 0.4.0、`cosmic-sky/3`、90 参数、13 预设；新增晴空、晚霞、暮光、月照薄云、阴天和昼夜轮转。桌面两个启动器均指向最新工作台。动态云形、月相、日周期、GPU uniform、重载与遮挡已有独立实机证据，见 [当前验证](cosmic-sky-lab/VALIDATION.md)。

研究资料保留 **15 来源、12 方向、178 源码定位**，离线资料库区分已实现与研究方向。体积云、天气风暴、双虹、雾、地形云影与特殊维度仍为后续路线；22° 冰晶晕仍是依据缺口。普通月亮外晕与云银边不等于冰晶晕。

当前大气是艺术化解析近似，薄云是有界二维远平面，自动昼夜不改变 Minecraft 世界时间/照明。后续世界体积云与空气透视需要额外位置、深度和合成入口，不能只增加方向参数假装完成。

原始参考代码、纹理与论文只留在研究目录，原创交付与 skill 不携带它们。参考渲染器静态研究和本项目实际 GPU 验证分开记录。

来源及完整结论见 [全天空研究报告](research/sky-materials-20261006/README.md)，机器可读索引见 [catalog.json](research/sky-materials-20261006/catalog.json)。
