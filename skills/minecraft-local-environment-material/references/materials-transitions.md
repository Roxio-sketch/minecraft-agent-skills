# 材质家族与区域过渡

## 材质接口

将区域和材质分离，材质函数只消费明确的 SurfaceContext：`PworldRelative/Pmaterial, normal, viewDirection, baseColor, albedo?, lighting?, category, time, seed, footprint`。返回 `replacementColor/albedo, emission, opacityPolicy, optionalDistortion`；现阶段不移动真实几何。缺少输入时选择有声明的近似或要求增加捕获。

区域覆盖 w 与材质算法分别计算：`out=mix(base,material,w)`。不同区域重叠时以明确优先级进行累积或预先决出 winner；后一个区域外必须沿用前一个结果，不能重新输出最初 sceneColor 擦除前一区域。

将像素位于球内与相机视线穿过球分开：本任务是原表面位置归属。若要球内雾遮挡球后场景，应另做射线区间积分，不能混在表面覆盖公式里。

## Cosmic 迁移的两种诚实路线

1. **保留 Avaritia 风格方向层**：复用已研究的星体多层方向场与 sprite/强度约定；改为环境可见表面/世界范围控制覆盖，去掉物品专属 transform、GUI scale 和物品 mask 假设。方向以明确的世界旋转/相机射线产生，不能再无条件叠玩家 yaw/pitch。该路线有“世界表面是宇宙窗口”的视觉，不等同世界粘附纹理。
2. **世界粘附 Cosmic**：稳定的三维噪声、世界网格星点或三平面投影与 normal 权重构造新星空场。相机变化只改变可见位置，不重排星点；适合草地、墙面、楼梯连续被材质化。它是原创变体，不声称逐像素复现旧 Avaritia。

原物品 shader 的 mask.r 决定模型覆盖；环境中的 w 来自区域与 category/coverage，不能把地形纹理红通道误用成整片环境资格。若保留星体 atlas，重载刷新 UV 或使用独立纹理表，不能沿用旧物品图集句柄。

材质构图尺度以方块单位/局部基定义。世界球面映射需要处理原点和经度接缝；三平面各层避免明显轴向重复。远处亚像素星点用导数过滤/低频质量档，不靠强闪烁补偿。

## 可替换的材质家族

| 主题 | 表面算法方向 | 所需信息/区别 |
|---|---|---|
| Cosmic | 方向星层或世界锚定星点+星云 | 指定锚定语义、尺度、图集/程序混合；不只是彩色噪声 |
| 水墨 | 世界纸纹、墨块密度、笔触方向、轮廓/法线明暗分段 | 后处理边缘要处理轮廓深度间断；保留主形与留白 |
| 虚空 | 暗底、细裂隙、少量边缘发光、低对比空间扰动 | 定义保留几何辨识度；纯黑会消除表面形体线索 |
| 熔岩 | 稳定岩壳/裂缝场、内部流动发光、温度 palette | 纹理流动与区域扩散独立；发光不自动照亮邻近方块 |
| 冰晶 | 结晶 cell、晶面法线、rim、受控色散 | 场景折射需要独立颜色输入；几何替换不是必要条件 |
| 时间流 | 沿世界方向/路径的相位带、停滞纹理、扫描层 | 真正回显过去的世界需历史缓冲/重投影与失效逻辑；不能叫噪声滚动“时间回溯” |
| 灵气 | 有方向的纤维流/脉络、稀疏光点、低频脉动 | 粒子/轨迹仅作伴随；表面仍由区域材质函数承担 |
| 腐化 | 多尺度侵蚀场、表面脉络、稀疏斑块、边界推进 | 每点稳定 seed；避免每帧重新随机导致整片跳动 |

这些是算法选择蓝图。随附原理核仅实现 Cosmic、水墨、熔岩的简化样例，不将其余名称当作已存在的 uniform 配方。

## 过渡由影响场定义

- **扩散/收缩**：`radius = radiusCurve(ageSeconds)`；球体或路径宽度变化。把 grow/hold/shrink 用同一时钟求值，暂停和低 FPS 不改传播速度。
- **溶解**：对稳定 noiseField(P,seed) 用随时间变化的阈值，结合范围 support；不把 time 加入随机 seed。
- **侵蚀**：`dEffective = dBase - frontOffset(age) + amplitude*noise(P)`；显式区分表面传播和空间距离传播。
- **波纹**：用 `sin(k*dBase - omega*t)` 或世界径向距离构造带状权重，仅在 support 内生效；不是修改原顶点高度，除非任务要求。
- **边缘发光**：独立 edgeEmission，按 `abs(dEffective)` 距边界强度；Lodestone 的 ring/sphere 只做外观伴随，区域资格仍由世界场计算。
- **扭曲**：优先扭曲内部材质坐标；只有要折射真实背景才偏移 sceneColor UV，并对取样目标深度/类别/区域做保护。不能把区外建筑拖进区域而还声称严格保留位置。

多 pass 推荐顺序为替代材质 → 受控边缘 emission → 降采样 bloom → 合成。是否允许 bloom 越过原半径要在设计中说清；严格“范围外像素不变”时必须裁剪最终 bloom，视觉会与物理散射不同。

## 五个任务的实现选择

| 用户任务 | 应选择 |
|---|---|
| 玩家中心 20 格逐渐星空化 | Region 玩家锚点插值，r:0→20；A 地形或 B 全部入选类别；材质原点释放时固定/世界固定 |
| 剑气路径地面临时水墨 | 带时间戳 capsule chain + 地形分类 + ground predicate；局部段龄消退，保留正常实体 |
| 指定球形范围进入虚空 | 固定中心与 radius、类别列表；暗材质保留必要 normal/边线，不创造替代世界 |
| 只影响方块 | 普通地形用 A；箱子等 BE 按白名单额外适配；水/玻璃是否包含由规则明确 |
| 命中点向外侵蚀 | 锁定 hit location、法线与 seed；扩张前沿+固定噪声，暂停/重载后按定义继续或停止 |

收到新自然语言需求时按这些决策生成设计，而不是要求用户填完整 shader 参数。调试阶段先用红色平面替代，确认空间/对象正确后再制作视觉。
