彩色原画线稿

用多尺度结构线与深度边界提取画面，再用一条连续的屏幕空间渐变为线条着色。

实时预览 · 与 Forge 使用同一片元着色器
输入：Minecraft 场景截图预览缺少真实深度；深度轮廓仅在游戏内生效
画面留白由线条强度控制。色彩只赋予线稿，不覆在原场景颜色上。
01 / 渐变设计

色标位置必须从左到右递增；首尾固定在 0 和 1。

02 / 线稿质感

放入实例的 local-environment-lab/presets/one-last-kiss.json，游戏里执行 /localmaterial sketch reload。
