# 粒子表面、坐标与结果状态

地面图案使用世界地面平面；方向薄片使用指定方向与视线构造基；普通billboard使用相机基。方向与视线平行时选取与主轴不平行的备用轴，不能固定某个也可能平行的世界轴。尺寸、旋转、透明度和寿命独立于运动模拟。

在实体dispatcher已经平移到插值实体原点时追加附着火焰，复用该PoseStack而非第二次减相机。这能覆盖未触发RenderLivingEvent的自定义实体renderer；真实入口仍须按目标版本验证。图集sprite已经应用配色时不要再次染色；资源重载重取sprite，缺材质限频报告。

方块破坏碎屑按实际成长形状或碰撞形状取采样域，避免小植物爆出整立方体碎屑；空形状需回退或跳过。少量原版粒子足够表达的状态不必增加整屏后处理。

失败、成功和取消按真实宿主结果分别选择发射器，失败烟雾不自动继承成功光环或悬浮产物。状态结束停止出生，已出生粒子按自身寿命消散。此原则不包含宿主炼制、伤害或奖励规则。
