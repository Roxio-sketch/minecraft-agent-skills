# 全场景原画线稿管线

## 从静态修图到实时画面

参考文本描述的灰度、反相、颜色减淡、模糊、对比度、全图渐变是静态图层工作流。实时渲染不需要照搬每个 Photoshop 图层。保留它的**视觉约束**：大面积白色、选出的结构线、少量调子、连续暖冷渐变。分阶段采集当前游戏帧，再用可调的多尺度亮度与深度边界计算线条强度。

单纯 Sobel 只在一个尺度比较相邻像素，容易把树叶与砖纹的每个 texel 变为杂线，也会漏掉同色表面的形体转折。此预设使用九采样 Gaussian 近似，在两种半径分别取亮度；较粗尺度与较细尺度的暗脊差强调大形，原色结构梯度只作为弱补充。对少量真正很细的暗线，再比较原像素和粗尺度亮度。深度差补足遮挡边界，深度斜率变化补足颜色接近的方块转角；远处使用相对差，而非一个固定原始 depth 阈值。保留少量低频暗部作为铅笔调子。

**不要把抑制噪声和删除轮廓混成一个阈值。** 在实心方块后、cutout 方块后和完整世界后分别保存深度。若 cutout 深度比实心深度近、且完整世界的深度仍等于它，只能判断该像素由 cutout 阶段写入。原版 GRASS_BLOCK 和 LEAVES 都使用 cutoutMipped，禁止据此直接认定为树叶并删除结构线。另以半分辨率覆盖图聚合大尺度树冠边界，避免整棵树消失。实体、手部覆盖深度时不能继续用下面的叶片类别。法线、物体 ID 和完整透明层信息并不会从这些深度图中自动出现。

输出 `mix(white, gradient(screenUV), ink)`。不是把彩色纹理覆盖在原场景上；原物体颜色只参与线条发现，最终线色来自整幅视野的渐变。需要世界固定渐变时改变锚定契约，并验证镜头移动，不把这两种需求混淆。

## 数据流和顺序

Forge 1.20.1 原版/Fancy 路线：

1. `AFTER_SOLID_BLOCKS`、`AFTER_CUTOUT_BLOCKS` 取得类别判定所需的实心与镂空深度；`AFTER_LEVEL` 保存含实体、透明层的世界深度。
2. 随后 `GameRenderer.renderLevel` 清深度并可画第一人称手部；在它结束时保存场景颜色和手部深度。
3. 半分辨率 pass 聚合镂空覆盖；最终 pass 按手部/世界深度、类别、颜色结构和覆盖图计算线条。所有采样都来自独立目标，只写主目标颜色。
4. HUD/聊天/界面后续再绘制，保持清晰可读。第三人称玩家属于第 1 步的世界实体；第一人称手部属于第 2 步。

这不是对象材质重写：水面的原有透明混合已进入场景颜色；后处理只风格化最终可见的结构，不提供每层透明材质的独立编辑，也不凭空增加原版水没有的物理折射。若需在流体阶段替换水本身的材质，转用局部环境材质 Skill 的透明几何适配。

当前原型对 Embeddium/Oculus/Rubidium 禁用；Fabulous 也回退。未知 Shader Pack 可能移动 framebuffer、改变深度、添加 TAA 抖动、自己输出线稿/折射；必须重新验证采集时点、主目标身份、附件样本、颜色空间和状态恢复。不要仅按 Mod ID 推断通用兼容。

## 可调参数

五个色标按 0 到 1 严格升序，首尾固定；`angleDeg` 定义屏幕渐变方向，`scale` 控制跨度，`offset` 平移。线稿参数是 `edgeSensitivity`、`detailSuppression`、`depthStrength`、`shadeAmount`、`lineWeight`。JSON 须验证 schema、色值格式、有限浮点数和范围；错误文件应保留旧配置并拒绝激活/重载，不默默接受半份配置。

权衡：增加纹理抑制可让草叶更干净，但会损失细小栏杆/面部纹理；增加深度边界能恢复遮挡轮廓，却不能识别所有共面接缝或本来没有深度差的材质边界；增加调子会减少白色留白。面对用户指出的断边，先将问题分为：深度边界漏检、同色转角、共面材质接缝、透明覆盖、镂空抑制过强。前两类可调相对深度差/斜率变化；第三类先检查 RGB 色差（等亮度不等于同色），无可见色差时再考虑材质或几何辅助缓冲；透明层需要按真实绘制阶段另采信息；最后一类要把宏观覆盖与局部叶片分开。不要简单把全部颜色阈值降低。多次采样有屏幕像素成本；高分辨率时优先考虑半分辨率结构缓冲、分离模糊和明确的质量档位。


## 2026-10-02 草地方块漏边修复

旧版本把整个 cutout 阶段当作树叶，错误压掉草方块台阶。这是分类缺陷，不能归咎于“缺少法线所以无法画边”。先查原版 ItemBlockRenderTypes 和实际遮罩可视化，再改阈值。

当前半分辨率结构图的 R 是渲染阶段覆盖，G 是放大 16 倍的多尺度色差，B 是世界深度边界/斜率变化。最终 pass 检查四个方向、两种距离的线条支持，并扣除各方向都有的密集响应；以此恢复连续地形线，同时限制碎纹。色差分支补灰度接近的草/泥土交界。局部深度支持用于减弱零碎候选，不能充当精确叶片 ID。

这仍是屏幕空间启发式：低分辨率树叶和斜线仍有碎纹、浅线，不能承诺所有边缘完整，也没有实现时域稳定。若需要严格的叶片排除或高质量细线，应在真实几何阶段生产叶片类别及法线，而不是继续把 RenderType 当材质 ID。

诊断命令 `/localmaterial sketch debug 0..6` 分别显示正常结果、色差、方向支持、色差线、稀疏 cutout 候选、阶段覆盖、经过抑制的色差线。退出诊断必须设为 0。工作台不生产这些真实深度/结构缓冲，仍只验证配方与基础预览。


## 后续轮廓精修：坡面、碎纹和斜线

非线性深度的一阶差分不能单独当作线条：倾斜平面投影后也有连续梯度。当前以相邻样本的二阶差（深度斜率转折）作为结构响应，取消独立的一阶差分着墨。半分辨率 B 通道和最终轮廓使用相同的转折判据。

连续性检查需要给斜线留出横向容差：沿四个候选方向，在两个距离取窄带最大响应；只沿数学中心线采样会把斜线变成虚线。再以周围结构响应密度抑制叶片密集区域，避免相邻碎线误组成长线。R 通道改用 7×7 加权覆盖采样，消除原来九个远距采样产生的梳状不连续；低覆盖等值线用于简化外形，可能产生轻微圆化或双轮廓，不等于精确几何边界。

854×480 和 1280×720 的开发阶段图为 refined-small.png、refined-large.png；正式 JAR 重启结果另行保存。参数仍控制相同的渐变与线稿配方。当前没有时间累积、运动矢量或真实材质 ID；移动中亚像素线仍可能闪动。窄带和密集覆盖增加采样成本，不能将截图通过当成 GPU 性能预算通过。

## 当前硬线稿输出（用户要求清晰、无圆润线条）

已移除“覆盖图等值线直接着墨”：该路径会移动真实边界、把方块角部画圆并形成双轮廓。最终几何轮廓只由全分辨率深度斜率转折产生，半分辨率结构图仅辅助连续性/密度判断，不将模糊后的形状描回画面。颜色表面暗纹压至硬线阈值以下，色差只作弱补充；天空和工作台保留颜色结构回退。

线条覆盖通过 smoothstep(0.16,0.55,drawing) 收紧，降低模糊的低强度边缘；渐变色经过 1.25 次幂加深，少量背景明暗降至原来的 35%。这不是对最终图像做锐化/高斯模糊或圆形扩边。用户选择的色标仍控制渐变，但输出线色有此加深映射。

取舍：更少的表面纹理细节、更硬的像素线；亚像素锯齿、少量断线和运动闪动仍可能存在。不要为了遮盖这些问题重新加入圆润的模糊轮廓；真正的抗锯齿或时域稳定需要单独设计验证。

## 短缺口与有限边缘覆盖

当前 Forge 原型在完整分辨率的深度斜率转折线上，用局部深度梯度估计切线。仅当中心线弱、附近结构图有响应且切线前后约 2 像素都存在转折时，补入中心短缺口；没有两端支持便不延长端点。对切线方向再给 1 像素横向容差，以免斜线经过采样网格时丢失。周围密集响应与 cutout 阶段抑制仍参与筛选。

在同一候选位置，仅沿法线采样两侧的转折，给边界一层低强度覆盖（线芯保持原全分辨率强度）。这是局部、当前帧的屏幕边缘覆盖，没有时域累积。854×480 固定地形视角的旧/新着色器 A/B 图在 `assets/evidence/bridge-before.png`、`bridge-after.png`；候选边缘覆盖图在 `bridge-aa30.png`。代表性地形 ROI 中，强线像素从 5176 增至 6899、没有旧强线跌出阈值；加入边缘覆盖又增加 396 个弱线像素。该统计只描述该视角的图像差异，不能证明所有断线消除或动态抗锯齿稳定。

水面、叶片若需严格的对象类别和自身表面轮廓，按 [水面与树叶专用线条方案](water-leaf-lines.md) 扩展渲染数据。不要把现有 cutout 密度和最终世界深度冒充精确叶片/水面 ID。
