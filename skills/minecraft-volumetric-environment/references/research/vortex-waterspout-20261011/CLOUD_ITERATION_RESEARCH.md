# 龙卷云体质量迭代：密度、运动和照明

## 当前基线的问题

已查看实际工作台截图 `volumetric-environment-lab/evidence/vortex/mode-1-time-20.png`，并读取 `workbench/vortex/volume-core.glsl`。截图里是一整块浅灰顶帽、渐细漏斗和几乎圆形的白色水环；没有运行原版 Horizon、Houdini 或新的 Forge 后端。

以下是对本项目代码的判断，不把它们归因于任何资料原作者：

1. **云体没有足够的空隙。** 漏斗与顶云密度都保留 `.08` 底值；螺旋权重还保留 `.40` 底值。即使噪声没有形成云块，整个解析包络仍持续积累光学厚度。将三倍密度再调高，会更容易获得结实圆锥，难以获得翻卷云团。
2. **形状尺度没有分工。** 当前三层值噪声主要调整漏斗半径和内部灰度；顶云仍是径向函数加垂直高斯。它的巨大平滑外形先于噪声细节主导视觉，所以增加 turbulence 也只是毛边的蘑菇帽。
3. **自遮光可严重漏采。** `veLightTransmission` 把光射线贯穿整个半径 150 的支撑柱后，按 `LightSteps=4` 等分。窄漏斗的局部实体可能只有十几单位宽，但首个中点已在数十单位外；四点都落空就会返回接近 1 的透射。这个问题来自采样距离与实体尺度不匹配，不是密度太小。
4. **环境光不看云内深度。** 当前环境项只由世界高度调整。位于巨大顶云中心和接近外沿的两个样本，即使粗高度相同，也得到相同底光，厚云的受光块和暗缝就会被填平。
5. **规则条纹替代了卷云。** 正弦四臂和固定高度相位很容易成为四条均匀装饰带。真实可辨识的视觉需求是相互剪切的大块、薄丝和裂隙；四臂可作为流向引导，不应承担主要云体形状。
6. **通过测试不代表成片质量。** 编译成功、零密度恒等、参数改变像素和 JSON 重放都是必要的合同检查，但不能证明云有体积感、漏斗不似网格锥或水环不似霓虹圈。

## 当前 WebGL2 的优先实现方案

下面的数值与公式是针对本项目的原创提案，未复制参考讲义代码。

### 第一优先：把太阳光的近处密度采到

先保留 `scene*T+L` 和原积分形式，只改累计密度的采样。对每个非零视线样本，把光程分成两个区间：

- 近场长度取漏斗局部半径与云块尺度的函数，约 12–28 个世界单位；用 4–6 个短区间积分，首个采样不应远于局部云体宽度的四分之一。不能把近场跨度继续等同于整个 Bounds。
- 远场剩余段用 2–4 个较粗区间；若要用粗密度，它必须反映云帽和相邻云块，而不是默默丢掉这段光程。后续才考虑预计算纹理。
- 每个密度点都乘其真实区间长度，先累计光学厚度，再取 Beer 透射；密度已足够遮蔽时提前结束。
- 首轮固定 8–10 个太阳光样本比较容易调正确。不要只提高原等距采样上限，却保持超大的首步。

对弯曲漏斗可以先计算保守包围体进行截断；如果没有真正保守的距离函数，不使用冒充 SDF 的径向值来跳过空间。弯曲轴、噪声偏移和侧向云块都可能使这种值高估到云体的距离。

验收重点：取一个漏斗内部非零点，在太阳侧存在近处密度时，改变支撑柱半径不应让它突然变成完全受光；移动点位置不能出现四个远端光样本引起的大片明暗翻转。

### 第二优先：云块实体与边缘细节分开

把密度内部拆成 `body / coarseProfile / detail`，不要用一条固定圆锥的密度底值填满全部支撑：

- 弯曲轴与半径轮廓提供目标构图；粗形状再叠加少量偏离轴线的云块和不对称半径变化，使主漏斗也有凸起、断续边缘与厚薄。
- 粗噪声只用低频，决定哪部分真正存在。允许低密度区域为零，保留密度较高的核心。
- 中高频只在边缘有明显侵蚀权重；厚核心的权重较低。这样能获得硬度适中的云块外形而不会把内部细节也掏空。
- 顶云改为多个重叠的扁椭球/偏斜云块包络；以大尺度密度变化形成块间暗缝，别把顶云整体设成一张高斯盘。
- 龙吸水的凝结柱可比陆地黑云窄而平滑，但底部喷雾应是另外的碎雾体，不能把所有密度乘同一个漏斗遮罩。

一种简单的原创形状关系为：`solid = clamp(profile + broadVariation - threshold, 0, 1)`；`edgeAmount = pow(1-solid, p)`；`rho = densityScale * max(solid - detail*edgeAmount*erosion, 0)`。这是概念说明，实际阈值要根据所用噪声分布调整；不借固定正底值掩盖分布问题。

### 第三优先：环境光与内部深度相关

粗包络在密度采样时一并返回，避免每个视线点重复算多套噪声。环境项可先用粗内部深度构造有界衰减，保持少量底光，轮廓仍可读；顶部遮挡较强的样本进一步降低环境贡献。太阳直射与环境光各自调节，别把顶云整体涂黑来伪造自阴影。

随后才增加很弱的多次散射近似：来自太阳的累计密度给出透射和柔和填充，填充在厚实体里比单次项衰减慢，但以明确的小权重控制。它是外观近似，不是真正的多次路径追踪。避免高强度填充再次把每块云刷成同一灰度。

### 第四优先：差速旋转与上升要呈现为结构运动

保持时间由秒数决定，固定时间可重放。使用半径连续变化的角速度，加入高度偏斜和低频时变偏移，噪声坐标仍按逆向流映射；正反转符号应实测。绕弯曲轴旋转、上升和向心聚集分别调节。

不要添加不可重放的每帧随机噪声。若需要抗欠采样抖动，先使用固定像素/种子的空间偏移；动画抖动会引入新的闪烁，需要实际序列比较。当前工作台没有历史重投影，不直接搬用生产项目依赖该缓冲的参数。

### 性能后续：原创体积噪声纹理

当密度/照明结构已成立，可在启动时生成自有 64³ 或 96³ 可平铺噪声纹理并以 WebGL2 三线性采样，减少视线和光线内大量哈希计算。RGBA8 的 64³ 四通道约 1 MiB，可分别保存低频实体与高频侵蚀。生成器和噪声均由本项目编写，不引入 Nubis 的纹理或示例源码。

这一步是性能选择，不应被当作视觉改善的前提。低频、中频与高频的作用若没有区分，换纹理采样后仍是雾锥。

## 本轮应追加的验收

- 固定相机分别看成熟漏斗、近处喷雾和顶云底部；以相同时间对比旧图和新图。
- 单独关闭太阳、关闭环境、关闭顶云，验证主云体确实由对应分量组成，而不是背景换色。
- 视线步数、光线步数减半与提高时，不应改变整体外形或使漏斗换成另一种明暗；对窄核心和云帽分别检查。
- 低密度仍可读结构，高密度产生暗厚块但不是无细节的实心锥。
- 至少检查三个成熟时间的静帧以及一段连续运动，区分形状变化与仅在体内滑动的纹理。
- 零密度仍是恒等；有限域、深度截断、固定时间重放、导出/导入继续有效。

本报告只提供研究与建议。具体哪项已实施以及质量如何，应以新的代码、实际浏览器截图和验证报告为准。
