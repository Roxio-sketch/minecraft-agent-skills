# 宿主体积环境合成顺序

体积云与闪电共用延后合成桥时，先保存正确世界相机和不透明深度，再在外部光影最终颜色已准备后取颜色快照。不得将阴影投影或已被GUI替换的投影用于云雾射线。读输入纹理与写输出附件分离。

背景体积、背景闪电和前景拖尾/装备效果有依赖顺序，不能仅靠各自注册 RenderGuiEvent.Pre 的偶然顺序。宿主可提供显式flushBeforeForeground，在绘制前景效果前提交待处理背景队列；HUD隐藏时仍有RenderTick END路径，避免F1使云或闪电消失。

临时替代原版云时保存原设置、仅在需要时关闭，并在事件结束/世界退出恢复。选项回调可能清空Fabulous目标，保存并恢复其FBO/viewport。不要将临时显示策略持久写成用户永久设置。

多个云事件需要明确选最近、统一预算或逐区域合成；代码只选一个区域时不宣称任意多区域同时显示。相机入水、外部管线检测失败、视口非主目标和资源异常分支应列入支持范围。

这些是宿主适配经验，随附基础模板的避让策略不因此升级为通用Oculus兼容；真实场景的颜色、深度、相机运动与F1必须独立验证。

## 移动云体与历史尾迹

云体、相机、包围体和逆矩阵使用同一重定位原点，以CPU double减共同原点后上传float；周期噪声相位另以原世界位置取模，避免跨重定位边界时图案跳变。只有原噪声所有频率确有整周期时，取模才保持等价。

实体云体中心使用相同插值时刻的位置，历史曲线只更新活动端，旧控制点保留世界位置。加速后的密度拉伸选用单调逆映射，避免形变折叠；它是风格化运动场，不等于流体模拟。

多包支撑沿射线的相交区间可先排序合并，跳过真实空区间；重叠密度应按原场规则计算，合并区间不意味着随意把密度取MAX。体积输出预乘辐射时若使用SRC_ALPHA混合，先还原直通RGB；否则会重复乘alpha使白云变暗。scene*T+L合成则保持预乘辐射，两种合同不要混用。
