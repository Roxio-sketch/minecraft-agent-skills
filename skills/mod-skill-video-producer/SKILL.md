# Mod 与 Skill 演示视频

交付能说明作品用途、外观差异、自定义能力及使用入口的真实演示片。沿用可用的工程、录制桥和工具；不要为每期重建整套流程。

## 需求与证据

先定位源码 / Release、可运行实例、现有素材、剪辑工程及音频工具。用户已经选择的音色、BGM、分辨率和发布方式继续生效。未知信息优先从文件和现有工程发现。

将功能整理为“功能 → 演示动作 → 参数 / 对照条件 → 镜头 → 旁白 → 验收证据”的覆盖表。参考 [references/production.md](references/production.md) 和 `assets/shot-plan.example.json`。每个主要能力要有可见证据：支持两种形态时都展示；范围、主体参与开关等分别做对照。不要以参数标签代替实际效果。

## 素材与录制

- 优先实机截图 / 录像；游戏 framebuffer 或应用窗口捕获可减少桌面遮挡。明确实际捕获方式和范围，只有验证后才能断言弹窗不会进入画面。
- 在专用存档或隔离开发副本中录制。必要时按用户授权适配录制 UI、相机或参数调度，不擅自把演示适配合并到发布源码。
- 锁定可比较的视角、背景和非目标参数；对照镜头只改要说明的因素。特效瞬时事件可固定 tick 做调参展示，但另保留实际动态镜头，并记录差异。
- 先录一小段并检查原尺寸。主体完整、UI 不遮挡、清晰度合格后再批量录制；窗口大小不是已导出视频分辨率的证明。
- 没有好素材时补拍。不上虚构画面，不把后期画出的效果说成 Mod 的能力。

本机旧工程与 MamboTTS 的入口见 [references/local-project.md](references/local-project.md)。录制桥是该项目的实例，不是通用 Minecraft API。

## 剪辑与声音

- 脚本按观看顺序串联：吸引人的效果 → 能改什么 → 有意义的对照 → 实际操作 → 使用与开源入口。相近功能连续安排，避免中途重复回到同一主题。
- 旁白使用衔接自然的完整句子，不逐条机械朗读字幕。先以未变调的原速试听确定音色，再生成完整音轨；不保证社区音色等同某商业软件的同名音色。
- 用户已选择的配音方案无需重新询问。若尚未选择，先出无配音版；需要登录、凭证或用户操作的步骤只在确有依赖时提出，继续完成其余工作。
- 按音频实际时长调整镜头或分句，避免大量加速来挤入窗口。保留原始旁白、文案、字幕与模型 / 引擎来源，必要时用识别检查漏字和错读。
- BGM 在旁白期间适当压低；按实际许可证记录署名、来源、许可与修改。新选择音乐时核对可用性和授权，不复制本实例音乐作为 Skill 资产。
- 现有 Remotion 项目继续按其结构剪辑，按需使用已安装的 Remotion 技能；如果选择剪映则使用可用的剪映接口，不假设国内版和国际版共享 API。

## 检查与交付

1. 覆盖表核对每个功能，查看每章代表帧及转场，确认素材加载、颜色、字幕、主体和 UI。
2. 用 `scripts/inspect_video.py` 检查分辨率、帧率、音轨、时长，按需执行完整解码。播放有旁白的段落，听取发音、衔接与 BGM 平衡；媒体元数据检查不能证明内容完整。
3. 字幕、旁白和章节时长均以实际媒体为准。沿用 1080p / 30fps 默认，但以用户指定为准；新成片默认 H.264 / yuv420p，兼顾清晰度与可播放性。
4. 输出成片、最终封面、标题、简介、真实项目链接和相关标签。推荐使用 `demo-cover-compositor` 完成封面；未安装时直接按用户确认的真实拼接风格制作。
5. 标题若用户选择 GPT 表述，用“我用GPT制作并开源了……”且如实描述开源范围；GPT 角标不是标题的必然附属。AI 声音等来源写入简介；平台标注按实际内容及当时规则核对。
6. 清理仅在用户请求时执行：保留成片、最新封面、文案、源素材及编辑工程，移除明确的旧输出和可重建缓存；本机删除优先回收站并记录清单。制作任务不包含自动发布、卸载软件或清理其他项目。

## 调用示例

“为这个开源 Mod 制作功能介绍，展示多形态与实际参数调节，使用现有音色，输出视频、封面与发布文案。”

技术检查命令（脚本路径相对于 Skill 目录）：

```powershell
python -X utf8 scripts/inspect_video.py --video 'E:\视频\exports\自定义黑洞与白洞-曼波配音版.mp4' --duration 246 --require-audio --decode --ffprobe 'E:\JianyingAI\tools\ffprobe.exe' --ffmpeg 'E:\JianyingAI\tools\ffmpeg.exe' --report 'E:\视频\maintenance\video-check.json'
```
