# 设计、算法与配方接口

## 描述到设计

| 用户描述 | 初稿决定 | 避免 |
|---|---|---|
| 清透冰晶、很细的彩边 | 大晶片、低 tint、无模糊、中等折射、小色散 | 所有面刷成蓝色而没有背景位移 |
| 破碎空间、星空被折断 | 中小晶片、明显晶面位移、固定星域对照 | 时间驱动随机重排晶片 |
| 琥珀刀刃、内部流光 | 窄覆盖、少量暖 tint、较少晶片、缓慢法线摆动 | 焦点落在剑刃 mask 以外 |
| 棱镜彩虹 | 增加 RGB 折射率差，先用黑白网格看彩边 | 把彩虹贴图叠上去称为色散 |
| 磨砂水晶 | 适量低成本柔化，降低高频星点 | 未测量就上大范围逐片元模糊 |

默认先采用物品内部背景；若用户描述明确要求“扭曲后面的树/地形”，选择世界场景路径。引用另一 skill 的 Cosmic 内核时明确输入坐标、颜色空间和采样责任；本技能不要求安装 Cosmic skill 才能工作。

## 原创内核

`assets/lab/crystal.glsl` 用固定 seed 的抖动网格构造二维 Voronoi 晶片。5×5 候选搜索返回晶片 ID 和 F2−F1 接缝近似。seed 和中心不随时间改变；每个晶片的法线方向按连续正弦轻摆。`fwidth` 在非一致分支前计算接缝采样足迹；它抗锯齿接缝，不保证背景高频纹理永不闪烁。

入射向量 I 与法线 N 位于同一示意空间，使用 `refract(I,N,1/n)`。红/绿/蓝分别用 n−d、n、n+d；将透射与入射斜率差换成纹理偏移，再分别取源图三个颜色通道。这是单界面薄层的屏幕投影近似，BendPx 是美术尺度，不是毫米厚度。RGB 折射率差不是 Abbe 数，底色也不代表物理吸收系数。

当前视角受限在 ±0.45，n 至少为 1，红通道 n−d 同样至少为 1；该受限空气到介质路径未提供全反射或二次出射。不要扩大成任意法线/任意视角而不增加无效折射向量处理。

输出先乘可调 tint，再加接缝亮度，最终按窗口与 amount 混合原图。这是在 RGBA8 演示颜色值上的美术处理，没有 HDR、场景照明、自动 bloom 或光谱能量守恒。生产管线如在线性颜色中合成，需要明确 framebuffer sRGB、解码与最后显示转换，不能重复 gamma。

## 实际读取的参数

| JSON 字段 | 范围 | 含义 |
|---|---|---|
| cells | 2–14 | 局部坐标频率；越大晶片越小，不是绝对片数 |
| jitter | 0–1 | 稳定中心的偏移量；0 接近规则网格 |
| bendPx | 0–160 | 以 600 高画布为基准的位移尺度；实际位移还受 n/法线影响 |
| dispersion | 0–0.15 | 红/蓝折射率相对绿通道的差；0 走单次无色采样 |
| ior | 1–2.4 | 基准折射率；无色散 n=1 时斜率差为 0 |
| bevelPx | 0.25–3 | 接缝近似宽度，不是实际几何倒角 |
| edgeLight | 0–0.3 | 接缝美术亮度；不是发光照亮世界 |
| tint / tintMix | #RRGGBB / 0–0.6 | 乘色和混合比例，与色散独立 |
| speed | 0–1 | 法线摆动相位速度，时间单位秒；0 静止 |
| blurPx | 0–3 | 五点十字柔化偏移半径，不是高斯标准差 |
| seed | 整数 0–65535 | 稳定晶片布局 |
| shape | 0/1/2 | 全幅/圆窗口/剑刃示意窗口 |
| background | 0/1 | 规则网格/原创静态星域 |
| time / view | 0–1e7 / 两个 ±0.45 数 | 固定时间和示意入射斜率 |
| debug | 0/1/2/3 | 正常/晶片 ID/接缝/位移 |
| amount | 0–1 | 配方的最终效果比例；原图按钮仅切换显示，不修改此值或导出配方 |

完整导出是 `{schema:"crystal-refraction-preview/v1",state:{...}}`。这不是 Minecraft NBT，也不是资源包标准格式。Forge 端需实现对应配置读取和 uniform 绑定后才有效。

“查看原图”只对大图、小图和 PNG 输出临时使用零效果；“返回折射”恢复配方原有比例，包括 0 和 0.4。对照期间导出仍保存原配方。导入配方、切换预设或调用 setState 会退出对照。播放到 time=10000000 秒会钳制并自动暂停，点击重置后可以继续播放；不会产生超过导入范围的时间。

预览根据画布高度缩放 BendPx/BlurPx，保持不同尺寸下相对位移；接缝宽度按输出像素估计。16/32 小图重新绘制源纹理和材质，不是大截图缩小。Forge 端应选择并记录“屏幕固定像素宽度”还是“随物体比例缩放”，不能混用。

## 预算与降级

内核每片元 25 个晶片候选；正常分色无模糊 3 次折射采样，有模糊最多 15 次，再加 1 次原图采样。无色散可减少为 1 或 5 次再加原图。编译器可能改变实际执行，以上是静态预算，不能换算为 FPS。

GUI 极小时优先保留大面折断，降低 cells、关闭模糊、减少色散；不要强行维持所有星点。场景纹理拷贝成本与晶片计算分开测量。可以缓存源图或同批共享快照，但顺序相关的透明效果不能随意合批。

## 原理定位

查正式定义时使用 Khronos 的 GLSL `refract`、`fwidth` 与目标 OpenGL framebuffer 规则；本页的 recipe 与薄层位移是原创美术方案，不是规范中的物理模型。依据当前 MC/loader 版本查注册 API，不能将 NeoForge 新版接口套入 Forge 1.20.1。
