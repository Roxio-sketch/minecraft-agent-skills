# 自由设计：从语言到轨迹、截面与材质

自由度来自可替换接口，不是固定颜色菜单。现有配方字段直接调；字段外的要求实现新接口，并区分本次完成与可扩展。

| 维度 | 选择 |
|---|---|
| 来源 | 刃根+刃尖扫掠、飞行物历史、骨骼挂点、即时端点束、任意曲线列表 |
| 主形 | 薄片刀光、相机光带、交叉光片、开口管；可扩展封端、多棱柱、分叉、扇面 |
| 宽度 | 任意沿程节点、收尾、鼓包；扩展速度/年龄/蓄力驱动函数 |
| 材料 | 任意 HEX 色带、纹理、发光核心+宽晕、双边轮廓、分节流纹；扩展星空、噪声、符文、侵蚀 |
| 动态 | 秒单位寿命、年龄消散、正反向流动、脉冲/等离子/符文图案、确定性分叉闪电；扩展蓄力、动作窗口与时序曲线 |
| 交互 | 动作/实体状态触发，游戏碰撞决定终点；伤害与命中由服务端独立管理 |

## 翻译示例，不是风格白名单

- **冰蓝薄刃、短刀痕**：blade 双挂点，alpha 外壳+细 additive 核心，短寿命和窄尾。
- **黑金符文持续束**：tube/cross，自制透明符文纹理+金色核心，低流速。黑色无法靠 additive 发亮，暗外壳用 alpha 或实体材质。
- **分叉红闪电**：`path.json` 选 lightning、设 seed/branches/branchLength；颜色和粗细由 recipe 单独决定。路径按时间切片更新，不在每 pass 重抽随机。
- **星空斩击**：blade 历史+Cosmic shader；宇宙方向与弧长纹理坐标分开，不能把滚动 PNG 称为 Cosmic。
- **追踪弯束**：Bezier/Catmull-Rom/自定义点列→弧长；模板接任意点列，不内置寻敌或伤害。

## 突破默认配置的方法

1. `Geometry.History.add(t,root,tip)` 接世界挂点；单点令 root=tip。使用目标动画系统，不强迫换模型。
2. `Effects.beam(id,recipe,List<V>,expiresAt)` 接任意路径生成器；更新同一 id 可实时追踪。分叉使用多个 emitter 或新 mesh。
3. `Geometry.Curve` 接 Java lambda，允许任意有限非负宽度函数；JSON 默认分段线性。
4. `Geometry.Vertex/Quad` 与 `BeamRender.draw` 分离，新的截面可直接输出 mesh。
5. `Paths.generate` 提供六种路径与可选分叉；`Effects.beam` 也接收完全自定义点列。`beam.fsh` 的七种 profile 是起点，不是 shader 创作上限。新增字段同步 schema、解析、绑定、工作台与检查。
6. 新混合、透明排序、bloom 和场景灯光可用专门 pass 扩展；不能仅加一个未实现的开关。

## 看图与调参

固定 t/seed 看主形和留空，再看远距离。分层观察核心、外壳、色带和纹理；分别观察路径运动与纹理运动。交付真实游戏截图/序列，或明确标记的独立预览。

工程提供 `/trailbeam showcase` 与 `/trailbeam world`，观察同一个材质/几何内核。GUI 是独立样例，不是武器挂点验收。外壳过曝先调 alpha/gain，纹理过密先调 repeat；急转扭结先修路径，不用过量发光掩盖。

## 动画武器的真正接入

Epic Fight 1.20.1 的公开源码给出有价值的设计参照：拖尾绑定动画关节的刃根/刃尖，按动作时间窗发射，并在高速动作中考虑前一帧、中间帧和当前姿态；停发后拖尾仍继续消散。本技能不复制其 GPL 代码。接到 Epic Fight、GeckoLib 或自制骨骼系统时，先写专门的 socket adapter，将动画姿态变换到世界坐标；动作窗口决定何时调用 `Effects.sample`，不是仅将玩家位置平移。若一次 tick 的刀刃转角很大，线性细分无法恢复中间弧度，应从动画函数额外采样。客户端渲染负责画面，伤害和命中另由服务端决定。
