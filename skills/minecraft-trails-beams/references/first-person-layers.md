# 第一人称拖尾分层修复

屏幕边缘速度流、角色后方历史轨迹、手部/武器轨迹和中心能量体是不同层。用户要求恢复拖尾时先确认现有层的来源与历史，不把关闭的中心雾团、光核或自身世界尾迹一起恢复。第一人称和第三人称可使用不同可见性开关，不能以恢复第三人称历史轨迹作为第一人称修复的替代。

速度驱动效果同时检查实际位置差和实体速度：自定义御空可能直接改变位置，导致 velocity 不能代表移动。重置维度/瞬移/传送和历史采样，限制异常位移，不把瞬移画成整屏长尾。

后处理/屏幕边缘层应绑定正确目标并恢复 GL 状态；外部光影的最终合成可能覆盖提前绘制的效果。验收分别看静止、起步、持续飞行、停止、第一人称中心与边缘，以及第三人称。画面中心保持用户选择的清晰范围，不以粒子计数代替视觉检查。
