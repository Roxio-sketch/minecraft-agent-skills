## 尚未覆盖

本次证实的是专用平面 window 物品的微缩几何场景。未认证任意原版/第三方物品 adapter、盔甲/骨骼模型、掉落物与展示框、全部 GUI 尺寸、Oculus/Iris/其他显卡、生产性能、完整世界远程视图、跨维度、镜面递归、纹理网格、光源/阴影、glint/bloom 共存。fixed/orbit 有实现和配置检查，未单独做最终 GPU 场景验收。

手持保持真实 off-axis 语义：主体可能随观察角度移出开口，不能为了始终居中而偷偷锁定相机。需要展示型效果可选择 fixed，或调整场景布局/窗口朝向。第三人称截图确认可见，但远距离细节有限。
