# Halo 验收

本技能的生成器行为检查与软件画图不涉及游戏启动。实施目标 MOD 后单独跑 Forge 场景，保留构建、生产 JAR 身份、真实截图及日志；不要复用旧 Cosmic 的通过结论。

## 素材与动画

- 合法 HEX、有限参数、未知键和路径 ID 验证；错误配方写入之前退出。既有输出目录不得覆盖。
- PNG 是 RGBA，角落 alpha=0，非空形状；RGB 不预乘 alpha，不重复乘 palette。黑/白底检查透明边缘，atlas 增加合适 padding 避免串邻图。
- 冻结 t 多次绘制完全一致，脉动在 t 与 t+period 闭合；正负速度方向相反；静态配方不变化。多个动画共享同一帧时间，不依赖 FPS 或 draw 次数。
- 单看纹理与 opacity/scale 应用后分别核验；PNG 不含动画，修改 recipe 不等于游戏内已经生效。
- 16/32 像素原生重采样，检查细环消失、刻度融合、光晕把主体淹没；放大只是辅助看像素。

运行 `python scripts/verify_authoring.py` 检查数学、alpha、输入错误、determinism、真实 export 与文件保护；脚本不验证 GPU 和 Minecraft。

小尺寸改动另外运行 `python scripts/compare_small.py --out <新目录>`，输出原生16/24/32px、两个时间点的视觉对照和120个16px时间采样。金色看环间暗带，红色看独立亮区；标准及阈值见 [small-icons.md](small-icons.md)。保持原配方作对照，记录尺寸占比与简化结构的变化，不能把最近邻放大图当作真实大图质量。

## 游戏场景（按请求覆盖）

| 场景 | 观察点 |
|---|---|
| GUI 多槽与工具提示 | 红蓝红同屏不串色；环中心、数量文本、耐久条、tooltip、scissor 和邻槽不被误盖 |
| 第一人称左/右与第三人称 | 锚点、镜像后旋转、billboard/模型固定选择、主副手 |
| 弓/弩/动态模型 | 实际 override/动作帧，装饰跟随指定挂点；不把主体重绘两次 |
| 掉落物/展示框 | 地形遮挡、旋转方向、背面/cull、多个对象透明顺序 |
| Cosmic + glint + Halo | 各层分别开关；原 glint 保留，Halo 不覆盖主体细节，不串 uniform |
| 生命周期 | 资源重载、切换世界/主菜单、暂停、窗口尺寸、shader 失败回退与缓存失效 |
| 性能 | 空基线/单件/满箱分别测 CPU/GPU 与 overdraw；记录分辨率与硬件，不以 quad 少保证低成本 |

专用实例/存档、启动器和自动化应按当前明确授权选择。备份与恢复实际修改的玩家/实体状态，记录恢复失败；未需要运行验证的技能创建任务无需启动游戏。

## 排错

| 现象 | 优先检查 |
|---|---|
| 黑方块或暗边 | RGB/alpha 预乘不匹配，blend 未启用，texture UV 与 atlas 混用 |
| 整个物品/后面的 UI 消失 | Halo 写深度，透明像素占深度，深度方向/偏移错误 |
| 环跟相机乱转 | billboard 与原模型变换重复应用，GUI 和世界共享错误坐标 |
| 正常游戏却暂停时抽动 | partial tick/时间源混用，每 draw 随机数 |
| 图层互相串色 | 延迟 buffer 使用最后一个 uniform，静态全局上下文，缓存键遗漏状态 |
| 重载后找不到纹理 | 旧 atlas sprite/ShaderInstance/缓存、资源命名空间错误 |
| 16px 几乎看不见 | 细节低于采样足迹、环太薄、主体挡住全部可见部分 |

仅记录实际完成项。未装 JAR 时写“素材/动画离线通过，Forge 运行效果未验证”。
