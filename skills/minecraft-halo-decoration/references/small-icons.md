# 小尺寸专用配方与验收

适用：Halo 在实际 16–24px 画布中融合成团、环层级不清、放射线分不出来。不要只提高纹理分辨率；最终可用像素和装饰结构才决定能读出什么。

## 当前两套可执行配方

| 项目 | 普通配方 | small 配方 |
|---|---|---|
| 金色双环 | 20 段外环 + 8 段内环 + 柔光 + 中心放射 | 8 段外环 + 4 段内环；仅两层；去掉填充暗间隔的柔光与射线 |
| 金环半径 | .82 / .59，scale=1 | .86 / .43，scale=1.35；扩大实际占比并拉开环距 |
| 金环线核宽度 | .012 / .018 | .045 / .046，收紧外晕，提升低分辨率可见性 |
| 红色放射 | 12 束 + 柔光 + 中心细环 | 6 束、单层；去掉柔光和细环，保留暗中心 |
| 红色中心与动画 | 射线延伸到中心；较强呼吸 | inner_radius=.32，scale=1.45；缩放振幅 .02、alpha 振幅 .06 |

金色保留 +12/-18°每秒反向旋转；红色保留 -7°每秒旋转与 2.8 秒周期。小图的视觉目标是两层环/分离射线，不强求保留普通版全部细节。small 是独立资源和结构方案，不是质量滑条的一组全局参数。

在当前预览的 1.55 半画幅下，16px 画布中金色两环半径约 6px/3px，间隔约 3px；旧配方两环相距仅约 1.2px。两者使用同一 16px 画布与采样设置，小图版主动占用更多可用面积，因此不是“同占比只改颜色”的比较。运行端保留 quad 尺寸/局部 scale 契约，不因资源尺寸变化额外放大两遍。

## 明确选择与命令

按实际最终采样像素选择，而不是 PNG 源尺寸或 Minecraft 的 GUI scale 数字：

- 16–24px：优先从对应 small 配方制作；特定主体挡住部分装饰后重新看图。
- 32px 或较大：通常用普通配方，也可按更简洁的视觉要求使用 small。
- 比 16px 更小：没有本轮认证，应进一步减少为单环/四束等；不是一套 small 自动解决所有尺寸。

```powershell
python <skill>/scripts/author_halo.py <skill>/assets/presets/gold-orbit-small.json --display-px 16 --out <新的金环目录>
python <skill>/scripts/author_halo.py <skill>/assets/presets/crimson-rays-small.json --display-px 16 --out <新的红色目录>
python <skill>/scripts/compare_small.py --out <新的对比目录>
```

`--display-px` 允许整数 8–512，输出 `preview-target.png` 和 render-contract 的 target_preview；它不改变 PNG 源分辨率、不自动选 small、不在游戏中注册切换规则。两个 small 的源纹理为 128px，运行端采样占比才决定小图表现。用户要自动 LOD 时实现 renderer 的尺寸选择；切换发生在一致 draw 边界，缓存两套有限资源，避免临界尺寸反复跳变。

## 制作规则

先移除抢占负空间的低频底光，再降低分段/射线数量、调整环距与线宽。盲目全局提亮会填平缝隙。角向线数、线宽和内孔需要配合：射线汇合处最容易模糊，内孔能让每束有明确起点。

局部尺寸转像素可估算为 `local_length * scale * canvas_px / (2 * view_half_extent)`。先检查线宽/间隔占多少像素，再微调颜色；估算不能代替带主体、旋转和采样后的画面。

新字段 `inner_radius` 仅在 rays 使用，取 0–.8 且小于 radius；从该半径开始以固定 .12 局部长度 smoothstep 渐入。省略或为 0 时保持原射线算法。这个孔是装饰几何的图案，不是物品材质 mask。

## 已验证范围

2026-09-29：两套 small 已导出透明纹理与 16px 目标预览；16/24/32px 原生 CPU 画图已检查。19 项行为检查通过，新增检查针对真实像素分离、inner_radius 合法性、目标尺寸导出，不只校验字段存在。

16px、暗背景 `(15,20,31)`、1.55 半画幅，每 .37 秒采样一次，共 120 次（0–44.03 秒）：金色两环指定亮带与间隙的线性亮度比最小约 26.4；红色按线性亮度 >.02、8 邻接且每组至少 2 像素的规则，每次均得到 6 个独立亮区。这个阈值是本次配方回归标准，不是视觉质量的通用评分。

对比脚本记录全部样本与度量定义。原生 PNG 放大只用最近邻展示像素；原图也同时输出。没有宣称任意背景/无限时间/任意旋转采样下永不融合；未验证 GPU 的 PNG 过滤、游戏 GUI 缩放或实际 MOD 接入。
