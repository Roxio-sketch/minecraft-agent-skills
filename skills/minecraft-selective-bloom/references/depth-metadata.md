# 发光深度元数据与遮挡

可以在浮点 emission 目标中存 RGB 辐射，并在独立通道存最近发光表面的线性视深度。通道不再表示透明度时，需要单独设计清空值和混合：RGB相加，深度取MIN；恢复分别设置过的RGB/alpha混合方程。也可采用独立附件，不要求必须复用alpha。

使用采样所对应的实际逆投影将场景非线性深度重建为同一线性视深度。深度归一化范围、空背景和epsilon属于该实现，不能通用照搬。RGBA8通常不足以保存精细深度元数据；按精度需求评估RGBA16F/32F或独立深度附件。

模糊时比较每个源tap的发光深度与目标像素场景深度，拒绝来自前景之后的光；最终合成再做遮挡，RGB-only写掩码保留场景alpha。只在最终合成裁剪，无法避免模糊阶段已将后方光带入前景。最近深度元数据无法精确表示多层发光透明体，需明确近似边界。

半分辨率目标的过滤、核半径和全尺寸重建共同决定外观；核尺寸在目标像素与屏幕像素间换算。检查远近发光体、细墙轮廓与多层叠加，不以无GL错误代替画面验收。
