# 自发光与附加场景照明

符文材质自发光和附近场景照明分开：前者按真实材质/UV选择发光像素，后者重建可见表面并计算点光。整物体full-bright或整屏加蓝色不能替代像素发光资格。

深度法线估计可在每轴选择深度差较小的一侧，减少轮廓跨面导数；先过滤天空和退化叉积，再定向法线。仍没有真实材质albedo、BRDF或光源方向遮挡，因此是对已着色颜色的风格化附加照明，不称为PBR或方块光传播。

如主体须保持原材质，可用真实几何标记或对象掩码排除自身；简化局部包围体可能误排相邻表面，应作为可调近似并验收。

按代码中的实际阶段/FBO/透明模式限制记录能力。有主FBO检测或Fabulous跳过分支的后端，不能因为同项目符文发光在光影包中正常就宣称点光也兼容。晚绘制材质发光、低分辨率Bloom、表面点光需要分别统计和测试。
