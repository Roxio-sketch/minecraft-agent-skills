# 设计与实际配方

## 灯光设计

“剑照亮周围地面”：世界挂点、有限半径、颜色和强度；“飘动萤火虫”：少数灯随代表性粒子移动，大量其他粒子只自发光；“宽灯带”：可用有限近似点光组或面积光后端，但先测热点和成本。

灯光色温与材质色分开。用户给 HEX 时明确转换到后端的颜色空间；shader pack 已 tone-map 的结果不再次作为线性 albedo 累计。默认示例在原画面 RGB 上做风格化附加项，没有完整线性照明。

## 本样例字段

color：RGB；radius：世界方块，0.1..128；intensity：0..16。示例只处理一个 anchor 点光；移动、随玩家、多个灯、脉动、spot cone 和阴影都不是无人读取的配置字段，需要扩展真实 Java/GLSL。

衰减使用有限范围 smooth envelope × 距离平方抑制 × Lambert 权重。示例公式在中心保持有限、范围外严格为零；它是设计用的 bounded falloff，不能称单位标定后的真实灯。

## 选择数据入口

| 后端 | 适用 | 限制 |
|---|---|---|
| 最近深度重建 + 近似法线 | 轻量局部原型 | 缺 albedo、分类、多层透明和隐藏遮挡信息 |
| 原几何材质 pass | 明确物体与 normals | 每个目标 renderer 需适配 |
| G-buffer/框架灯光 | 多灯、场景统一合成 | 需要 attachment、阶段和兼容契约 |

相机相对坐标提高大世界精度；光位置和表面位置来自同帧视图，不用第一人称相机与第三人称玩家位置混算。深度反投影矩阵必须匹配生产者的 view/projection。深度不提供实体类型、完整法线或光源与表面间的遮挡。

法线优先真实几何或 G-buffer；重建时选择深度跳变较小的相邻差分，并在轮廓/天空退化时回退。近似法线可能在斜面/薄几何失效，应显式诊断而非掩盖。
