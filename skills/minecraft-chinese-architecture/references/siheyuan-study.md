# 示意四合院：偏门、院落序列与小尺度构件

来源：[Chinese Siheyuan (1:1 Scale)](https://www.planetminecraft.com/project/chinese-siheyuan-1-1-scale/)，页面署名 **Mineman_is_King**，2021-01-20发布。通过页面的 [MediaFire镜像](https://www.mediafire.com/file/tyoh0pl2rutzzif/Siheyuan.zip/file) 正常下载。作者明确说明它是示意设计，不基于某个具体四合院；标题的1:1是作者表述，未完成现实尺寸核对。不能据此确定某一地区、年代或具体历史家庭的功能配置。

文件为Java1.14.4、DataVersion1976，有3,514个已保存主世界区块。人工材料候选包围盒为 `[-110,3,-152,-80,11,-89]`，含端点31×9×64格；区块数包含大片超平坦地面，不能当作建筑数量。只截取 `[-112,3,-154,-78,13,-87]` 作本地分析，未把源体素加入Skill。来源与SHA256见 [sources.json](sources.json)。

## 从格式差异得到的修正

该世界采用 `Level/Sections/Palette/BlockStates`，每块区块的DataVersion决定打包方式。1.14.4方块索引可跨64位边界；不能使用现代Anvil的填充式打包。新增旧版调色板世界读取，真实3个含超过16种状态的区块与独立nbtlib逐格核对。旧数字ID的 `Blocks/Data` 世界仍拒绝，避免未识别数据被当成空气。

## 布局实测

坐标按Minecraft世界XYZ；此处北是-Z、东是+X，不代表实际场地朝向。完整人工材料范围中心X=-95。南侧入口下半门位于 `[-87,5,-92]`，内侧门为 `[-87,5,-98]`，相对这条中线**向东偏8格**；两门平面沿Z相距6格。中部过门屋面中心回到X=-95。先经过偏门，再转向中部院落，形成不同于所有门都在一条轴线上的空间序列。

中间明确无上部遮挡的矩形为X=-101..-89、Z=-127..-110，在Y=5..13全部为空气，即13×18格天空开敞区。北侧另有X=-103..-87、Z=-141..-139的17×3格狭长开敞区。它们是可复算的保守矩形，不是自动识别出的完整院界，也不等于院落的全部面积。样本采用前后串联、侧边连接和内向厢房的关系；房间的历史名称和使用者身份没有文本证据。

门的位置、框选与空域核对保存于 [siheyuan-layout-measurements.json](siheyuan-layout-measurements.json)。门在存档中关闭，当前整格寻路器会把关闭的门当占用；本次没有把门删除后声称源存档原样通行。

## 屋面与细柱

[siheyuan-annotations.json](siheyuan-annotations.json) 的六个材料选区属于**同一个作品**；结果在 [siheyuan-measurements.json](siheyuan-measurements.json)。过滤仅包括石半砖和平滑石英半砖，不含所有白墙、下挂楼梯和装饰。

| 选区 | 材料水平范围 | 观察 |
|---|---|---|
| 北侧后房屋面 | 31×11 | 长横向体量，中心截线从8.5到11.5的实体上表面 |
| 中央主体屋面 | 15×11 | 与长后房分离，围出北侧窄开敞区 |
| 西厢屋面 | 9×13 | 纵向小体量；东侧有对应布置 |
| 南侧偏入口屋面 | 7×13 | 与前房横向屋面交接，局部上表面达到Y=12 |
| 中部过门屋面 | 7×7 | 位于X=-95，对应中央序列节点 |
| 西侧北段连接屋面带 | 3×7 | 仅屋面材料宽度，不能当作走道净宽 |

北侧后房Z=-145、Y=5..7的金合欢栅栏竖段位于X=-105、-101、-97、-93、-89、-85，连续3格，间距均4格。西厢X=-105对应Z=-120和-116的两条同高栅栏段，也相距4格。它们是细柱状构件，但不是实心原木柱，更不是已识别的完整传统木构柱网。测量器现在支持明确的 `material_pattern`，避免只认原木而漏掉小尺度细柱。

石半砖大量使用bottom、top、double组合。占用体素Y=8和实际上表面Y=8.5不是同一数据；新增可选 `shape_profiles: true`，以1/16格记录中央截线的实体上表面。结果按 `[起点,终点不含,表面高度]` 压缩，固定截线经过某格的中点；未实现形状明确列为近似。该样本所选半砖截线没有形状回退。体素材料范围与形状表面须分别解释。

## 对新设计的用途

可吸收偏入口转向主轴、长后房和短主体的体量差、内向两厢、沿边低连接带及细构件表达。这些关系已用于[多进院与偏门原型](multi-court-generation.md)的参数化设计，没有复制原坐标。连廊模板仍未声称复原此处3格小屋面。半砖拼出的屋面节奏可以作为新算法参照，不能用屋面方块占比代替坡面曲线和细部测量。
