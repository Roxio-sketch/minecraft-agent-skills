# 重檐与建筑细部

`chinese-detail/1` 是可独立生成的构件目录。参数放在 `parameters` 中。不把放大的构件教学模型直接贴到一格柱的房屋上；拼装前按报告中的尺度和实际包围盒检查。

| kind | 已实现的几何及参数 |
|---|---|
| double_eave_hall | 一个使用层、两道檐带；柱高10～20、下檐高6～12、下檐出挑4～7。环形下檐保留主厅净空，外围副柱接地 |
| column_base | 半径2～5、高10～28；straight/taper/entasis 三种柱身轮廓，`inclination` 0～4格倾移；柱础、柱身截面分开记录 |
| bracket_panel | 半跨7～16、高7～14、垂落2～5；梁端三角托饰与小段挂落，保留中间开口 |
| ridge_end | 半跨8～20、抬升3～10；swallowtail 分叉上扬或 abstract_end 抽象端饰，非历史脊兽谱 |
| tile_course | 半径2～5、2～7组、长8～28；放大弧面瓦列、通道与端部。弧面台阶有面连接 |
| wall_corner | 长12～36、高5～14、厚1～3；L形墙、转角和错列颜色接缝及压顶 |
| drainage_strip | 长16～64、落差0～6且不超过长度1/6；五格干路与两侧向出口递降的干排水槽 |
| log_frame | 半宽6～12、半深5～10、高7～16；逐层交替出头的横木墙及入口，展示井干关系 |

原有 `chinese-landmark/1` 仍提供抬梁/穿斗横架、层叠挑托、藻井、牌楼、亭和扩展屋面。这里补足柱础、柱形、井干、梁端、瓦作及脊端的几何工具；**没有由数学轮廓推导出梭柱制度、侧脚生起法式、斗口模数或真实榫卯**。

历史解释以 [构架与屋面依据](carpentry-and-roof-evidence.md) 和 [复原工作流](reference-reconstruction.md) 为准。要“清式七踩斗科”“某地燕尾脊”等，先选具体图纸、年代和构件位置，再改模型与截面；不能把 `tiers` 或本表数值直接翻译为历史等级。

在正常建筑上使用装饰，优先采用已测柱网、门窗和材质角色；放大面板适合构件展场或近景教学。自由放置见 [组件与材质](composition-and-materials.md)。
