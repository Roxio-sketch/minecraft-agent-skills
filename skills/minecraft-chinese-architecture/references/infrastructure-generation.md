# 廊桥、爬山廊、梯田、地下建筑与防御原型

使用 `chinese-infrastructure/1`：`kind` 选择组件，`parameters` 修改对应参数。统一入口 `architecture.py generate`，结果含结构、NPZ、报告和预览。

| kind | 参数与行为 |
|---|---|
| covered_bridge | `half_span` 5～40、`clear_width` 3/5、`rise` 0～min(6,半跨/2)、`clear_height` 5～9。桥面台阶、两侧栏杆、立柱和顶棚；全宽留两格净空 |
| hillside_gallery | `path_xyz` 2～12个折点，X/Z在±120、地板Y2～48；水平段正交且至少6格，升降不超过水平距离1/3；`clear_width` 3/5/7、`clear_height` 5～9。支持负坐标和下坡，沿整条宽路带求不超过一格的相邻高差，固定给定中线标高 |
| terraced_farm | 半宽12～32、2～6层、`terrace_depth` 8～16、`level_rise` 1～3。每层田块、灌溉渠、挡土及独立干路相连；每格作物距水不超过4格 |
| tomb | `depth` 6～16、`half_width` 14～26、`chamber_depth` 8～18。明确土体、下行阶梯、前室、主室和两侧室；检查覆土，堵下行口后地下应不可达 |
| pagoda | `mode: storeyed` 为2～5层实际楼板与梯井；`dense_eaves` 为2～7道装饰层檐、只有一个内部使用层。报告把实际楼层和檐带分别计数 |
| fort | 半宽26～38、半深24～36、墙高8～14。围墙、城门、登城梯、四角望亭和内部作坊；检查所有高处目标及封门隔断 |

爬山廊输入坐标指**支撑脚下的方块**。侧面横向高度可能在转角作一格台阶调整，以保持连续净空；不把最近路径段的高度直接铺满整个转角。路径自交、过近段标高矛盾或过陡都会拒绝。桥与廊的受力没有计算；编木拱桥另需具体工艺资料。

梯田用原版小麦和湿润耕地表达农业景观，并未新增水稻品种。水渠有底和边界，但生长、灌溉更新与雨水行为仍需要游戏检查。墓室的石台、塔刹及营堡属于原创抽象设计，不对应某朝墓制、宗教图像或军事工程规范。

独立组合可放进 `chinese-scene/1`，带入口的组件可作为 `chinese-complex/1` 的 `kind: infrastructure`。高度场场地只负责平台与道路，爬山廊的具体折线标高由本组件提供，不能让两套标高设置互相冲突。

用 `render_sections.py --axis y --at ...` 查看墓室地坪、土楼楼板和塔梯井；用 `--axis x` 或 `z` 看竖向交通。不要把墓室地面上方的屋顶图当成地下功能已验收。
