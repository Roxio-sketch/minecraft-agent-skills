# 骑楼与地域院落

统一入口使用 `chinese-vernacular/1`，返回房间、门口、楼梯、设施操作位及入口到目标的通路。它可通过 `chinese-scene/1` 任意旋转拼装，也可作为 `chinese-complex/1` 的 `kind: vernacular` 组件接入场地。三类空间与资料的对应见[证据记录](vernacular-evidence.md)。

## 骑楼商住

`vernacular-arcaded-street.json` 生成底层退后的店铺、跨店连续的廊道和上层住户。每个单元有自己的室内楼梯；上层楼板为楼梯开真洞，地面店界墙终止于退后的店面，不穿过公共通廊。

| 参数 | 范围与用途 |
|---|---|
| `shops` | 1～5个并列单元 |
| `module_width` | 10～18格；每个单元的总宽 |
| `floors` / `floor_height` | 2～4层；层间高6～9格 |
| `arcade_depth` | 4～8格；底层店面相对上层外墙的退距，净廊宽为退距减1 |
| `depth` | 20～40格；至少 `arcade_depth + floor_height + 8`，容纳楼梯和后部空间 |

地层有柜台和储物，上层有成对床方块与桌子，均有可达操作位。报表的 `arcade`、`shop_doors`、`stair_flights`、`stair_voids` 和 `rooms` 可用于复核。屋面不提供登顶路线。作者提供的楼梯、店面和冠饰均为原创设计；并未重建广州某家旅馆，也没有把来源的2～3米直接当成5格。

## 镬耳小院与闽南院落

`wok_ear_court` 有三开间后排与两个前伸侧房，围绕小天井；后排每间从檐廊独立进入。山墙在山面真实升高，具有中部拱头、凹肩和收尾的阶梯化轮廓。它是受资料启发的方块表达，未复算特定建筑的山墙曲线与防火构造。

`minnan_court` 将三开间主屋与左右侧房组合。`wing_rooms: 1` 生成二攑头关系，`2` 生成四攑头关系；房间数、门口、院深和投影长度相应变化。`ridge` 可为 `round` 或 `swallowtail`；后者在主屋每个正脊端生成两条向外上扬的分叉。燕尾是显式选项，不能推断所有金门民居都应使用燕尾。

共同参数：`bay_width` 8～14、`main_depth` 10～18、`wing_depth` 6～10、`wing_room_width` 8～12、`court_extra` 6～14，均为偶数格；`eave_height` 8～13、`roof_rise` 3～8。两翼和廊下必须留下至少7格的中央开敞区域，空间不足会要求扩大开间或缩窄两翼。镬耳增加 `ear_rise: 2..7`。

上述单院入口有小门罩，天井有浅沟。报告明确检查上空、各房入口和沟槽开敞。小门罩不是“三盖廊”或“二落大厝”；需这些类型时选择新增的`minnan_compound`，见[多落、护龙与过水](minnan-compounds.md)，其前端屋顶、院序和门路有独立几何。

## 材料与检查

`palette` 可修改墙、木、地面、石基、收边、窗、瓦块、瓦阶、瓦半砖及楼梯；角色名见预设及脚本 `PALETTE`。楼梯/瓦阶与半砖使用不带属性的对应方块ID，其方向由几何决定。来源放在 `evidence`，自由组合仍保留配置与原创/来源判断。

验证包括所有房区、设施、梯段上下口以及连续公共通廊；封一家店后只隔离对应单元，封院门后私室不可达。结构和配方可编辑，导出进行完整方块状态回读。当前仍为离线体素路径与近似色预览，未验收邻接更新、真实玩家碰撞、雨水流动或历史受力。
