# 实际凹凸与镂空构件

`chinese-ornament/1` 生成可以单独导出或拼装的块状雕饰。图案来自原创算法，没有临摹第三方雕刻几何；术语只说明图案和制作方向，不声称掌握某流派的雕刻工艺。

## 浮雕与阴刻

`relief_panel` 支持 `lotus` 莲瓣、`meander` 回转折线、`cloud_scroll` 卷曲线。`mode: raised` 从正面向外增加真实方块层；`incised` 向基材内部挖入。每处深度写在 `depth_rows_yx`，不是只改变墙面颜色。所有方向均保留指定背板，不将阴刻误作穿孔。

| 参数 | 含义 |
|---|---|
| `width` / `height` | 整板15～81格宽、13～65格高 |
| `frame` | 1～4格外框 |
| `depth` | 最大雕刻深度1～8格 |
| `backing` | 雕刻后保留1～5格连续背板 |
| `stroke_width` | 1、3或5格线宽；小板宜细线，避免莲瓣合并成块 |
| `repeats` | 回转折线重复1～8次，每次至少有7列空间 |

四份可编辑起点包含砖石浮雕、灰石阴刻、木质卷线和透空窗屏。`palette.body`、`frame`、`carving` 分别决定基材、框和雕饰的整块材料。每层深度就是一格；49×33格教学板不应不经设计就贴进20格宽的小住宅。

## 镂空屏

`lattice_screen` 没有背板。`orthogonal`、`diagonal` 分别生成直格/斜格；`ice_ray` 用固定种子的Voronoi分隔网络生成不规则孔，属于冰裂形态的算法类比，并非历史窗棂营造语法。`spacing: 4..14`、`bar_width: 1|3` 和 `depth: 1..8` 控制孔距、杆宽和厚度；`seed` 控制不规则网格。

空白格会贯穿整板厚度，不以玻璃替代空气。报告包含杆网、开孔数、净孔比例和连通检查。这里的净孔比例以图案内框面积为分母，不能当成结构承载率。斜杆用相邻面桥接，避免只在方块角点接触。

## 拼装和用途

板正面朝北，即负Z，Y由下向上。用 `chinese-scene/1` 的 `turns` 和 `at` 装入场景；它是没有行走入口的几何组件，不作为 `chinese-complex/1` 的可进入建筑。安装面、框厚、板后空间与墙体冲突须显式处理，`include_air: true` 会挖掉目标原有格位，仅在有意开墙时使用。

这些能力可用于原创砖雕、石刻、木花板和灰塑层次的粗尺度研究。细小刀痕、材料强度、灰泥配方、具体吉祥题材制度、彩绘和历史作者作品复原仍需独立资料与实现。
