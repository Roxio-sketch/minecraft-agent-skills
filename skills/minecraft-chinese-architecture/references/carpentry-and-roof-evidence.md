# 构架、屋顶和装饰：证据与建模

查询日期2026-10-29。这里将机构对概念的说明，与本Skill的原创Minecraft表达分开。条目支持定义与分工，不提供所有年代、地域和尺度；需要历史复原时另找具体建筑测绘、构件图和修缮记录。

## 可核对的概念

| 主题 | 来源支持的要点 | 对建模的约束 |
|---|---|---|
| 木构营造 | 以木材、榫卯结合及模数化尺度为重要内容。[中国非遗网](https://www.ihchina.cn/mujiegou.html) | 分开柱、梁、枋、檩、椽和围护；方块相连只能证明几何相连，不能证明榫卯或结构合理 |
| 抬梁/穿斗 | 传统木构有不同构架体系，不能由屋顶颜色识别。[中国非遗网专题](https://www.ihchina.cn/project_details/24801) | 拆出横架比较柱、梁和穿枋关系；`timber_frame`是教学示意，未复原节点 |
| 斗栱 | 斗和栱的组合关系，以及清式斗口作为尺度单位，是不同层次的概念。[故宫词条](https://www.dpm.org.cn/lemmas/241374.html) | 栌斗、栱、翘/昂、承托位置应按时代和具体实例辨认；不能用叠了几层台阶反推几铺作/几踩 |
| 攒尖 | 顶部汇聚，有方、多角和圆等轮廓，也有单/重檐变化。[故宫词条](https://www.dpm.org.cn/lemmas/241403.html) | 多角亭需要匹配平面、柱位与坡面；六/八角不能只裁掉方顶四角 |
| 盝顶 | 坡顶上部截成平顶并围出边脊。[故宫词条](https://www.dpm.org.cn/lemmas/242243.html) | 核对平顶范围和外围坡面；小模型平台上升的程序表达不证明实际排水 |
| 藻井 | 天花内向上收进的层叠装饰，常见方、多角、圆层级。[故宫词条](https://www.dpm.org.cn/lemmas/241427.html) | 从室内向上检查净空和内凹轮廓；把外面屋顶堆高不等于完成藻井 |
| 木拱廊桥 | 编木、榫卯与拱架具有具体技术内容。[中国非遗网](https://www.ihchina.cn/mugongqiao.html) | 现有池桥是桥面与栏杆原型，没有实现编梁体系；需要单独研究拱架和支座 |

故宫部分页面全文读取超时，攒尖、盝顶、斗栱条目使用搜索索引返回的官方定义片段；没有据此声称阅读了完整学术论文。正文中的算法、尺寸与材料替代均非摘录这些来源的施工规范。

## 从整体到构件的操作次序

1. **地面与台基**：先定地坪、柱础和踏道；记录每条通路的表面高度。半砖体素Y与真实表面高分开，用 `shape_profiles` 或游戏检查。
2. **柱网与横架**：横向逐开间数组、纵向进深和入口放在同一坐标图；柱高只数连续柱材。跨得过大的梁、偏置门、楼梯洞口不允许被自动柱网填上。
3. **梁枋与檩椽**：确定横架和纵向构件方向；屋面应找到支撑，避免只有瓦壳。已有 `timber_frame` 展示两种关系，椽、望板、具体榫卯仍需独立节点设计。
4. **挑檐与构件尺度**：先用普通梁托或明确的原创层叠托臂；需要真实斗栱时，选定建筑、年代、柱头/补间/转角位置，再按构件图逐件映射。未经资料核对，不把小尺度装饰套成宋式或清式。
5. **屋面**：检查正脊、垂脊/斜脊、转角和交汇谷部；控制脚下净空和墙体收头。连接形式需要同时调整柱网，不只把两张屋顶相交。
6. **墙与小木作**：隔扇、槛窗、漏窗有不同用途和开合关系。已有四种窗格只是几何图案；门窗位置需匹配室内功能、视线与通行。
7. **装饰**：彩画、雀替、挂落、脊饰、瓦当、砖雕石雕放在具体构件上。先说明原创主题或有证据的历史题材，不依据“看起来中式”随意混合等级、地域与宗教符号。

## 不同尺度的取舍

- 1格柱：保留柱网、梁架层次与主要屋脊，细部采用颜色/半砖暗示；不要给一格斗栱编造精确榫卯。
- 2～3格柱或近景展示：可拆柱础、承托、梁底与檩端，单独剖切屋面层；通路仍按玩家尺度检查。
- 构件教学放大模型：允许一构件数格宽，报告缩放目的；不得将它不经缩放拼回日常尺寸建筑。

同一场景若用两套年代或地域做法，应说明为架空原创、改建叠加或对照展示。没有证据时保留明确的设计选择，比虚构一套“万能中式比例”更有用。
