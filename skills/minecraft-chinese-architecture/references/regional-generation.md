# 地域空间原型

`generate_regional.py` 提供五种不同空间逻辑的原创可编辑起点。它们对应[地域合集](regional-collection-study.md)与[土楼样本](ancient-structures-study.md)提出的问题，并没有复制原始体素，也没有把原作者游戏标签当成历史测绘结论。

```text
python scripts/generate_regional.py --config assets/regional-stilt.json --out-dir generated/stilt --name stilt
python scripts/generate_regional.py --kind tulou --out-dir generated/tulou --name tulou
```

配置为 `chinese-regional/1`，`kind` 选择类型，`parameters` 的可用键随类型变化；不认识的键直接拒绝。共同支持按角色改 `palette` 和保留 `evidence`。所有结果有Sponge结构、NPZ、逐目标通路、参数报告及三向离线预览。

| kind | 空间与参数 | 已查什么 | 尚未代表什么 |
|---|---|---|---|
| `stilt` | `lift` 2～8，逐开间 `bays_x/bays_z`，`column_height`；每个柱点落地、底层留空、长梯与外缘栏杆 | 支撑连续、底层空气、地面到室内及断梯拒绝 | 不是所有干栏/吊脚楼的通用民族样式；未做半边依山、转角楼和地方穿斗节点 |
| `cave` | 1/3/5孔，奇数净宽5～9，墩厚3～6，深8～24，拱高5～9 | 新建土体内明确逐格开挖、拱上至少3格覆土、隔墙、逐孔可达及封门隔断 | 当前是崖面式原创体量；不等于地坑院、独立砖窑或地质安全验算 |
| `tianjing` | 外半宽14～26/半深13～24，院半宽4～10/半深4～9，四周间距至少8；墙高6～10、屋面升高3～6 | 四翼内向房带、露天天井、两侧阶梯封火墙轮廓、跨浅沟干路、入口闭合 | 未复原具体徽州宅院的房间功能、木构和马头墙装饰；浅沟不模拟排水 |
| `yurt` | 半径8～18，围壁3～6，顶高增量3～8，顶部圈半径1～3 | 圆形木/羊毛围护、入口、内部支持、顶部玻璃封闭、不同半径及封门 | 羊毛是毡布的游戏表达；顶部玻璃是设计选择，不是传统天窗材料；无可拆装杆件体系 |
| `tulou` | `shape` round/square，半径24～38、院半径10～22，环带至少13；2～4层、偶数层高6/8/10 | 厚外墙、上层窄窗、环形屋面、连续内廊、径向隔断、三格双跑梯、每层四廊点和12个房区目标 | 未按真实房间分配、宗族关系、消防、墙体受力或具体遗址复原 |

`stilt` 的湾距仍须满足厅堂组件的限制（每轴总数为偶数）；`tulou` 环带宽度须同时容下三格双跑梯与内廊，不能只缩放外径而忽略内院。全部尺寸是Minecraft格数，不能直接当米制测绘。

## 观察如何转成设计

样本干栏下部两层20个竖向栅栏位置，提示支撑、架空平台与外梯应分开处理；新生成器用完整原木柱，未照抄20个位置或18×15×14尺寸。窑洞样本有大量未指定格，故新原型先建完整土体，再明确开挖，而不是把分析空气当施工清除指令。帐居样本使用石英，新设计改用羊毛/木材的角色映射；这来自构造对照，不是作者模型材料测量值。

土楼样本的环形高屋面、中间空隙和重复梁板带用于提示“外部围护—内向交通—共享内院”的分层。原型采用6/8/10格层高来容纳现有三格双跑梯，**没有声称保留样本4格重复梁板节奏**。天井住宅的四翼布置、尺度和阶梯封火墙是新设计，不由一个11×11×15样本推导出完整徽州构造。

## 历史与地域对照

查询日期2026-10-29。以下来源仅支持所列区别；数字尺寸和生成算法仍是原创。

- [UNESCO福建土楼](https://whc.unesco.org/en/list/1113/)：圆或方的内向多层居住、厚土墙、受控入口和开敞内院。原型分别检查内廊、房区与垂直交通，不能只生成圆筒。
- [UNESCO西递、宏村](https://whc.unesco.org/en/list/1002/)：村落、街巷与水系须共同理解。单一住宅原型不等于已实现水乡村落；地方社会含义需具体资料。
- [UNESCO蒙古包营造](https://ich.unesco.org/en/RL/traditional-craftsmanship-of-the-mongol-ger-and-its-associated-customs-00872?RL=00872)：木构架、毡布围护和绳索参与可拆装体系。该条目登记于蒙古国，不能据此声称覆盖中国境内各蒙古族居住分支。
- [土家族吊脚楼营造技艺](https://www.ihchina.cn/project_details/14733/)：永顺转角楼的干栏木构、走廊与栏杆有具体地域做法。当前直线架空房只是原型，不使用“完整土家族复原”标签。
- [窑洞营造技艺](https://www.ihchina.cn/project_details/14686/)与[地坑院营造](https://www.ihchina.cn/project_details/14687/)：靠崖、独立及下沉院落应分别处理；不能将所有窑洞都埋入相同长方体土块。

## 验证边界

`test_regional.py` 的6项测试包含多组有效尺寸、全部楼层和房区、入口封闭、断梯、覆土/隔墙、材料角色及逐状态文件往返。默认圆土楼有50个目标（每层16个，加两个中间梯台）；四层大变体有67个。测试表示离线体素可达，不是实际玩家半砖碰撞、村民导航、屋面耐火或雨水行为证明。离线图使用近似颜色；内部应另用 `render_sections.py` 查看。
