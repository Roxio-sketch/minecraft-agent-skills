# Bliss 2.1.2：末地云雾分布与间歇云中闪光

Bliss 的末地效果由世界空间的有限体积雾、中心旋涡和跨帧局部光源共同构成。云中闪光是随时间变化的局部照明，进入体积雾、地形与透明表面的光照计算。它没有在这条路径中生成闪电枝条几何。

本报告是第三方源码静态研究。没有运行 Bliss 客户端，没有测量其画面或性能；以下机制也尚未等同接入本项目。工作台新增的二维巨型天体与电影黑洞属于另一条原创实现路径。

## 云雾怎样分布

主密度逻辑在 `lib/end_fog.glsl:95–167`，使用世界位置，具有以下空间结构。

| 机制与锚点 | 可见影响与限制 |
|---|---|
| `95–107`：512² 双通道 noisetex，Y 切片偏移 193，插值恢复连续三维噪声 | 以二维噪声纹理近似三维密度；不是天幕上的静态云图片 |
| `144–160`：Y 压缩为 1/48，低频主体加随时间平移的高频侵蚀 | 横向延展的块状/纱状雾，边缘持续演变 |
| `110–119`：按高度与 `frameTimeCounter/50` 旋转采样域 | 中心附近有缓慢扭卷；直接旋转密度采样坐标，而非旋转整个屏幕 |
| `122–141`：以约 `(0,100,0)` 为中心减去球形区域，同时扣除半径参数 150 的环状区域 | 中心与环带形成疏空结构，不能用单一水平云层描述 |
| `148–166`：以 Y=-60 为下部界线的指数密度 | 下方虚空更浓，上方迅速衰减，最后与主体雾相加 |
| `266–281`：世界原点半径 300 的中心/外围分区，相机 100 单位内按距离平方限制密度 | 中央更有秩序，外围是风暴；近处视线较清楚 |

中心光源在 `(0,200,0)`，见 `69–93`。中心分区检查的是世界原点距离，和密度空洞的中心高度不完全相同。`END_LIGHTNING` 关闭时光源分区强制走中心模式，不能理解为简单隐藏一层闪光图片。

源码 `116` 的旋涡边界包含可能出现负输入的 `sqrt`。这只是静态风险发现，没有据此断定 Bliss 实机异常；原创实现应先把定义域夹到合法范围，再做平滑过渡。

## 间歇闪光怎样触发

事件状态放在不每帧清空的 `colortex4` 特定像素中。`dimensions/composite5.fsh:28` 声明 `colortex4Clear=false`，`dimensions/deferred.fsh:169` 写入 DRAWBUFFERS 4。数据乘 150 存储，读取时除 150，最终跨帧混合见 `373–379`。

| 状态位置 | 锚点 | 更新协议 |
|---|---|---|
| `(3,1).x` | `deferred.fsh:324–339` | 读取倒计时，减 `frameTime`；到零时当前帧触发，并重设随机等待 |
| `(1,1).x` | `342–347` | 存储当前帧的 0/1 触发值，以 `clamp(4*frameTime,0,1)` 混入历史 |
| `(2,1).xyz` | `350–365` | 读回空间状态，叠加 `frameCounter/50` 分段驱动的哈希增量，再以快速历史权重存回 |
| `(5,5).r` | `174–180,377` | 历史尚未初始化时强制当前值，避免依赖不可用的前帧状态 |

最大等待参数为 5 秒，重设公式对应 `5*u^5`，其中 u 为哈希值。这个分布偏向短等待，因此会有密集短促的闪光和偶尔长间隔。若将 u 理想化为均匀随机变量，单次等待的数学期望约为 0.833 秒；这不是本包实测频率，还受帧时间离散、哈希分布、历史响应与初始化影响。

闪光经过历史混合，实际雾亮度不会简单成为满强度的一帧开关。通常的帧率下，快速空间更新权重达到 1；`frameCounter/50` 在这里是整数分段，而空间状态逐帧累积，不是“每 50 帧选一个独立均匀新位置”。

`end_fog.glsl:74–82` 将外围局部光定位到相机附近的 200 单位世界网格，再施加缓冲中的随机偏移。中心光保持固定，外围闪光由 `179–191` 读取闪光强度并赋色。`THE_ORB` 有独立的恒定球光分支，不应混成同一种风暴事件。

## 光如何进入云与实际世界

`end_fog.glsl:169–177` 使用局部光距离的指数衰减，再连续平方增强近处。`194–208` 沿光的方向取三次密度来近似自遮挡，并叠加艺术化的厚云染色。它既不是完整多重散射，也不是阴影贴图对云体的严格遮挡。

`215–343` 的雾积分使用 16 个指数分布样本，射线最长 384 世界单位。在每个点计算密度和局部光，按 Beer 型透射累积颜色。`297–301` 的蓝色 haze 只加亮度、不增加主透射的吸收，因此 haze 与主雾是两个不同的艺术控制项。

`dimensions/composite2.fsh:374–428` 读取实际 `depthtex0`（含条件性的 Distant Horizons 路径），重建视空间终点并执行末地雾积分。`dimensions/composite3.fsh:133–180,303–315` 用五个样本做深度差筛选，将低分辨率结果放大。最终 `438–439` 先用体积透射衰减场景，再加体积辐射。这条路径使建筑前后的雾获得真实终点约束。

地形表面在 `dimensions/composite1.fsh:1084–1103` 读取同一个闪光状态，考虑法线朝向与三点近似云影后加入直接及间接光。透明表面在 `all_translucent.fsh:642–662` 也读取闪光，按法线加入局部光；该段没有同样的三点云影调用。

不要据此扩大为“所有透明层后方的末地雾均正确拆分”。`fogBehindTranslucent_pass.fsh:375–390` 中独立的后方雾调用受 `OVERWORLD_SHADER` 保护。透明表面有末地闪光照明，与完整末地多层透明介质分解是两个不同证据。

## 玩家已有控制项

`lib/settings.glsl:638–648` 默认开启 `END_LIGHTNING`，风暴密度与 haze 密度均为 1；中心光色约为 `(0.3,0.5,1)`，外围闪光色为 `(1,0,0.5)`。`shaders.properties:291–293` 将开关、两种密度和两套光色暴露在末地/下界雾设置中。计时分布、事件持续与位置更新在这些 UI 行中没有独立滑块。

## 对原创项目可采用的路线

未来若开发异界云闪光，可以将形状、事件和光照分开：形状用连续世界空间密度与合法定义域的中心空洞；事件由固定种子、秒级时间戳和可调间隔生成；局部光为云内点源，先计算密度自遮挡，再积分到真实场景深度。明确暴露闪光频率、脉冲衰减、颜色、空间分布和云密度，避免用帧号决定玩家配方的时间行为。

这种有限世界体积应走本项目的环境介质入口；无限远二维黑洞与巨型行星走世界方向驱动的天空入口。有限体积需要位置视差和场景深度，二维巨天体需要角尺度、遮罩与天幕层次，各自验证相应契约。

当前这部分只交付研究与可复核锚点。后续开发应有独立的开关/时间对照、世界平移、地形遮挡、透明材质和相机晃动验证，不能把此报告当作已完成的云闪光验收。
