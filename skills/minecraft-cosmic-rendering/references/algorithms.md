# 星点、星云与预算选择

| 方法 | 适合 | 决策点 |
|---|---|---|
| 稀疏格子程序化星点 | 可控密度、低资源依赖的远景 | 邻格、确定性随机、亚像素过滤、分层预算 |
| 星点 sprite 图集 | 特定光晕/美术星形、动画 | atlas UV 与 mask 分离，stitch/reload 后重新取句柄，边缘过滤 |
| 世界方向三维 FBM | 无限远星云/银河云带 | 连续方向域、octave 与覆盖像素成本、频率过滤 |
| 分形 raymarch 背景 | 特定分形外观 | 明确射线空间与迭代上限，不自动等同物理体积 |
| 有限体积 raymarch | 进入星云、视差与地形交互 | 边界相交、场景深度、步长、透射率与早停 |

## 已测模板

星点取 `p=d*frequency`，检查 3×3×3 邻格的确定性随机中心。半径 0.025–0.095，中心限制在单格内侧，以高斯核着色；颜色在冷暖范围混合，时间只改亮度。它是球面采样随机三维场的斑点，不是恒星位置目录。

核宽 `max(radius,0.55*max(length(dFdx(p)),length(dFdy(p))))`，亮度乘 `radius²/width²`，用于降低亚像素丢失。该补偿是实用近似；高频层、剧烈 FOV 或分辨率降低时，核可能超出枚举邻域，不能保证完全连续或无闪烁。也要检查 hash 的方向相关性与视觉重复。

| 档位 | 星点频率 | 邻格求值/片元 | warp/dust FBM octave |
|---|---|---:|---|
| 1 | 75 | 27 | 3/4 |
| 2 | 75,170 | 54 | 4/5 |
| 3 | 75,170,350 | 81 | 5/6 |

这些常数用于可复现实验，不应作为所有需求的默认密度。需要稀疏电影风格时，分别调亮星与暗星层，避免仅增加所有星点的亮度。

星云使用两组 3D value-noise FBM：warp 扭曲采样，dust 提供云密度，倾斜带权重限定分布。紫蓝着色再 `1-exp(-color*1.35)` 压缩显示范围；没有 HDR render target、物理散射或体积视差。若用户只需静态天空，不要引入深度纹理和百步积分。

## 接缝和数值

经纬度方案要逐项检查噪声、格子、邻格、距离和纹理的周期性；最终 `fract` 不足以使整条链无缝。极区的采样密度与坐标伸缩另测。立方体方案确认是否从连续三维方向采样，逐面独立 UV 容易出现边界。

三维方向方案消除了经度展开这一类接缝，却不能自动证明有限邻域、数值精度和过滤的全部边界正确。做全天球检查时至少扫过原经度接缝、上下极点、立方体面边界和窄 FOV。

噪声/分形排错检查零向量 normalize、零分母、pow 负底数、指数溢出、NaN，以及反向 smoothstep。保持 smoothstep 边界递增，需要反向权重时用 `1-smoothstep(lo,hi,x)`。

## 成本

用覆盖像素×层数×每层求值数估算热点，再 profile。有限体积还乘 ray steps；留意循环动态 break 后的实际次数，不能只按源码上限算。固定时间、相机、分辨率与质量后，用 GPU query 测 pass，用 CPU profiler 测分配/状态查询。读回截图放在计时区间外；异步 query 避免每帧阻塞取结果。

更高质量应增加明确的预算或改善过滤；不要把全屏 shader 的单 pass 毫秒数换算成整帧 FPS。不同显卡和动态频率条件分别标注。
