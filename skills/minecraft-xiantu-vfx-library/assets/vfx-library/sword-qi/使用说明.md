# 金白剑气

独立预览：`sword-qi/index.html`，完全使用本地文件，无 CDN。

形状为三维弧形薄刃，白色锋线、金色流纹。512×128 像素一帧，8 帧图集为 512×1024；图集在自定义网格的 UV 中切换，不使用原版粒子。网页支持观察角度、暂停、重新释放和循环。

Forge 源码：`SwordQiVisuals.java`。施法正常完成时，服务端发送 mode=4 的 RiftPacket，客户端从完成位置沿施法方向发出剑气。持续 60 tick，末尾 18 tick 淡出，96 段网格，世界位置仅减一次相机位置。退出世界与切换世界会清理，最多同时保留 32 道剑气。取消施法不触发。伤害和地形规则保持原样。

网页为独立 WebGL2 预览，Forge 使用 Minecraft 自发光透明材质，两者不是同一着色器。当前没有屏幕 Bloom 或场景动态照明，不把自发光材质称作照亮环境。

`recipe.json` 为本版设计记录；Java 常量与预览实现固定该版数值，不提供游戏内热加载配置。现有 Blender 十二分镜工程没有被改动，独立特效预览也没有替换为新的完整影片。源码已接完成事件，但尚未安装、启动游戏验收；最新 Blender 分镜仍需后续单独适配到游戏动画系统。

弧刃修订：主体为新月弧形薄刃，两端各三条历史轨迹拖尾，最多回溯 28 tick。拖尾逐段收窄，带独立摆动和年龄淡出；不是原版粒子。
中央拖尾修订：新增 512×256×8 金色流纹图集，64×12 三维曲面覆盖弧刃后方，回溯 24 tick，独立条纹滚动与末端淡出；保留双尖拖尾。
