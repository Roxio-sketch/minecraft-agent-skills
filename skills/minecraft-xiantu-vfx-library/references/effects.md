# 效果入口与范围

所有路径相对assets/vfx-library；运行serve.py可通过本机目录统一打开。

| 目录 | 可复用内容 | 边界 |
|---|---|---|
| cataclysm-rift | 炽金圆环、稳定锯齿轮廓、沿边缘弧长的波包、双数据贴图、场景颜色FBO、HDR与选择性辉光 | GLSL150双颜色附件接口；尚未接入Minecraft |
| sword-formations | 四道背后剑流、四角蜿蜒、三层剑幕、环形剑群、人物交叉掐诀、真实剑网格及挂点拖尾 | 约10秒形态原型；不含服务端伤害，不等同后续15秒游戏版本 |
| sword-qi | 金白弧刃、尖端与中央金色尾流、序列图集 | 网格+贴图预览，不含落地挖沟玩法 |
| qi-sea | 五行/单灵根玉盘、修为驱动旋转亮度、灵气储量 | 使用独立参数模拟，不读写玩家存档 |
| rift | 确定性骨架、竖直裂口1.80×5.05、动态星河及开合 | 场景为测试网格；组合来源见目录NOTICE |
| energy | 20组灵气/烟纱预设、体积积分与配方 | 共用算法不等于所有宿主完成接入 |
| lightning | 固定tick闪电骨架、配方与多组预设 | 需另接客户端/服务端生命周期 |
| shield | 能量护盾及破碎交互 | 属于可调视觉预览 |
| trails | 拖尾和光束路径、色带与配方 | Canvas近似预览，非生产GPU渲染认证 |

各预览的暂停/密度/观察参数只控制该预览。cataclysm-rift的GLSL150需宿主绑定SceneColor、FlowNoise、Filaments及全部有效uniform，使用颜色和发光双输出；对发光附件降采样模糊，再合成和色调映射。世界接入还需深度遮挡与相机变换。
