# 仙途特效库 · 图片预览

九组可编辑特效：剑阵、剑气、五行气海、焚空裂隙、程序化裂隙、灵气、闪电、护盾和拖尾。

下面是实际效果预览，**不是Minecraft游戏实机截图**。图片只展示单帧；动态在工作台中查看。

## 焚空裂隙

稳定的锯齿轮廓与炽金圆环，局部波动沿边缘传播。

![焚空裂隙实际着色器预览](../../docs/media/xiantu-vfx/cataclysm-rift.png)

## 五行气海

金木水火土五色旋涡，修为与灵气参数分别控制。

![五行气海实际着色器预览](../../docs/media/xiantu-vfx/qi-sea.png)

## 拖尾与能量束

已有拖尾编辑器界面，属于Canvas近似预览。

![拖尾编辑器截图](../../docs/media/xiantu-vfx/trails-workbench.png)

## 使用

从仓库根目录运行：

```powershell
python skills/minecraft-xiantu-vfx-library/scripts/serve.py
```
