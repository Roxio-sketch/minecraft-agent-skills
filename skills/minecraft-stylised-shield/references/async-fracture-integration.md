# 异步破碎与事件身份

Voronoi 曲面裁切属于纯CPU任务，重碎片网格首次生成不宜在渲染线程完成。使用有界队列和受限线程，不选 CallerRunsPolicy 将拥塞任务反送渲染线程。后台仅处理不可变几何、种子与命中点，不访问 OpenGL、可变世界对象或装备状态；GPU上传留在客户端线程。

开始事件时冻结原点、半径、表面状态与开始tick。等待结果时可以保留冻结壳体，结果到达不重新开始动画。回调必须核对当前世界、实体实例、事件身份、寿命和重施状态；过期/换世界/重施时丢弃旧结果，取消future不代表任务必定立即停止，因此身份核对不可省。

队列满或计算异常时明确降级并限频日志，禁止无界积压或每帧重试。用服务器语义事件触发一次破碎，状态耗尽、同次攻击余伤和后续独立命中不能混作一个触发。耗尽是否保留壳、何时破碎由宿主玩法决定，不将示例规则强加给其他项目。

验证连续受击不重播、途中重施清旧结果、多人并发、换世界、过期回调和遮挡。CPU几何回归、服务器事件测试和客户端动画截图分别证明不同范围。本文指导接入，不宣称随附模板已自动具备所有服务器同步能力。
