# 宿主几何适配：装备与静态物品

## 穿戴层真实捕获

在原装备 renderer 的最终 VertexConsumer 入口捕获实际位置、UV、法线与材质，并将原顶点继续转发给原消费者。按装备槽/件记录参数，不将全身最高等级或一张通用UV遮罩施加到全部件。保留原裁切、染色、glint、内外层和可见性；第三方未知UV仅使用能证明正确的通道。

兼容层可能提供通用 MultiBufferSource，而非 BufferSource；某些 FullyBuffered 实现的 endBatch(type) 为无操作。捕获可接受通用接口，但不能因此假设已刷新基础护甲。世界附加层在基础实体提交后绘制；背包预览使用它自身立即缓冲路径。只刷新相关原层，不全局清空他人缓冲。

区分实际世界投影、GUI正交投影和光影阴影pass，不能只靠某个 Forge 阶段是否出现。保存捕获时矩阵；晚合成的世界投影取正确事件矩阵，不能沿用阴影相机。匹配原护甲深度缩放；过大clip偏移可能让内层穿出外层。每帧清空绘制队列，并检查混装、移动、墙体、背包与资源重载。

这些是宿主接入方法，未改变随附 BEWLR 示例的兼容范围；只有完成并验证目标适配器后，才能宣称支持其装备或骨骼库。

## 物品局部空间与拆层

模型绘制之后、原抓握/显示 PoseStack 尚在时追加效果，避免再次减相机或重复应用 ItemDisplayContext。脚本化姿态需要传递语义显示上下文时，临时上下文在 finally 中恢复，允许嵌套调用。

静态 baked 模型可按 atlas sprite 分离透明壳与发光材质，保留原 quad、UV、normal、overrides与显示变换。各方向及 null 面分别缓存，资源重新 bake 后重建；依赖 ModelData、随机种子或动画的模型不能用固定静态缓存替代。透明壳只写颜色可避免遮掉内部光丝，但排序仍须实测。普通透明材质不等于折射。
