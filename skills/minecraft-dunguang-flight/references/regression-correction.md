# 烟与赤焰的版本回退

日期：2026-10-15。用户在 V4 工作台指出“红黑离烟”和“赤焰撕裂”看起来像退化。本次修正恢复较完整的旧观感，不把技术复杂度当作美术进步，也不宣称用户已认可 V3 的还原度。

## 当前选择规则

- “红黑离烟”和“赤焰撕裂”各自的 `formVersions` 默认均为 `3`，调用 V3 消费者；在“效果版本”下拉中可单独切至 `4` 查看实验版。烟与火的版本选择互不影响。
- V4 烟和火保留为实验对照，不再作为这两族的默认升级结果。当前没有完成新的美术优化。
- “羽状分叉 V3”按用户要求保留造型并作为独立选项；开放流羽 V4 另行迭代。后续局部硬缝修补也应用于 `/v3/index.html` 的共源消费者，旧 V3 ZIP 与修前源码快照仍保留。
- 新宿主中的 V3 与旧版共用消费者，但相机和合成来自新宿主；“默认画布与显式 V3 基线一致”只指同一新宿主、参数与时刻下的比较，不声称与原始 V3 页面逐像素相同。

## 实际可见的损失

| 形式 | V3 保有的可见特征 | V4 实验的损失 |
|---|---|---|
| 红黑离烟 | 参差的中小尺度烟边、局部强红裂光、烟团之间的空隙与独立散逸 | 主体连成大块暗紫色层叠轮廓，偏布片或薄饼；细碎烟边与红黑明度层次减少，热斑模糊，连续采样中大瓣变形压过卷碎消散感 |
| 赤焰撕裂 | 较饱满的发光体积印象、连贯向后流动的火丝和较宽的外焰轮廓 | 主体缩成较小的橙黄亮头，后部火流明显变稀、变暗；局部撕口与独立主舌没有补偿整体焰势、连续性和丰富度的下降 |

对照依据包括同宿主的 [当前默认与实验对照](../assets/prototype/regression-correction.jpg)、[历史 V3/V4 实验对照](../assets/prototype/iteration-comparison.jpg)、烟/火基线与实验截图、连续采样及视频联系表。[当前连续预览](../assets/prototype/motion-preview.gif) 依次展示开放流羽 V4、烟 V3 和火 V3。视频红黑遁光的前端玫红亮点与短粗烟披值得继续提取；V3 的串团倾向同样不等于电影还原。

## 后续改进从 V3 开始

红黑烟以 V3 的烟边与局部裂光为底，先打散近似等距的烟团排列，将主要亮点集中到前端，再以少量较弱的后向烟流连接主体与残烟。V4 密度域可作为小比例内部吸收层试验，先保住外轮廓、空隙和红黑层次，避免再次用一个连续长域替掉全部细节。

赤焰以 V3 的连续焰流和饱满轮廓为底，逐项增加不等长、不同节奏的主舌与局部撕口；每次保留足够外焰和明暗层次，先检查整体焰势是否减弱，再决定是否保留细节改动。不要同时收短、收窄和压暗尾焰。

每次只改变可指认的视觉问题，在同一参数、时间、相机、背景和曝光下对照，再检查运动与转向。积分步数、层数、独立函数数和技术检查通过都不能证明观感提高。

## 技术核验范围

修正后的正常十一入口与离线四入口检查通过；烟/火默认画布与同宿主显式 V3 基线的像素平均误差小于 `0.00001`、最大为 `1`（浮点合成差），选择 V4 后画面有明显区别，烟与火的版本状态互不串用。该结果验证默认恢复与版本隔离，不代表新效果已优化、影片已还原或用户已通过美术验收。仍未接入 Forge 或完成游戏实机验证。

## 局部硬缝修复

用户后续截图指出羽流尾部的平切和赤焰中斜矩形割口。本次处理这些局部连续性缺陷，保持默认烟/火 V3、原配方、中心线与整体形态，不增加 Bloom。

- V3/V4 共源 ribbon 按每个连续整段的实际弧长，在首尾施加短窗透明度渐隐；截短亮筋和断段边缘各自收尾。不能把每个短 quad 单独渐隐，否则会产生珠串状断续。
- V3 火舌取消整排 `cut` 挖洞，避免直接缺三角段产生矩形负形；V4 火舌切口改为连续 alpha 蚀刻。V4 部分羽筋补上短收尾。
- 水膜/漩涡的 alpha 按共享顶点参数求值，水膜使用连续法线，减少格片间的透明度与明暗跳变。

已实际查看同条件 [局部修前后对照](../assets/prototype/seam-close-comparison.jpg)：赤焰矩形洞移除，羽尾平切弱化。另有六形 Bloom 开/关、修前后及运动截图；当前十一入口 WebGL、六入口离线检查通过。这些证据支持本次局部修补，不宣称所有角度永无面片感、整体还原完成或获得用户美术认可。

原 `/v3` 也应用共源修补，保留的是用户指定的造型；旧 ZIP 和修前源码快照仍保留。V2 活跃入口重定向至 `/v3`，休眠 V2 旧源码未改。
