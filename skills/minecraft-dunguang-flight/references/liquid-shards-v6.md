# V6 第二批：液光流绸与碎芒汇流

本轮按已批准方案修改水膜和碎光片两项。保留红黑离烟 V3、羽状分叉 V3、赤焰 V3，以及 [第一批长虹与双流 V5](flow-iteration-v5.md)。后续扇流已完成 [V7迭代](fan-flow-v7.md)，起遁和到达后续见 [V8阶段](transition-stages-v8.md)，开放流羽 V4 暂缓。只使用程序几何、现有纹理与 GLSL，无新增人物、武器、兽体或载体模型。

## 入口与对照

[工作台](../assets/prototype/index.html) 默认打开 `water` 液光流绸，另一项 `swords` 碎芒汇流。两项默认 V6，可在“效果版本”中切 V5；旧 key 为兼容标识，不表示包含武器模型。长虹和双流仍默认5，可切4；烟火仍默认3，可切4。六族分别记忆版本，导出实际消费者版本。

- [静帧对照](../assets/prototype/liquid-shards-comparison.jpg)：同一参数、时刻、相机、背景和曝光，仅替换 V5/V6 消费者。不是两版原始默认配方对比。
- [动态对照](../assets/prototype/liquid-shards-motion.gif)：两项两版本各24帧、间隔8/60秒，固定步截图合成；不是实时帧率录像。
- [运动关键帧](../assets/prototype/second-flow-motion-keys.jpg)：4.13、5.60、7.20秒的两项 V6。

## 实际消费者

新文件 `assets/prototype/liquid-shards-lookdev.js` 只覆盖 water/swords，保存 V5 消费者以供对照。九份旧基础脚本逐字节沿用 V5；宿主增加 mode16–19 着色分支、两族版本选择和逐包 emission 值，旧效果维持原值。

液光流绸：3–6条不等宽、不同展开相位和寿命的透明曲面长流，沿世界历史路径生成；新生处收尖，后段展开、扭卷并逐龄变薄。横向曲面起伏与共享顶点连续法线支撑薄面高光；稀疏亮筋独立发光，少量细水丝连接，从老尾边缘释放微光滴及短迹。几何端部和透明度按完整弧长窗连续收束，不切掉整排三角形。

碎芒汇流：每0.12秒出生桶缓存真实历史样本，包含2–7片大小、亮度、速度和寿命不同的小曲面碎光。出生后沿原方向前移、横向缓慢卷漂与收聚；每片18段短迹取该片自己的过去位置。亮筋、碎片和极低亮关联丝分层，保留空隙，不套整齐编队或一根统一长尾。

上述数量受参数控制，默认值只是可编辑起点；没有真实背景折射、流体网格或物理焦散。当前水光更接近透明亮纱，远景碎芒仍可能偏细碎。未获用户新的美术认可，不能将技术通过表述为影片还原通过。

## 继续修改时的空间约定

历史样本首次消费时缓存出生位置、方向框架、宽度、展开与寿命。旧几何由出生状态和年龄计算，不由当前人物位置重新摆放。只有最新连续段追加当前端点；该临时端点不参与碎芒和水滴出生。瞬移、掉头断段后分别消费，不跨接旧段。

碎片按分段ID与固定时间桶识别出生，不能按实时数组下标或渲染次数生成。暂停重绘必须确定；停止发射后老尾和离体片继续老化，完全过期后几何清空。材质流动按连续弧长组织，纹理运动不等于流体平流。

## 已完成检查与边界

Edge headless / D3D11 WebGL2：十一入口绘制、GL错误0、无shader或脚本异常。七入口 file:// 离线检查通过；V5/V6水和碎芒、V4/V5长虹和双流均覆盖版本导出、选择隔离、转弯/瞬移断段、停飞余光及最终顶点/历史清空。两项新旧版本各24张运动采样，并查看侧面、斜角、远景、浅背景、灰度与关闭Bloom等画面。

数值检查：水和碎芒坐标有限、完整三角；同一时刻暂停重绘确定；改变当前人物位置不改变旧世界几何；完全过期顶点为0；相距100米的分段没有跨接。覆盖输入下最大三角边分别约0.208和0.282米，不是任意参数和路径的上界。

保留性：红黑离烟、羽状V3、赤焰、长虹、双流五项在同条件画布比较中平均及最大像素差均为0，九份基础脚本字节一致。证据位于研究目录 `prototype/v6/qa-v6-report.json`、`qa-v6-offline-report.json`、`qa-v6-geometry.json`、`qa-v6-preservation.json`。这只覆盖本次环境与样本，不保证所有角度和硬件都没有面片感。
