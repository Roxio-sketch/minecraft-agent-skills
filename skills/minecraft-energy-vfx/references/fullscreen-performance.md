# 0.2.2 全屏烟纱优化与实测

2026-10-02。用户反馈全屏明显卡顿、窗口轻微卡顿，并授权由我选择优化路径。最终采用精确涡旋系数缓存与第一人称自身可见性策略；两个收益分别报告。配方仍是 energy-vfx/2 的 48 字段、20 个起点。

## 保留薄烟细节的缓存

每帧为最多 32 个密度包、每包 6 个 RK2 求值时刻，计算原局部涡旋格点的轴与角速度，写入 RGBA32F 2D array。13³ 个格点映射到 169×13×192 纹理，固定占用约 6.44 MiB（6.75 MB）。原解析 curl 在积分端点继续计算距离、权重与叉积，仅格点系数通过 texelFetch 读取；没有空间插值、时间插值或屏幕模糊。格点范围外与不支持 OpenGL 4.3 时走原解析路径。

每帧更新系数；调度前等待前一帧相关纹理读取完成，调度后执行 image/texture fetch barrier。资源重载和退出释放缓存，非默认 image 单元与 array texture 绑定恢复。同步语义参考 [Khronos glMemoryBarrier 原始参考页](https://raw.githubusercontent.com/KhronosGroup/OpenGL-Refpages/main/gl4/glMemoryBarrier.xml)。

分辨率、模拟数量、内部回溯、噪声、薄层 Gaussian 段积分及采样位置保留。九组同帧画面对照中八组 RGB 最大差为 0，强流动组为 1/255 色阶；没有超过一个色阶的像素。对照包括前后视、白烟、近裁剪面、低分辨率 Bloom 参数兼容、后续时刻、强流动、强制关闭缓存和空发射器。此质量对照关闭第一人称可见性策略，只验证缓存。

## 第一人称自身可见性

完整身体与盔甲烟团在眼前重叠会覆盖整屏；仅缓存无法充分解决这一视角。新策略只用于本地玩家的第一人称：出生时固定选择稀疏的身体/盔甲烟团，优先保留持有装备烟团，并按相机与烟团包络的距离平滑淡出近眼部分。选择在出生时固定，保留正常出生/消亡渐变，避免每帧重新挑选引起跳变。

这项策略会减少第一人称看见的自身烟量，是明确的外观取舍。所有烟团仍在世界空间模拟，生成率、寿命和独立漂移不变；第三人称绘制完整烟团。用户保存的 firstPerson、数量和其他参数文件不被改写。近眼策略是运行库行为，不能据此称第一人称画面逐像素不变。

## 2560×1440 原生 GPU 对照

硬件 NVIDIA RTX 4060 Ti，Minecraft 1.20.1 / Forge 47.4.10 / Java 17。全新独立平坦世界，冻结相同 25 个包、时钟与相机；resolution=1、steps=128，持续发散实际每包 64 个积分段、65 个端点。先关闭特效，再旧路径/新路径各两轮。记录实际主帧缓冲尺寸，避免 Windows 窗口装饰造成高度少 19 像素。

第三人称每例预热 60 帧、测量 140 帧；第一人称预热 30 帧、测量 60 帧。GPU timestamp query 异步读取已完成结果，无 glFinish，无阻塞等待；两组 droppedQueryFrames=0、GL error=0。生产运行不开启计时。

第一人称模拟仍有 25 包，最终上传 3 包，出生稀疏选择排除 20 包，近眼隐藏 2 包、部分淡出 1 包。约 11 ms 的总特效耗时包含这项可见性取舍，不能归为同画质的纯缓存收益。旧路径约 735 ms 对应刻意固定的近眼重叠压力场景，不代表用户 ASTRA 的实际帧耗时。

独立场景的特效 GPU 时间不是整游戏 FPS 保证；背景世界、其他 MOD、显示同步与第一人称遮挡都可能影响实际帧率。

## 中间试验的边界

早期窗口测试实际为 2560×1421，单独归档，不冒充 2560×1440。第一人称只开缓存的早期压力测试超过七分钟，completed=false；只做近眼淡出的中间版约 76 ms，随后增加稳定出生选择。以上均不替代最终通过的两轮结果。最终版优先保留装备发散，并保持第三人称完整烟量。
