# 光带、尘埃与透镜运动

以下记录描述 v2.2 的研究与旧配方。当前默认配方、宽画幅背景、分层 HDR 光带及诊断入口见 [v3.1 工作台](v3-workbench.md)。


## 来源核对


该 shader 的运动有三处：盘噪声循环中的角坐标随 time 改变；`traceColor` 的最终 galaxy Cubemap 方向绕 Y 按 time 度旋转；`main` 中相机按 time*0.1 环绕并上下移动。引力加速度公式本身没有独立 time 项，因此“透镜在转”的观感包含被偏折的运动素材与视点变化，不能声称它实现了旋转时空或 frame dragging。

`unity-black-hole-shader-main/Assets/Black Hole/BlackHole.shader` 在弯曲路径中求盘平面交点，通过极坐标噪声、内外缘渐隐和角向时间变化形成光带；多次穿盘形成上/下方映像。学习其薄盘交点与层次关系，不沿用按 stepSize 捕获核心的缺陷。

## 工作台 v2.2

- `diskStyle=dust`：原创周期三维 value noise 的四个尺度相乘，再映射为稀疏体积密度。在弯曲射线的实际采样位置计算，正面盘与绕射弧使用同一尘埃场。不是屏幕贴点，也不保留试验中的规则 Gaussian 点阵。
- `diskStyle=ribbons`：薄盘交点、统一角速度、极坐标多尺度噪声，径向噪声频率高于角向频率。径向坐标及内外渐隐遵循 Unity 来源的 smoothstep / outFade / inFade 关系。原创噪声替代来源贴图，没有分发来源素材。预设扩大外盘、内缘空隙，关闭额外 halo，默认内流为 0；仍可单独开启内流。
- `speed` / `infallSpeed`：分别推进盘结构的角向和径向坐标。尘埃各尺度增加有界角向偏移，保留多尺度相乘分布。新风格不使用随 time 无界增长的径向差速相位；旧 granular 路线仍提供差速旋转。固定纹理不会每帧重新随机生成。
- `backgroundSpin`：程序星域方向旋转，单位弧度/秒，范围 -1–1；发生在透镜射线求解后的背景查询中。没有旋转整个最终屏幕。
- `orbitSpeed`：观察者绕 Y 的角速度，范围 -0.3–0.3；默认 0。盘与可选 sprite 使用同一相机。它不冒充引力场自旋，也不完全复刻来源相机的上下摆动。
- `viewDistance`：观察距离 5–24；旧配方缺省 7.8。当前尘埃预设拓宽盘外缘至 6、观察距离 14，以留出连续尘埃分布；盘外径允许 2–8，盘内径允许 0.55–3。
- `backgroundStyle`：`nebula` 为原创弥散星云，`stars` 为原有程序星点，`black` 为纯黑；旧配方省略时仍选 stars。两种新风格默认 nebula，使盘内尘埃与背景星点可分辨。星点背景按出射方向的像素足迹过滤；切换纯黑可直接检查噪点来自盘面还是背景。
- `dustScale`（1–4 整数）/ `dustFill`（0.05–1）：尘埃细度/密度倍率；`bandDetail`（2–24 整数）控制窄带频率。

新默认关闭额外 sprite 与 halo，以避免用户反馈中的亮短条、模糊叠光。原 `particles` 参数仍可导入，属于另一个可选轨道粒子 pass，不是 dust 风格的密度控制。三份经典配方继续使用旧求解路径。

不要把曝光压成纯白后再添加噪声补细节。先使密度/源亮度保留灰度层次，再检查实际像素分辨率、掠射角、上下绕射弧；放大模糊截图不能证明尘埃结构。程序背景不是参考项目的 galaxy Cubemap，也不是 Minecraft 当前世界。

## 代码与验收

v2.1 用户截图在 277.85 秒出现严重锯齿，源于 `time * omega(radius)` 的径向相位导数持续增大；几秒钟的动画检查未覆盖此问题。内侧点状亮环还包含被压缩的背景星点，不应一概归因于独立粒子或用额外黑圆遮住。定位时分离盘辐射与背景，并查看 captured / exhausted / transmission 诊断。

v2.2 将有限射线路径预算加倍而不增大步长。exhausted 仍代表计算截断，不标为核心捕获；未解出的背景不参与合成，已积累的前景辐射保留。新风格使用 2x2 空间超采样，诊断保持单样本，便于直接统计标志。超采样增加像素工作量，不代表实时帧率达标；极端参数及强压缩的高阶映像仍可能需要更精细的积分或过滤。

`assets/preview/styles.glsl` 实现两种原创场；`black-hole.glsl` 增加缺省不改变旧行为的 `BH_DISK_DENSITY` / `BH_SURFACE_DISK` 钩子。`layers.js` 只在新风格启用这些钩子。Forge 模板的独立内核与生成资源保留其已构建版本，迁移时必须显式生成、构建、实机验收。

`scripts/validate_styles.cjs` 检查默认无 sprite、上下弧和盘面的角向运动、独立径向输运、冻结、配方往返、背景旋转、相机环绕、旧配方默认值与手机宽度。v2.2 的 16 项结果位于研究工作区 `research/black-hole/workbench-v22-styles`。

`scripts/validate_long_playback.cjs` 的 25 项检查覆盖 0 / 1.7 / 277.85 / 99999 秒、7957 圈旋转回归、不同质量/倾角的最薄盘、纯黑背景、背景配方往返及手机布局。故意降低测试射线预算，确保 exhausted 背景检查实际命中未完成路径，不能用零命中通过。证据在 `research/black-hole/workbench-v22-long-playback`；检查粗糙度稳定只是抗时间退化回归，不能代替参考图的视觉评估。这是浏览器验证，非新增 Forge 认证，也不是 Unity 原项目逐像素复刻。

可以使用 `?preset=ribbons&play=1` 直接打开光带并播放，普通地址仍默认尘埃、暂停。新字段随 `black-hole-preview/v2` 导出；旧 v1/v2 省略时背景/观察环绕为 0。
