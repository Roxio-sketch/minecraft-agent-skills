# Reused textures

Kenney Particle Pack: https://kenney.nl/assets/particle-pack — CC0 (see KENNEY-LICENSE.txt).

smoke-atlas.png combines original transparent smoke_01, smoke_07, smoke_08, smoke_04 in that order; erosion.png is fire_01; flow-streak.png is trace_05. Original 512×512 files were verified in the official archive on 2026-10-15. No frames from the user's videos are used as production textures. The full download provenance and SHA-256 list are kept in the research workspace v3-resources/kenney/sources-and-hashes.json.

texture-assets.js embeds identical PNG bytes so the study also opens directly from a local file without fetch or a server.
