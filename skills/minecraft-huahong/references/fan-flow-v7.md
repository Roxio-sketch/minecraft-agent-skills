# V7：扇形流霞

本文记录扇流阶段；后续起遁/到达见 [V8阶段衔接](transition-stages-v8.md)。只做程序几何和GLSL，无鸟体、实体翅膀、人物、武器或载体模型。红黑离烟V3、羽状分叉V3、赤焰V3、长虹V5、双流V5、液光V6、碎芒V6保留。

## 入口与版本

[工作台](../assets/prototype/index.html) 默认选择 `bird` 扇形流霞V7。旧key只是参数兼容。“效果版本”可切7/4：旧扇流是V4算法，沿用至V6页面，不能误称它已经有一个新造型的V6消费者。七族版本选择独立记忆，导出实际版本。

- [同条件静帧](../assets/prototype/fan-comparison.jpg)：两版相同时刻、参数、相机、背景和曝光，仅换算法；不是旧版原始默认配方对比。
- [巡航、急转、停飞动态](../assets/prototype/fan-motion.gif)：两版各36帧，间隔10/60秒，固定步截图合成；不是性能录像。
- [运动关键帧](../assets/prototype/fan-event-keys.jpg)。研究目录另保留每版24张巡航采样及浅背景、灰度、无Bloom、远景、追尾和斜角截图。

## 本轮实际实现

`assets/prototype/fan-lookdev.js` 只覆盖原 `DunguangCarrierForms.bird`，另存旧消费者供对照。宿主增加mode20–22材质分支、扇流版本管理与该项相机取景。此前十份基础脚本逐字节沿用。

世界历史点缓存出生位置、方向框架、宽度、展开、寿命和舒展参数。每侧2–5束不等长纱流从集中根部逐龄向外展开，宽度和余量沿程变化；不同相位的缓弯、卷边与细褶支撑开放扇面，不画刚性翼板。主体比液光更短、更展开，不使用水滴或羽状V3的二次分叉。

共享顶点连续法线、低频透明密度和方向性流纹构成薄纱；疏密高光单独发光，少量细筋与更长的低亮散丝延续后尾。端部按完整分段弧长同时收窄、渐隐，修正急转后宽流截面的齐切感。没有靠删整排三角形制造破碎，未增加模型。

当前依旧能在斜角和近追视读出分层丝带；浅背景对比下降。软碎边和卷动是艺术近似，不是流体输运、布料求解或影片精确复刻。用户尚未评价本轮，不能把技术通过写成美术认可。

## 延续时保持

旧纱流由出生框架和年龄计算，不按当前人物位置摆放；只给最新连续段追加当前端点。瞬移和急转后的旧段各自消散，不能跨接；停止发射后继续老化。颜色、曝光和Bloom不要替代轮廓、展开和疏密关系。

本轮学习沿用 [既有核查来源与许可证](lookdev-resources.md)：Riot的朝向/主次用于集中根部和低亮外纱，Catlike的流动方法用于材质方向与局部变化，HDR发光与多尺度模糊用于少量高光。新增消费者与着色分支为本任务原创，没有新下载外部素材或复制未授权代码。

## 证据与限制

Edge headless / D3D11 WebGL2十一入口与八入口file://检查通过，GL0、无shader/脚本异常。扇流7/4选择隔离、导出、转弯和瞬移断段、停飞余光、最终历史/顶点清空均检查；另有两版各36帧巡航→急转→停飞序列，末帧顶点0。

数值检查覆盖有限坐标、完整三角、暂停确定性、改变当前位置不影响旧世界几何、完全过期清空，以及相距100米的两段不跨接。该输入最大三角边约0.191米，不能外推所有参数。

十份基础脚本字节一致。与V6同条件画布比较，六项像素差为0；水流636000像素中24个像素最大单通道差1/255，平均单通道差约0.0000126/255。新增共用shader分支后的量化边界差异被如实记录，不声称七项逐像素完全相同。

研究证据：`prototype/v7/qa-v7-report.json`、`qa-v7-offline-report.json`、`qa-v7-geometry.json`、`qa-v7-events.json`、`qa-v7-preservation.json`。仍是浏览器研究原型，没有Forge运行JAR、游戏第一人称、多人或GPU性能验收。
