# 多形式的设计与验收

本 Skill 的目标是制作不同构型的遁光。**同一梭壳＋螺旋丝＋长尾只改色相、线宽或层数，仍算同一构型的变体。** 初版网页因此被用户明确否定；新预览和后续游戏制作都应按实际几何、运动、材质、空间关系与生命周期判断差异。

形态族是可组合的技术起点，不是预设白名单或固定种类总数。用户的新参考可引入新截面、新发射域、新附着关系或新的转换相位。不能以“只有八个预设”替代设计。

当前制作范围仅为程序几何与着色器特效，不新增人物、武器、兽体、鸟或飞舟模型。参考中的实体造型照实记录，但不能把新增模型数量算作遁光形式。

## 各类应有可辨的结构

| 形态族 | 必须成立的轮廓与空间 | 运动与退出 | 消费者应如何不同 |
|---|---|---|---|
| 细针/长虹 | 极小集中头部，1–3条窄的世界长迹；人物可外露 | 留真实历史，停止旧线淡去；近远宽度策略明确 | 独立历史条带，禁止默认叠巨大包裹壳 |
| 羽状光梭 | 前尖集中，肩部向后外展多根长短不同羽枝 | 局部羽枝随速度基，长尾另存历史；控制点连续 | 二次Bezier主/支曲线，外带与内核两次几何提交 |
| 空心旋带 | 人物/暗中心可辨，多条绕身曲面有间隙 | 局部错相旋转/轴向流动，制动时卷带收束 | 真正环绕曲线/薄片；不等同均匀椭球上画螺旋纹 |
| 红黑烟遁 | 不规则宽短暗密度，内部只有少量红光 | 烟包出生后离体，旧烟不跟人物转身；停注入后扩散变薄 | 有历史包/团的普通alpha或体积吸收；黑色加法不是烟 |
| 碎光片阵 | 能逐个识别的透光折角片，片间留白；没有武器模型 | 伴行、盘旋、聚拢、散开分阶段；不是闪点 | 程序光片、片元侵蚀与独立轨迹/旋转相位 |
| 水膜聚散 | 薄透明弯膜、断续水丝和分离水滴 | 聚成身体外衣/显形，结束散膜散滴；无必需长虹 | 多片网格和独立水滴位置；有折射才声称真实折射 |
| 赤焰撕裂 | 多条不规则火舌、内部暗缝、尖端不断破碎 | 出生后向后输运，长度错峰、熄灭不全体硬切 | 不同长度火舌几何/侵蚀及有限余烬；不是球罩改橙 |
| 旋涡/通道 | 大小渐变的三维漏斗、前后尺度与空心明确 | 沿轴向进入/退出，旋转与尺度推进；属遁行转换相位 | 环/螺旋管/漏斗的实际几何，不默认装成身体护盾 |
| 兽形参考的薄纱层 | 观察兽形轮廓周围多股薄纱尾，主体只作参考 | 只研究光纱拉伸与脱落 | 本任务不制作兽体模型或化形动画 |
| 灵禽参考的扇状羽流 | 提取扇面流片、中心留白和分离尾光 | 流片错相弯摆、旧光保留历史 | 程序透明流片与 shader；不创建鸟体/实体翼羽 |
| 飞舟参考的双股剪尾 | 提取分离双流、冲压弧片和负形 | 非对称剪切、脉冲与双尾衰减 | 程序波片与世界双轨；不创建船体/帆 |
| 自由新造型 | 依新参考定义主体与负形，如兽形、花瓣、符文羽翼 | 由用户目标确定阶段 | 新字段有真实消费逻辑，不能写无人读取的JSON |

## 最小差异检查

在同一相机、路径、seed与曝光下录制各族，先忽略颜色，核对：

1. **外轮廓**：是单细线、分枝、环、团、片阵还是漏斗？不能全都读成同一锥形尾巴。
2. **负形与人物**：哪里留空、人物是否外露、细片之间是否有缝？超亮白烧不应掩盖结构。
3. **坐标空间**：局部外衣、世界历史、离体包、相机边缘各自是什么？相机不改变世界过去的位置。
4. **运动规律**：旋带绕轴、烟团离体、碎光片编队、水滴聚散、火舌撕裂应能在时间里区分；静帧不同仍不足以证明运动不同。
5. **启动/停止**：停止移动、停止发射、技能关闭和显形是不同事件。各族可以有不同退出，但UI动作应说明实际触发哪个事件。

种类名称或不同顶点数只是实现线索，不是美术验收。逐族查看截图和短序列，用户指出相似时修改实际消费者，而不是再添加同一结构的新配色。

## 复用已有宿主时

御剑基线擅长真实剑尾挂点与窄世界剑气；境界基线擅长身体—尾迹同源包裹与动作联动。复用它们的状态、时钟、历史、深度/后处理合同；新增造型选择自己的几何与材质。

若以后接入宿主已有载体，可读取其真实挂点与姿态，并保留原动画；本任务不创建或替换载体模型。兽体本身、人物骑兽、无人器物仍是不同参考关系，未看见人物时保持未知。

浏览器预览可验证算法差异，但不会自动使这些族成为五行仙途可选择的游戏技能。要入游戏需实现样式枚举/消费者、多人同步、真实挂点、资源重载、第一人称策略及实机测试，保留宿主已有两种效果的行为。
