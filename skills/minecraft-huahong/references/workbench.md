# 遁光 V8 工作台

打开 [实时预览](../assets/prototype/index.html)，先读 [V8阶段](transition-stages-v8.md)、[V7扇形流霞](fan-flow-v7.md)、[V6液光与碎芒](liquid-shards-v6.md)、[V5长虹与双流](flow-iteration-v5.md)、[烟火退化与默认恢复](regression-correction.md) 和 [V4实验与不足](lookdev-v4.md)，同时可读 [学习资源页](../assets/prototype/learning.html) 与 [资源研究](lookdev-resources.md)。当前只绘制程序几何、纹理与GLSL特效，不加入人物、武器、兽体、鸟或飞舟模型。

液光与碎芒分别默认 `formVersions=6`，各自切换5/6；长虹与双流默认5、切换4/5；烟与火仍默认3、切换3/4。扇流默认7、切换4/7。七族各自记忆选择，导出实际消费者版本。顶部新增独立阶段控制：旋带聚光/扩散与轴向卷入/回卷，详见V8说明；普通巡航默认不开阶段。

## 当前消费者

| 形式 | 当前实际组成 |
|---|---|
| 贯空长虹 V5 | 集中长光梭、单主世界长迹与稀疏伴流，按年龄收细；可切 V4 对照 |
| 开放流羽 V4 | 不等长开放宽膜、少量中段分叉、青蓝/淡紫副枝、三条较亮主枝与窄世界尾 |
| 羽状分叉 V3（保留） | 保留密集二次Bezier分羽、二级羽筋与多筋历史长尾；独立选择，修补共源 ribbon 的硬端口 |
| 红黑离烟 | 默认 V3：历史出生的纹理烟团、参差烟边、局部红裂光与余烟；V4 三维密度积分仅供实验对照 |
| 赤焰撕裂 | 默认 V3：连续火丝、多层外焰与后向焰流；V4 非等长主舌、撕口与短残焰仅供实验对照 |
| 扇形流霞 V7 | 两侧错位后展的不等长透明纱流、疏密高光与散丝，端部收窄渐隐；可切旧扇流V4，无实体翼羽 |

“羽状分叉 V3”是用户指定保留的独立版本；“开放流羽 V4”另行迭代。新版 V3 变体共用新版相机与合成；保留 V3 造型并修补同源硬缝，原 `/v3` 入口也获得修补。旧 ZIP 与修前源码快照仍保留，不宣称当前页面与修前字节不变。

用户指出烟和赤焰的 V4 观感退化后，两族分别以 `formVersions=3` 为默认；各自的“效果版本”下拉可切换 V4 实验版，互不影响。回退保住旧观感，不代表 V3 已通过还原验收，也不代表完成了新的美术优化。

这些是研究消费者，不是视频所有法术的完整复刻。此前用户已否定V1统一梭壳换色与V2结构草模的美术质量；不能把按钮数量、代码独立或技术检查通过当作还原度通过。当前仍需逐族对照参考反馈。

## 共用合成和材质

CPU固定60Hz/0.14m历史推进；各族选择局部层、世界历史或离体出生状态。GLSL负责透明密度、双相流动遮罩、细节侵蚀、烟密度积分和发光。不是全GPU模拟。

场景颜色与独立发光写入两张FBO附件；支持时使用RGBA16F，不支持时降为RGBA8并如实报告。发光经过三尺度横纵高斯模糊，再与场景合成、曝光和色调映射。羽丝宽外带/细亮核两次几何与此后处理分别存在，不能混称同一个双pass。当前默认2×超采样用于细筋，质量和堆层优先，尚未性能优化。

默认 V3 烟与火焰次层使用 Kenney 四张静态烟遮罩图集，另有侵蚀和流丝纹理；可选 V4 烟实验主体使用程序密度；原许可和变换说明附于textures目录。它们不是已确认的连续模拟flipbook。没有从商业视频截取成品贴图。

此前的接缝修补：V3/V4 共源 ribbon 在连续整段首尾按弧长短窗渐隐；V3 火舌不再以整排切断挖矩形洞；V4 火舌使用连续 alpha 蚀刻，V4 部分羽筋补收尾；水膜/漩涡透明度按共享顶点求值，水膜法线连续。未增加 Bloom，也未改配方或整体形态。已目视检查 [修前后局部对照](../assets/prototype/seam-close-comparison.jpg)，火焰矩形洞移除，羽尾平切弱化；分层表面仍可能在部分角度显出面片感。

## 操作与边界

拖动/滚轮观察；暂停冻结时间，停飞停位移并继续老化。Bloom/曝光独立可调；可切三种中性背景、同色结构，以及V3消费者同场景对照，网格和遮挡立柱默认关闭。烟与火先在各自“效果版本”选择 3 或 4，再以相同参数、相机和时刻比较。普通停飞仅老化；新增阶段另有制动与短时散光，但没有人物显形或游戏技能接入。

导出schema仍为`dunguang-study/1`，`minecraftRuntimeValidated=false`、`modelsIncluded=false`，附本原型合成设置；不能直接导入五行、Photon或其他运行库。旧API key `swords/bird/vessel`只是兼容，消费者分别为碎芒汇流/扇流/双流。

默认 V3 烟是纹理密度卡片；可选 V4 烟实验采用有界程序密度积分和不透明深度截断。透明包/多域交叠仍按包中心排序，未做流体解算或多重散射；没有屏幕背景折射、地形照明、光学运动模糊、多人网络或真实骨骼适配。第一人称、Fabulous/Oculus、游戏深度和目标显卡性能均需后续Forge接入验收。

诊断入口`window.dunguangStudy.getDiagnostics()`；`renderPipeline`显示实际HDR格式/模糊层尺寸，`form`显示透明包与顶点数，`textureReady`应为3。这些数字用于定位问题，不用于替代美术判断。详见 [验证范围](validation.md)。
