**当前状态：**用户指出 V4 红黑烟与赤焰像退化后，两族均恢复 V3 为默认，V4 仅为“效果版本”下拉中的实验选项，各自独立选择。下述 V4 改动是实验记录，不是当前默认或已认可的升级。可观察损失、恢复规则与后续从 V3 改进的方向见 [烟火退化与默认恢复](regression-correction.md)。

## V4 实验曾做的修改

| 视觉问题 | V4 实验消费者 | 实际变化 |
|---|---|---|
| 青光像整齐刷子或闭合细梭 | `feather-lookdev.js` / mode 11 | 不等长开放宽膜，后方保持发散，少量中段出生的二级枝；青蓝与淡紫副膜、三条较亮主枝、小白尖；世界尾减窄，保留过去位置 |
| 火焰像等亮网纹或橙色椭圆线团 | `flame-lookdev.js` / mode 12 | 三股长宽悬殊主舌、独立偏移尾端、实际三角缺口，外围只保留短暗碎片；前中部两处主热源、脱离残焰、烟和火星 |
| 烟像低模球或柔糊胶囊 | `smoke-lookdev.js` / mode 10 | 88步有界三维密度积分、域扭曲卷块、不齐尾缘、局部玫红热袋；每步两次额外密度探针做艺术受光/自遮蔽；黑色吸收与发射分开 |
| 所谓侧面实际接近轴向、主体被压缩 | 宿主相机 | 以飞行方向和侧轴构造侧视，按三个主体设距离与焦点；提供灰蓝/浅灰/暗夜背景 |
| 改背景或相机后难以判断材料改动 | 同场景V3开关 | 在同一宿主、参数、时刻、相机、曝光中切换旧/新消费者；对比图来自此开关 |

## 可选 V4 积分烟的接入约定

透明包中的 `volume` 带 `center / axes / radii / fade / seed / glow`。单张前置屏朝代理面只负责光线范围，主体来自三维程序密度。局部烟中心与方向停飞后冻结；残烟读取旧世界出生位置，不跨断带连接。

宿主把不透明深度复制到独立深度纹理，用逆VP重建遮挡距离，截断积分上界。读取的纹理没有同时附着于正在绘制的FBO，避免反馈。场景RGB与积分alpha按普通alpha合成，发射单独写HDR附件；曝光/Bloom不替代烟密度。烟色参数有实际uniform消费者，灰度开关也作用于烟的片元颜色。

双次曲线几何、88步积分和屏幕Bloom是不同操作。烟的光照是两探针艺术近似，不是多重散射、流体模拟或场景动态照明；交叠烟域仍按包中心排序，透明水/玻璃不在本深度快照里。

## 当前证据与不足

浏览器十个研究起点加 V3 保留变体的十一入口检查、最终三消费者回归、离线四消费者检查均有独立报告。三类各有16张连续时间采样，以及追尾、自由相机、灰度、明暗背景、Bloom和烟深度柱截图。`iteration-comparison.jpg` 保留历史 V3/V4 实验对照；`regression-correction.jpg` 展示当前默认与实验版。当前 GIF 已更新为开放流羽 V4、烟 V3、火 V3，均为固定模拟步截图合成，不是实时性能录屏。

回退修正后，正常十一入口与离线四入口检查通过。烟/火默认画布与同宿主显式 V3 基线像素差接近零；V4 实验画面存在区别，版本选择互不影响。这证明恢复与隔离生效，不代表美术改进通过。接缝补丁后又通过 V4 十一入口、V3 十入口及离线六入口检查，并查看六形修前后、Bloom 开关与运动截图；矩形切口已移除或软化，仍不能保证全部角度没有表面片层感。

V4 实验的实际损失不能仅写成“仍有差距”：烟出现大块平滑暗紫层叠轮廓，细碎边、空隙和红裂光减少；赤焰主体与尾流变小、变稀、变暗，整体焰势减弱。羽膜曲线也偏平滑，细碎边和局部湍流不足。恢复 V3 是保留较完整旧观感，仍未精确重建完整起遁/巡航/刹停/显形、电影镜头和光学运动模糊。

尚无Forge构建/安装/实机、多人挂点、第一人称、Fabulous/Oculus与GPU耗时验证。不能继承五行仙途旧实机结论。质量优先阶段不进行减层优化；需要接入游戏时继续完成真实消费者并实机验收。
