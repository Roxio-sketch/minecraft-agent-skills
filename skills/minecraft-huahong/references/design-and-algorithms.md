# 遁光的形态、空间与算法

这里给出可重组的实现决策，不限定只能制作参考中的几种风格。数学式是独立设计建议，不是对参考视频专有实现的断言。来源见 source-research.md。

## 先选形态，再选技术

| 可见目标 | 主体结构 | 适合的补层 | 容易误判的地方 |
|---|---|---|---|
| 青绿长虹、多股丝带 | 世界历史中心线＋窄核心＋几条外层 ribbon/tube | 局部亮头、弧长滚动纹理、少量飞散点 | 近距追视的扇面不等于世界里是巨大锥体 |
| 包住人物的水梭/风梭 | 速度方向局部梭形网格、几层错相流丝 | 小规模离体气团、噪声侵蚀 | 滚动透明壳不是体积流体 |
| 红黑烟遁/灰雾遁 | 低频连续暗密度、离体包历史、内层少量发射 | 长丝余烬、边缘侵蚀 | 黑色加法几乎不显影；需 alpha/吸收 |
| 金光/电光遁 | 清楚的梭形或环状轮廓、少量长线筋 | 分支电流、短促启动壳、有限金屑 | 雷击、爆炸、护盾与巡航需要分开 |
| 花瓣/剑形/羽片等自定造型 | 真实三维网格或沿历史的截面族 | 纹样、偏心细丝、姿态联动 | 不必强行套圆球或固定预设 |

至少写清：主体是否可见、运动方向、外衣长度/半径、尾长/宽度曲线、细丝拓扑、配色层级、残留、触发、镜头及遮挡。颜色、形状、运动、生命周期分别记录，避免一个名字塞进多个未知量。

## 两个坐标系统

人物局部层使用 `world = anchor + F*x + N*y + B*z`。`F` 通常来自速度，而不是相机或身体 yaw；`anchor` 由实体位置/实际姿态挂点给出。速度低于阈值时沿用上个有效方向，必要时回退实体朝向。方向按 `a=1-exp(-dt/tau)` 平滑并处理反向退化，不能直接对接近相反的向量线性混合后归一化。

历史点存 `positionWorld(double), bornTime, cumulativeArc, segmentId`。不能把历史点每帧重新 parent 到人物，也不能在渲染中不断追加。模拟和网络校正对历史的处理要明确：小幅误差平滑修正头部；传送或大跳变开启新段，不画穿地图的连接线。

外衣可用轴向参数 `u in [0,1]` 与截面角 `theta`：

```
x(u) = mix(-backLength, frontLength, u)
r(u) = radius * pow(max(0, sin(pi*u)), taper)
theta(u,t,k) = phase[k] + turns*2*pi*u - angularSpeed*t
p = anchor + F*x(u) + r(u)*(N*cos(theta)+B*sin(theta))
```

这是梭形壳/细丝起点。前端、腹部、尾端可用独立曲线替代，不把正弦半径当唯一形状。壳面做小幅低频变形，薄纱和亮筋使用不同频率/相位；避免所有层同步成硬弹簧。若要视觉上的纵向流动，纹理沿轴向或弧长变化，别仅靠整壳旋转。

## 历史尾迹的稳定采样

1. 每个客户端固定模拟步读取实体历史位置（Forge 通常 20 Hz）；高速视觉可在相邻 tick 间按距离插点，但插值不凭空恢复未同步的真实急弯。
2. 从最后采样锚点到新点沿线段按 `sampleSpacingMeters` 插入，携带未用完的距离。每步插点设置资源上限；超限应断段或按明确 LOD 降采样，不能卡死。
3. 对极短段不产生退化三角形。急弯设置 miter 上限，改用 bevel/round 或断段；掉头先判断切线点积再处理，避免无限放大的侧向向量。
4. 年龄 `age = now - bornTime`，透明度可用 `pow(max(0,1-age/life), fadePower)`。宽度另取 `w(age/life)`，不要靠 alpha 强度冒充宽度。
5. UV 取 `cumulativeArc / repeatMeters - scrollSpeed*time`。删掉旧尾点后保留累计弧长基准，纹理不能随删点跳动。

### 连续带的收尾与局部蚀刻

片状平切先检查几何沿程边界：横向 `1-abs(uv.x)` 只能软化两侧，不能消除历史带末端、截短亮筋或硬删除三角段留下的横口。按每个连续整段的实际弧长，在首尾施加短窗透明度渐隐；保持中心线、配方和主体尺寸。断带后各连续段分别处理，避免把短窗按整条历史的长度拉大。不要给每个短 quad 分别渐隐，否则连续尾迹会变成珠串。

火舌内部的破碎优先用连续 alpha 蚀刻；整排省略三角形会留下直边矩形洞。共享边的透明度应从同一顶点参数求值，水膜等受法线影响的表面同时使用连续法线，避免相邻格各自定值造成片状明暗跳变。真实切口仍可保留，但切口周边需有局部收尾，不能靠增加 Bloom 掩盖。

本次 V3/V4 共源 ribbon、V3 火舌、V4 火舌/羽筋及水膜/漩涡已按这些边界作局部修补；修前后同条件图见 [局部硬缝修复](regression-correction.md#局部硬缝修复)。这不消除分层表面在所有角度下的面片观感。

远处可以用相机朝向 ribbon，近旁观或环绕可用连续标架的多薄片/管状截面。最小切线旋转运输前一法线，随后重新正交化；180°反向选稳定备用轴或断段，不直接对接近零的叉积归一化。ribbon 的视线与切线平行时同样需要沿用稳定法线或备用轴。

`tailLength ≈ speedMetersPerSecond * lifeSeconds` 是直线匀速估算。寿命、距离上限、采样间距是不同控制；例如 30 m/s × 0.8 s 是 24 m，0.15 m 间距约160段。此数值是起始设计，不是视频测量，也不保证固定 GPU 耗时。

## 离体烟、细丝与流动

烟包在出生时继承 `v0 = inertia * ownerVelocity + localFlow`，之后在世界中推进。不能让所有旧烟包持续无条件加上人物当前速度，那会让已留下的烟追随急转。细丝可沿历史标架偏移，使用平滑噪声/相位曲线；无散 curl 场本身不会向中心吸聚。

curl 可由势函数旋度构造，速度场轨迹用中点 RK2：`k1=v(p,t); pNext=p+dt*v(p+0.5*dt*k1,t+0.5*dt)`。势函数乘空间包络后再取 curl，与直接缩放已有 curl 速度不同。添加向心/后向拉伸项后，不宣称整体仍无散。

只有壳面不够厚、镜头需要穿入气团时再选局部体积积分：求视线与包围域交点；用世界不透明深度截断区间；相机在域内时从近裁剪/零开始；`T *= exp(-sigmaT*density*ds)`，发射权重随步长一致。按屏幕面积×积分步数×包数估算成本，再测 GPU。不要把天气体积云的时域历史直接套到瞬移的玩家技能。

## 合成与相机

- 亮丝：RGB与alpha权重及blend函数必须配套，保留世界深度测试、通常不写深度。加法只是混合方式，不使遮挡自动正确。
- 暗烟：按远近排序做合适 alpha 或单域发射吸收，避免多片黑卡交叉。实体前后层与透明水面需要专门验收。
- Soft intersection：比较同空间的线性深度/重建位置。原始投影 depth 值的相减没有固定米制意义；正反深度/近远面必须一致。
- Bloom：独立 emission target → blur/down-upsample → composite；超亮宽条不是 Bloom。采样背景必须用独立颜色副本，不能读当前写附件。
- 第一人称：局部外衣靠眼部分连续淡出或隐藏中心段，世界尾迹保持；边缘速度流是独立相机层，不用它代替世界尾迹。第三人称相机拉近也要处理入壳覆盖。

## 逐步实验

先关光晕和碎点，验证亮头、外衣和曲线能读懂；再旋转相机检查三维结构；再加低频侵蚀和细丝相位；最后加 Bloom/扰动。换白天/夜晚、靠墙、穿树、近水，分别固定路径与 seed 对比。艺术方向变更时修改曲线/截面/场的消费者，不把不支持的字段塞进 JSON。
