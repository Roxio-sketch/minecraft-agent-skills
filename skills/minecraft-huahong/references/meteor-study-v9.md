# 流星化虹 V9

本轮只扩展流星：虹核流星 `meteor_prism` 与燃尾流星 `meteor_flame`。不加入极光、雪、山体、角色、武器或陨石模型。旧形式与各自版本不变。原 Skill `minecraft-dunguang-flight` 更名为 `minecraft-huahong`，内部 `dunguang-study/1` 导出 schema 与 `window.dunguangStudy` 保留兼容。

## 参考拆解

用户提供三份文本附件及一段主文 shader。第一份包括分层噪声、域扭曲、虹色流核、闪电、粒子和脉冲环；两份较长文本包含彗星主体、场景演出和环境，其中一份全部位于块注释内。只提取流星相关思路，不把被注释的 mainImage 当作可执行入口，不把极光、雪和山体纳入化虹。

彗星代码把采样点投影到运动轴，再按轴距和径向距离塑造燃尾；碎片采用出生偏移、速度和后向加速度。实际局限是碎片仍相对当前 mPos 计算，转向时会跟随头部移动；t_center 附近固定采样区间不能保证覆盖长尾。部分常量如 FRAG_VEL 没有实际消费者。直接 clamp 轴向距离还可能在核前生成密度。适配时必须限定真实轴向范围或使用世界历史路径。

主文 fire 是屏幕二维角度函数与逆平方亮度，不是真实三维流星。fs 或中心距离为零可产生非有限值；normalize(0) 无定义；fract(iTime*2) 的坐标平移和毫秒级 floor 抖动会产生跳变。fbm1 的频率逐次减半、振幅倍增，是低频占主导的纹理叠加，不应当作通常的高频递减 fBm 照搬。iChannel0/1 的原贴图和采样配置未提供，不能宣称复现原图。

## 独立消费者

`assets/prototype/meteor-huahong.js` 是本轮独立实现，不嵌入或改写粘贴 shader 全文：

- 虹核：集中白核、稀疏虹色丝流与世界长迹；标准余弦色板只用于连续色相，不靠整团换色区分形态。
- 燃尾：不等长开放火舌，连续曲面与轴向噪声侵蚀，细核和少量脱落短芒；无封闭梭壳。
- 固定 tick 世界历史、按 segment 断带；停止后历史独立老化。碎芒缓存出生位置、方向框架及侧展，不跟随当前头部重定位。
- 宽度、丝量、侧展、局部长度、寿命、速度、气晕和颜色各有真实消费者。速度只改变预览运动，不添加游戏玩法速度翻倍机制。

这些是曲面材质原型，不是体积流体或光学流星模拟。虹色着色使用常见余弦调色公式，来源线索为 Iñigo Quílez 的 [Palettes](https://iquilezles.org/articles/palettes/)；本轮网页读取受限，未据此声称读取作者实现或取得额外授权。
