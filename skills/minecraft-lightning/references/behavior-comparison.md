# Spektr 行为对照与本轮修正（2026-10-02）

## 结论

此前不能还原的主要原因在实现，不应把原因归为“直线源码不能适配圆环”。中心线可以是直线或圆弧；附着、扰动和生长可以在中心线局部坐标中分别处理。但原 Spektr 的短段窗口会沿通道滑动，与用户要求的“电弧自己的根部固定、从该端延长”是两种动画。因此保留独立 `spektr`、`grow`、`ring` 对照，避免混淆。

## 直接读取的源码

- `Assets/Spektr/Lightning/Shader/Lightning.shader`：`pp01=lerp(tp01,pp01,bolt_len)`；按每条通道随机 interval 和每周期 seed 决定长度、可见性与强度；两正交轴做双频 Simplex 位移。
- `SimplexNoise2D.cginc`：Ashima 2D Simplex，与先前的格点插值噪声不同。当前 Java/JS 是其标量 CPU 移植，保留完整 MIT 声明。
- `Assets/Test/Test.unity`：端点 -10/+10、20 条、30 顶点、长度比例 .8、长度随机 .9、间隔 .3 秒、throttle .1、噪声幅度 1.2、频率 .1、速度 .1。
- 用户 Inspector 截图另显示 Bolt Length .1、Length Randomness 0、Throttle 约 .573。因此增加“截图短弧参数”（arcLength=2）和“Spektr 参考场景”（arcLength=16）两个预设；不能把仓库场景参数当成截图中唯一的参数。

## 修改与原因

| 问题 | 修正 |
|---|---|
| 噪声像格点波浪，动态不接近源码 | Java/JS 改用同类双频 Simplex；截图参数预设使用较慢噪声 |
| 随机线长改变时根部跳位置 | 棍身根部依据固定最大预留长度定位，环弧依据固定 seed 角度定位；噪声在根部门控为零 |
| 高增益主雷白色、分叉有色 | 2026-10-06 明确两层渐变与保色核心模式；主雷与分叉使用相同沿程材料，传统加法可截白；可选 additive 恢复旧显示 |
| 细分后出现规则亮点 | 2026-10-05 WebGL/Forge 光晕逐路径 MAX 取覆盖并集后 ADD；核心保留共享接缝位置、宽度和颜色；禁止逐段圆帽直接加法 |
| 转动后出现贯穿画面直线 | 遇到近裁面拒绝或不连续连接时结束当前可见路径，避免跳过点后跨缺口连接 |
| 预览速度与帧率绑定 | 使用真实时间差 ×20 tick/s；增加时间定位滑杆，拖动即暂停 |
| 主干打结 | 保留主轴投影单调约束；16 组极端参数检查主干不反向及预算 |
| 落雷尾部被截断 | Forge 必须等所有延迟子事件结束后才清理；原先把延迟加到计时上会过早清理 |
| 第一次触发忽略配方 seed | 先读配方，再选择默认或指定 seed；随机命令限制为可导入工作台的有符号 32 位整数 |

## 验证与限制

Node 检查通过：参考噪声向量、固定根部跨周期/双向、从根部延长、源模式复现、种子变化、极端参数单调性/预算、落雷分叉上限。

Forge 47.4.10 / Java 17 的 `build reobfJar` 和 `lightningCheck` 通过：同组噪声向量、固定根部、不同相机下共享 miter 接缝、确定性、分叉限制、延迟落雷清理。

浏览器检查：高细分主干、转动视角、短弧预设、环形参考预设、时间定位及渐变。记录本地截图，未把截图视为 Minecraft 实机通过。

2026-10-02 的原记录未做 Minecraft GPU/实机认证；2026-10-05 的新工作台、独立工程和 GPU 验证另见 [验收](validation.md)。尚未做原 Unity 场景同步逐帧对比，不声称完全还原。随机散列仍使用稳定的播种整数实现，未复刻 Unity float sin 散列；真实闪电的 JS/Java 随机序列不同，各自可复现，跨语言不承诺逐点一致。新工作台使用 WebGL2 逐顶点宽度/颜色和与 Forge 一致的径向光强与光晕合成；预览相机/core接缝及随机树仍有差别。当前光晕仍不是 Unity HDR/Bloom，尤其曝光和外围溢光存在差别。

three-windline 仅作为圆弧路径参考，lightning-arc 作为种子/噪声/光晕对照；没有执行这两个仓库的脚本，也不据此认定视觉还原已完成。

## 2026-10-02：速度与集束击地补充

弧头速度现在独立为格/秒，在固定根部模式和环形模式中控制中心线延长；噪声速度保持独立。慢速自动延长脉冲周期，源码短段模式保持原来的移动窗口。

落雷新增小范围集束、硬落点边界和零分叉预设。击地含径向延长电弧、扩散断环、闪光和有限弹道火花；按各雷的先行到达时间触发，尾段有独立寿命。形状模板播种后缓存。参考图用于方向和构图，未宣称与参考视频逐帧还原。

Node、Java 检查与 Forge build/reobfJar 通过，浏览器检查击地开关、触发和尾段清理，保存 cluster-impact.jpg。Forge 使用方块射线落点，但地面电弧暂用水平局部面，火花没有方块碰撞；本轮未启动 Minecraft 做 GPU/实机测试。
