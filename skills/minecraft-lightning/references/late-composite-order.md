# 晚合成依赖与HUD隐藏

将世界效果延迟到光影合成之后时，冻结正确的世界projection/modelView与场景深度，延迟回调不从GUI当前矩阵重新取相机。多个事件合并队列后，保持背景云先于闪电、前景效果最后的宿主依赖；前景绘制前显式提交待处理背景，不能把独立事件订阅顺序当作稳定渲染图。

RenderGuiEvent.Pre只是通常的提交点，隐藏HUD时未必调用。保留RenderTick END兜底并确保每帧只提交一次；START清理未消费的上一帧回调，世界退出释放深度和待提交对象。

检测主viewport、深度附件、FBO所有权与阴影pass；缺少深度时选择明确回退，不无条件穿墙。完整核心/光晕与场景照明各有输出语义，不因某层能在光影包下显示就宣布全部通道受支持。
