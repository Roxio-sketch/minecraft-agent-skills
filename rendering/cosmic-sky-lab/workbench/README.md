# 启动星空工坊 0.6.0

Python3运行 `launch.py`，保持窗口开启，Ctrl+C停止。仅需标准库和WebGL2浏览器，网页无需外网。工作台有39个可编辑起点、188个参数。

六个新起点为球形晴空、散射日落、轨道边缘、轻雪漫游、风雪云幕与玻璃雨景。保留原26种星空、大气、云雾、二维电影式金环黑洞与曲率黑洞。拖动环顾、滚轮调FOV、暂停和时间条复查，所有配方参数自动保存到当前浏览器。

“球形大气”以真实km长度、分子/微粒/臭氧介质计算透射和近似多次散射，并用天空缓存减少绘制成本。太阳高度与观察者海拔都参与计算；“轨道边缘”使用150km观察基准，从大气层外看弯曲的行星边缘。解析美术大气仍可单独选择。顶部太阳强度和显示曝光是相对RGB基准，没有绝对光度标定。

世界观察用WASD平移、Q/E升降，或调整X/高度/Z。“按生物群系”雨雪在网页通过演示气候选择雨、雪、干燥区域和高度变化；游戏读取实际世界气候与地表、屋顶遮盖。雨雷模拟用于“跟随游戏天气”。原雨幕也保留独立入口。

场景选择器提供仅天空、地面深度、玻璃与水面。透明测试可以比较最终场景合成与按透明层分段；环境渲染比例用于降低云雨雾成本，也可能改变细节与亮度，并非无损。细小雪花会保持完整分辨率，渲染状态分别显示目标与实际比例及保护原因，并显示大气缓存是否就绪、造表次数、环境合成尺寸以及异步GPU计时。页面FPS不能代替单个GPU阶段的用时。

配方导出为完整 `cosmic-sky/6` JSON，也能导出PNG或生成配套Forge1.20.1资源ZIP。本机保存写入 `exports`。配方不保存相机、时间、测试透明场景或演示气候，长期作品请导出JSON。

浏览器可显式升级完整旧/1、/2、/3、/4、/5。/4保留原美术大气、雨幕与已设置的云雾；新的球形大气、气候雨雪和透明分层按需开启。API和游戏严格读取完整/6。JSON放入实例 `config/cosmic-sky.json` 后执行 `/cosmiclab load`；资源ZIP启用后F3+T，再执行 `/cosmiclab reset`。ZIP需要配套MOD，不是独立shaderpack。

目录可携带；`--root`指定资源，`--no-browser`只启动服务，`--check`检查资源，`--generate-forge`生成同源资源。各模式的实际游戏、数值与GPU验证参阅工程README和 `evidence/advanced-sky-20261006`；第三方光影的适配能力以实际选择的实现和测试为准。

新增七种二维巨型天体：气体巨行星、冰封巨行星、破碎月球、辉光暗盘、双恒星、耀斑恒星、旋涡暗星。样式0保留普通天体；调整天体角半径/尺寸倍率、位置、相位、自转和双色。原32起点参数保留，/5升级保留184值并默认关闭新样式。

Bliss2.1.2末地云雾分布与间歇云内闪光已完成可复核源码研究，未作为已实现效果发布；指定三包的恒星/暗盘调用链也加入天空研究库。
