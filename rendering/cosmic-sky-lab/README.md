# 星空工坊 0.6.0

原创程序化天空与环境工作台，188个参数、39个可编辑起点。提供动态星点、流动星云、巨型程序天体、两类动态远景黑洞，以及日月、薄云、世界体积云、雨雪、双虹、冰晶晕、雾、云影和天光。新版本增加球形大气缓存、生物群系与屋顶雨雪、原版玻璃/水的分层环境合成，以及可调环境渲染比例。

桌面 `启动星空工作台.py` 和 `启动能量特效工作台.py` 均启动此工作台。便携版解压后运行 `python workbench/launch.py`，仅需Python标准库及WebGL2浏览器。保持启动窗口开启，Ctrl+C停止本地服务。

## 创作

选择起点，按分组修改参数；拖动画面环顾、滚轮调FOV、播放/暂停和时间轴观察动态。PNG、完整配方JSON及配套Minecraft资源ZIP均可导出。作品自动保存在浏览器，长期作品请另存JSON。相机、时间、测试场景和演示气候属于预览状态，不写进配方。

首次打开或首次选择新的天体/黑洞组合需要编译，可能等待数秒；同一会话重选已有组合会复用缓存。

新增六个起点：球形晴空、散射日落、轨道边缘、轻雪漫游、风雪云幕、玻璃雨景。原26个起点的参数值保留。球形大气使用km单位的Rayleigh/Mie/臭氧介质，并缓存透射、高阶散射近似和天空；轨道边缘可以在大气层外观察弯曲的行星边缘。它是RGB近似，没有完整光谱或绝对光度标定。

七种二维巨型天体提供气体巨行星、冰封巨行星、破碎月球、辉光暗盘、双恒星、耀斑恒星、旋涡暗星起点。样式0保留普通天体；可以修改角半径、尺寸倍率、位置、相位、自转和双色。原32起点参数保留，/5升级保留184值并默认关闭新样式。

世界测试可用WASD平移、Q/E升降、位置控件或飞行按钮进入云层。场景选择提供仅天空、地面深度、玻璃、水面；演示气候提供雨、雪、干燥区域与高度变化。网页模拟雨雷驱动跟随天气预览，游戏读取实际天气与每个位置的生物群系、地表和屋顶。

金环黑洞是二维电影式方向天幕，具有暗核、弯曲光弧、横向吸积带、旋转纹理和弯曲宇宙背景的有界引力透镜；另一种保留曲率积分透镜。两类都由程序实时生成。天体没有相机平移视差，黑洞不吸实体，亮环不照亮地形。需要近距离世界透镜或粒子时使用独立黑洞实现。

环境比例.5–1降低云雨雾采样成本，地面纹理与透明表面保持原分辨率，但细节和亮度可能改变。细小雪花自动保持完整分辨率；状态栏显示请求/实际比例、大气造表次数与GPU阶段计时。页面FPS和单pass GPU耗时分别理解。

完整配方为 `cosmic-sky/6`、188字段。浏览器可以显式升级完整旧/1、/2、/3、/4、/5，保留原值并给新选项补默认值。API与Java严格接收完整/6；非法导入保留当前作品。

## Minecraft

目标MC1.20.1 / Forge47.4.22 / Java17。安装 [cosmic-sky-lab-0.6.0.jar](deliverables/cosmic-sky-lab-0.6.0.jar)，将JSON放入实例 `config/cosmic-sky.json`，执行 `/cosmiclab load`。导出资源ZIP需要此MOD，启用后F3+T，再 `/cosmiclab reset` 使用资源默认配方；ZIP不是独立Oculus/OptiFine光影包。

`nebula` 显示完整天空环境，`stars` 仅星点，`quality 1/2/3` 调采样预算，`freeze` 固定时间0，`direction` 显示方向诊断，`off` 恢复原版路径，均使用 `/cosmiclab` 前缀。示例路由主世界天空；已有项目按实际维度与渲染入口适配。

透明分层覆盖原版BLOCK玻璃和水，保留原几何、UV、光照、alpha、排序与目标缓冲。其他透明RenderType需另行适配；条件不符时回到最终环境合成。启用外部Oculus光影时交由该光影管线拥有天空/环境，关闭后恢复Cosmic；这种交接不代表任意光影包与本项目物理效果同时叠加。

## 实现与维护

浏览器与Forge依次共享五份原创算法GLSL：core、extra、physical、weather、environment。参考光影代码和天空贴图仅留研究目录；原版Minecraft透明着色器包装保留自己的来源说明。世界合成读取实际颜色/深度，并使用本帧相机、逆投影、逆view和投影光学眼点，处理走路bob造成的投影平移。

体积云16/24/32视线步、2/3/4太阳步；雾和天光12/20/28视线步。地形深度截断云、降水和空气积分。世界环境在已曝光RGB上合成，云影是表面调制；未实现历史重投影、完整场景光照分解或任意透明物体遮挡。其他GPU、加载器/版本与4K性能需要另验。

改参数后运行 `node workbench/sync-metadata.mjs`；改算法或包装后运行 `python forge/sync-advanced-resources.py`，再 `python workbench/launch.py --generate-forge forge/src/main/resources`。生成天空、环境与附带LUT/透明/重建资源；新增字段还需同步SkyRecipe.java。Java17下构建并核对JAR实际资源。

[VALIDATION.md](VALIDATION.md)记录当前证据、失败诊断与限制；[manifest.json](deliverables/manifest.json)给出交付哈希。[天空研究库](workbench/sky-library.html)提供来源和效果链接；[skill](../skill/minecraft-cosmic-rendering/SKILL.md)包含可携带工作台与接入方法。历史0.5文档及原15用例模板独立保留。原创算法适用 [LICENSE](LICENSE)。
