# 炼丹炉特效参数编辑台

按五行仙途实际五格炉体制作，炉底火、炉口药气、炼化细丝和凝丹光核均为程序三维密度。主火从用户指定的八角圆底下缘出生，圆底内部持续燃烧，外围不规则火簇分叉、卷回并上舔；默认暖色炉火、苍青药气与金白凝丹，30个可编辑参数。当前以画面为先，默认400步积分。

双击桌面“启动炼丹炉特效工作台.py”，或在“启动全部工作台.py”选择“炼丹炉特效”。当前服务 http://127.0.0.1:8820/。拖动旋转、滚轮拉近；四个阶段按钮和阶段进度观察不同炼制状态。半剖、人形、网格与挂点仅用于预览，不保存到配方。保存写入本项目current-recipe.json，导出得到严格alchemy-vfx/1配方。

精确模型测量与范围判断见MODEL_RANGE.md和model-audit.json。原OBJ/MTL/PNG快照在model，导出脚本export_model.py可重新读取宿主源码。修改体积核心后运行build_shared.py同步Web资源，Forge构建也应同步并核对核心SHA。

游戏适配位于forge，通过实际成型炼丹炉状态接入，保留原炼丹结算。宿主已经有旧版炼丹几何效果；新的接管hook必须明确协调，避免旧火和新火叠加。可审阅集成补丁在forge/integration，宿主源码没有在预览制作过程中被直接覆盖。独立测试不等同于用户实例安装。

旧版18条固定火舌和连续亮环已移除。新火床采用填充密度、局部冷却高度、噪声导数生成的旋度场与三步中点回溯。它是程序化卷流与三维密度积分，不是网格流体求解器。闭炉仍由真实模型遮挡，使用半剖观察中心火床。
