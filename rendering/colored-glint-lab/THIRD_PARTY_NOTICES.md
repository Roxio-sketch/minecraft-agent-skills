# Third-party material

The nine unchanged `textures/misc/glint_item_*.png` assets are from the user's
RenderBlender 1.1.2 source archive, declared authors cu6, cnlimiter, IAFEnvoy,
declared license LGPL-3.0. The original license is in
`THIRD_PARTY_LICENSES/RenderBlender-LGPL-3.0.txt` and in the built JAR.

The integration Java is newly written for this experiment. Original source
audit and texture hashes are retained in the project's
`skill/minecraft-colored-glint/references/source-manifest.json`.

The audit driver adapts the local Cosmic Material Lab's existing test harness;
its existing license is preserved as `LICENSE.txt`.
