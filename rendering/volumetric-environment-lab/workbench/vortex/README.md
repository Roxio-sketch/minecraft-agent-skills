# 陆地龙卷、龙吸水与水龙卷工作台

当前工作台路径 `/vortex/`。`mode=0` 为陆地体积云漏斗，`mode=1` 为海面吸起的水团、多层不规则水片与上段云雾，`mode=2` 为延伸至大部分云层高度的液态水龙卷。使用“重新形成”播放生成过程；暂停后设置时间可重放。

预览下方的“云体总密度”范围为 0–5，控制漏斗云雾、云帽和喷雾共同强度。右侧还可分别修改上下半径、收束曲线、稀薄内芯、轴线弯曲、翻卷、旋转、上升、底部卷吸、云帽密度和喷雾密度。两种水面模式另有中心凹陷、水波高度/相位速度和泡沫控制；液片、水滴与云雾分别渲染。

云雾使用本机生成的 64³ 三维云块/细胞侵蚀纹理，按解析地形、海面或液体的命中距离积分。近处细采样改善自遮光；视线预算每步两个子采样。水面由多方向风浪、中心凹陷、扰动涡脊与破碎泡沫组成，反射使用程序环境。

液体主体采用填实的连续水团，螺旋隆起直接改变外轮廓，谷部继续保留液体。共同绕轴相位的高度系数为水龙卷 9.0、龙吸水 7.5 弧度，消除此前高度项相互抵消造成的弱螺旋；减小位移和皱褶，不再挖穿主体上层。外围水皮按当前核心半径重叠并加厚，开口只影响辅助薄片。三个邻近的输运高度槽继续生成不同方向与尺寸的侧向水片，根部按实际海面高度裁切。最多 96 个有限生命周期水滴从主体附近沿切向、向外和上升初速度甩出，随后沿重力弹道运动；解析椭球交点、法线和最近深度比较独立于连续液体。水滴尚未由真实片边断裂驱动，泡沫也只是艺术代理。

水柱泡沫与细法线沿共同螺旋相位形成噪声调宽、断续覆盖的斜绕轴水痕，再叠独立旋转、上升细纹；它们不会裁掉主体。海面泡沫与细法线沿风、旋流和径向卷吸移动。参考 [Valve 水流讲义](https://cdn.fastly.steamstatic.com/apps/valve/2010/siggraph2010_vlachos_waterflow.pdf)，用 2.8 秒短段双相位、半周期错相和空间错相限制纹理变形并隐藏重置。既有 `rotation/rise/inflow/waveSpeed/foam` 分别控制旋流、上升、卷吸、风浪输运与泡沫强度；暂停固定秒数可冻结输运，没有新增字段或流体求解。

水界面采用单次空气到水的折射方向，以 24 个占据样本估计有限液体场内的累计水光程，再按 RGB 吸收区分厚水团与薄片。透射背景采用 12 步环境云积分与平均海面/天空近似。有限样本可能漏过细片，没有追踪出口界面、再次追踪起伏海面或求解多水界面光路。水面交点采用有限扫描与二分，极端掠射或多交点可能漏过最近根；有限区域会平滑截断高扰动或过宽的云体。

导出的 `vortex-cloud/1` JSON 保存基础 62 字段配方、20 个涡旋参数以及预览时间/相机。本页导入会恢复完整作品。基础 Forge 配置读取器不识别这层协议，新增密度、液片、水滴与水面没有游戏接入；原 Forge JAR 的验收范围仍是基础环境功能。
