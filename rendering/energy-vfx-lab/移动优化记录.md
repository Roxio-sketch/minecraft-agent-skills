## 两项变化及外观边界

等画质裁剪：0.2.3 为持续发散路径加入每气团的保守屏幕边界，按流向椭球包络投影、合并可见范围，并在 shader 中跳过该气团边界以外的像素。离开相机可见范围的拖烟不再撑大整个体积 pass；跨越透视 w=0 的边保留保守范围，边界外扩像素。此项只减少无贡献的计算与场景复制范围，密度、内部积分与采样位置维持原值；“等画质”的验收范围是下述同帧对照中的一个色阶以内判定，不声称所有像素严格相等。

近眼策略从第一人称延伸到本地玩家的近距第三人称。距离指相机到玩家眼位的距离：1.8m 及以下采用完整近眼权重，身体/盔甲气团按出生时固定的稀疏选择，并将贴近相机的气团平滑淡出，优先保留持有装备气团；1.8–3.0m 用 smoothstep 平滑减弱策略；3.0m 及以上权重为 0，恢复完整烟量。固定出生选择避免每帧重新选包造成跳变。

近眼筛选发生在上传绘制阶段，所有存活气团仍照常模拟出生、寿命、漂移和消亡。模拟数组容量为 32 包；preset 16 的发射率和寿命通常形成约 24–25 个存活气团，具体数量随生命周期变化，不能保证始终 25 包，阶段末数量以表中实测为准。该策略会减少眼前可见烟量，收益包含外观取舍，不能称为纯同画质加速。正常远距保留完整存活数量；用户保存的配方和数量参数不因此改写。

源码：[PacketBounds.java](forge/src/main/java/dev/energyvfx/PacketBounds.java)、[AuraEmitter.java](forge/src/main/java/dev/energyvfx/AuraEmitter.java)、[volume.glsl](forge/src/main/resources/assets/energyvfx/shaders/volume.glsl)。

## 真实移动测试方法与计时范围

最终清理后重跑：Minecraft 1.20.1 / Forge 47.4.10 / Java 17，新建独立开发测试世界，16 号蓝烟预设，resolution=1、steps=128。每阶段先将服务端和客户端统一到本组固定坐标并确认到位，随后重置并 bind 发射器，使 noiseBase 从同一起点建立。报告逐阶段读取 startPosition 与 originConfirmed，并检查七个起点在 0.000001m 内一致；只出现 completed=true 而缺少这些字段的旧运行不会通过最终验收。

发射器和时钟不冻结；服务端每 tick 更新玩家位置，并读取客户端位置。新协议的 travelledMeters 只累计测量期实际移动距离。每阶段暖机 80 client tick，随后测量 200 client tick；检查 warmupTicks=80、measurementTicks=200 和 clientTicks≥280。顺序为关闭特效移动、旧/新移动第一轮、旧/新移动第二轮、旧/新站立，共七阶段；站立两阶段检查测量期位移为 0。统一起点减少原 QA 在阶段转换时改变 noiseBase 与初始烟分布的混杂因素，实际移动和帧数仍以原始记录为准。

GPU timestamp query 只异步读取已就绪结果，无 glFinish 或阻塞 query 等待。vfxGpuMs 是该测试中复制、体积/缓存、Bloom 和合成的特效 GPU 区间；frameGpuMs 是测试插桩包围的渲染区间，frameSubmitCpuMs 是对应 CPU 提交区间，frameIntervalMs 是渲染回调间隔。各指标有独立样本数，不能把阶段 P95 相加，也不能把这些毫秒或其倒数冒充用户整游戏 FPS。生产运行不开启这批测试计时。

本次清理后重跑同时修正 CPU 记录窗口：emitterTickCpuMs 和 vfxSubmitCpuMs 都只在 PerformanceQa.recording=true 时采样，与 GPU 使用同一个测量窗口，排除前 80 tick 暖机。模拟 CPU 按 client tick 记录，提交 CPU 按实际渲染帧记录；计数各自独立，不能按样本数量或 GPU 的变化推导 CPU 整体加速。旧 854p 的 CPU 记录包含暖机，不能和本次 200 tick 测量口径直接比较。

近距测试用墙使背后相机压到眼位约 0.714m，属于刻意制造的高重叠压力场景；正常背后相机约 4m。新协议站立阶段的玩家位置固定，气团和时间仍继续模拟；测量期位移为 0 才称站立。其他运行中的应用可能争用 GPU，采样帧数也并非逐帧相同。

旧 854×480 两组是 50 tick 暖机、200 tick 测量的历史试验，未记录各阶段统一起点确认；停止后的累计移动还包含阶段转换。其原值用于说明排查过程，不作为最终同一起点、等画质裁剪的定量验收。

源码：[MotionQa.java](forge/src/main/java/dev/energyvfx/MotionQa.java)、[PerfTrace.java](forge/src/main/java/dev/energyvfx/PerfTrace.java)。
