# 幽气内部翻卷：两种可直接接入现有体积场的方法

日期：2026-10-02。本文件是只读研究后的原创数学与 GLSL 建议，尚未改入编辑器或游戏。当前目标先达到参考图中的透明白/蓝卷烟外观；包装、ASTRA 启动与继续部署暂缓。

关键是分开“云团占据哪里”和“云团里面的烟纱如何流动”。32 个气团继续提供出生、离体运动、生命周期和空间包络；微观速度场只反向追踪材质坐标。包络使用原始三维点，薄纱与侵蚀使用追踪后的坐标。应去掉 auraField 中统一的 `p.xz = rot * p.xz`，否则不同细节共享同一转轴，看起来像整个云团旋转。

## 一手依据与许可

- [Bridson、Hourihan、Nordenstam 2007 原论文](https://www.cs.ubc.ca/~rbridson/docs/bridson-siggraph2007-curlnoise.pdf)：三维向量势的 curl、不同尺度势的叠加、在势而非速度上调制振幅，以及局部涡旋势。作者的 [源码页面](https://www.cs.ubc.ca/~rbridson/) 明确提供 public-domain example code。
- 已检查该例子的 `curlnoise.h`、`example_3dplume.cpp`、`main3.cpp`。三维例子确实有完整 xyz curl；main3 的中点积分没有更新中点时间，源码自身注明它对时间变化速度仅为一阶。这里的 GLSL 会同时推进中点位置和时间，不直接照抄该积分。
- [GPU Gems 3 第30章](https://developer.nvidia.com/gpugems/gpugems3/part-v-physics-simulation/chapter-30-real-time-simulation-and-rendering-3d-fluids)：烟雾的标量随三维速度平流；普通半拉格朗日插值会丢失细节，MacCormack 需要反向步骤与局部范围限制器。这里仅取回溯采样的数学思想，不复制书中的 HLSL，也不引入压力投影、体素障碍或完整流体系统。第38章的二维例子不能当成已经实现三维流体。
- 现有 [psrdnoise3.glsl](https://github.com/stegu/psrdnoise/blob/main/src/psrdnoise3.glsl) 提供三维解析梯度与随时间旋转的格点梯度，MIT，作者 Stefan Gustavson / Ian McEwan 的全文许可已在 noise.glsl 保留。以下组合与格点涡旋 GLSL 为本次原创建议；若采用仍保留噪声的原许可。

## 方法一：局部 curl 速度 + 有界反向平流

### 三维速度

一般形式 `v = ∇×A` 天然满足 `∇·v=0`。最完整的向量势有三个独立噪声，但当前 raymarch 成本较高，先用 `A=(a N₁/f, a N₂/f, 0)`：

```text
v = a (-g₂.z, g₁.z, g₂.x - g₁.y)
g₁ = ∇P N₁(P,t), g₂ = ∇P N₂(P,t), P=f x
```

虽然向量势只有两个非零分量，速度仍有 xyz 三个分量、且随三维位置变化；这是三维场，不是二维速度贴图。除以 f 的势幅度抵消噪声坐标缩放带来的梯度倍数，便于把 a 解释为速度幅度。不同位置得到不同局部剪切与卷曲，不能用一个旋转矩阵代替。

```glsl
// Original proposal. x is in stable instance-relative world metres.
vec3 localCurl(vec3 x, float seconds) {
    const float frequency = 2.0; // inverse metres; change vortex size
    const float gain = 0.06;     // velocity amplitude, not a unit direction
    vec3 g1, g2;
    float ignored1 = psrdnoise(x * frequency + vec3(13.7, 5.1, 37.3),
                              vec3(0), seconds * 0.23, g1);
    float ignored2 = psrdnoise(x * frequency + vec3(41.1, 19.7, 8.3),
                              vec3(0), -seconds * 0.17, g2);
    return gain * vec3(-g2.z, g1.z, g2.x - g1.y);
}

vec3 traceBack(vec3 x, float seconds, float span) {
    vec3 v0 = localCurl(x, seconds);
    vec3 mid = x - 0.5 * span * v0;
    return x - span * localCurl(mid, seconds - 0.5 * span);
}
```

两个噪声应使用不同固定种子偏移和不同时间速率，避免同步转动。不要 `normalize(localCurl(...))`：这样会消除有快有慢的区域，也会破坏无散恒等式。可以归一化一个局部涡旋的轴；不能随意归一化整个速度场。不要随意把速度乘以空间振幅遮罩后仍称无散；需要局部调制时应对 A 调制，再求 curl。

### 如何进入现有薄纱函数

1. 在 `point + noiseOrigin` 形成稳定的世界材质坐标，保持双精度原点策略；不要每帧把噪声原点重新锁到玩家或相机。
2. 用原始 point 求 32 气团支持度、寿命与吸收包络。
3. 用 `q=traceBack(x, clockTime, h)` 求薄纱噪声与侵蚀。先试 h=0.25–0.4 秒、低时间演化率。改变 curl 频率控制卷大小；改变 gain 控制局部翻卷速度。
4. 保留原来的低频层、梯度归一化等值面和烟雾/烟纱混合。让密度随 q 移动；不要只改变颜色或 Bloom。

固定短窗口是一种连续的局部材质变形近似，尚未存储真正历史密度。它可以先检验内部非刚性翻卷是否接近参考图，不应宣称成为不可压缩烟雾求解器。

如果短窗口仍显得像原地抖动，可增加“两相有界回溯”：`a₀=fract(t/T)`、`a₁=fract(t/T+0.5)`，分别回溯 `aᵢT` 秒并采样初始薄纱，权重 `w₀=sin²(πa₀)`、`w₁=1-w₀`。回溯相位重置时对应权重及其一阶导数都为零，避免硬跳；在密度上加权，不在两个噪声标量间直接插值。T 可先取 1–1.5 秒。长回溯需要拆成小步，并会增加每个积分采样点的成本，不能直接用无限增长的 `q=x-t*v`。

### 成本与厚度

一次两势速度需要 2 个 psrdnoise；一次中点回溯需要 4 个，尚未计薄纱与侵蚀。两相和多步会继续增加成本，因此先在现有低分辨率目标和 48–64 步上验证，再决定是否加细节层。

回溯单步以 `h U / L ≲ 0.25` 作为保守起点，U 为观察到的速度峰值、L 为局部涡尺寸。过强变形会把等值面压薄到采样步长以下，表现成闪烁或断层。严格的最终厚度应使用 `∇x S = Jqᵀ f ∇N`；只用噪声返回梯度会忽略回溯变形的 Jacobian。短窗口、低强度时可先使用原近似，强翻卷时需补该梯度修正或明确厚度只是艺术参数。

## 方法二：八个邻域涡旋势，减少噪声调用

这是基于论文局部涡旋势的一种原创紧支撑构造。每个格点有独立的方向轴、转速符号、时间相位；每个采样点最多求所在网格单元的八个角点。涡旋半径 R 取网格间距 L，超过半径的项严格为零；换网格单元时消失的远角点已为零，避免邻域切换接缝。

定义 `r=x-cᵢ`、`s=|r|²/R²`、`k=max(1-s,0)`，向量势与速度为：

```text
Aᵢ(x,t) = ωᵢ(t) R²/8 · k⁴ · axisᵢ(t)
vᵢ(x,t) = ∇×Aᵢ = ωᵢ(t) k³ · (axisᵢ(t) × r)
v = Σ vᵢ
```

axisᵢ 与 ωᵢ 对同一格点只依赖种子和时间，不依赖采样位置，所以各项仍是 curl；k 的多项式使边界速度和低阶导数平滑消失。多个随机轴的局部滚动不共享整体 y 轴。这里只计算解析速度，没有网格压力、流体碰撞或巨大的缓存。

```glsl
// Uses the existing original hash3(vec3) from field.glsl.
vec3 nodeAxis(vec3 id, float seconds) {
    vec3 base = vec3(hash3(id + 11.1), hash3(id + 39.7),
                     hash3(id + 73.2)) * 2.0 - 1.0;
    float phase = hash3(id + 5.4) * 6.2831853;
    vec3 drift = 0.18 * vec3(sin(seconds * 0.27 + phase),
                            sin(seconds * 0.19 + phase * 1.7),
                            cos(seconds * 0.23 + phase * 0.8));
    return normalize(base + drift + vec3(0.0001));
}

vec3 vortexVelocity(vec3 x, float seconds) {
    const float L = 0.45;   // world metres; radius also L
    const float spin = 2.0; // radians/second amplitude
    vec3 cell = floor(x / L), velocity = vec3(0);
    for (int i = 0; i < 8; ++i) {
        vec3 offset = vec3(float(i & 1), float((i >> 1) & 1),
                           float((i >> 2) & 1));
        vec3 id = cell + offset, r = x - id * L;
        float k = max(1.0 - dot(r, r) / (L * L), 0.0);
        float phase = hash3(id + 23.5) * 6.2831853;
        float signSpin = hash3(id + 91.8) < 0.5 ? -1.0 : 1.0;
        float omega = spin * signSpin * (0.65 + 0.35 * sin(seconds * 0.43 + phase));
        velocity += omega * (k * k * k) * cross(nodeAxis(id, seconds), r);
    }
    return velocity;
}
```

将方法一中 localCurl 换成 vortexVelocity，保留中点时间回溯即可。先试 L=0.35–0.55 米、spin=1–3 rad/s、h=0.25–0.4 秒。大卷和小卷确有需要时再叠加一个较弱、约一半 L 的层；不要立即给每个采样点堆许多层。该场不增加 psrdnoise 次数，但八个格点的 hash、sin/cos 和 cross 仍有成本。

作为第一轮外观试验，我更建议先试此方法：局部轴和相位可以清楚打破整团旋转，同时比反复计算解析噪声梯度容易控制成本。随后若规则网格节奏可见，再换方法一或做两层弱叠加。

## 验收应看什么

固定相机、固定气团中心/外包络，只让内部时间推进：烟纱中不同小区域应有不同方向和速度，卷边应挤压、展开和断裂；整体轮廓不能仅绕一个轴旋转。再打开正常发射，确认离体移动与内部微流叠加。

观察同一份薄烟在 0、0.25、0.5、1 秒的局部特征连续性与绕视形状；同时检查细层闪烁、相位重置接缝、包络边界、GL 错误和帧时成本。只有颜色/Bloom 改变、朝相机平面贴图变形或二维染色流动，均不能证明三维内部翻卷完成。此文仅给出候选方法，最终是否达到参考图须由实现与视觉检查确认。
