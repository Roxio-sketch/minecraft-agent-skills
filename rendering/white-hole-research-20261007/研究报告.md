# 白洞特效研究与扩展方案

整理日期：2026-10-07。目标平台沿用当前 Forge 1.20.1 / 47.4.10 / Java 17。此次交付是资料核查、现有源码审读与研发方案，尚未制作白洞 shader、修改 skill/MOD 或进行白洞游戏验收。

## 推荐方向

建议在现有黑洞 skill 内增加独立的白洞行为分支，首版先做 **白／蓝白核心＋水平外流环盘＋内侧出生、螺旋外散的粒子**，保留原有固定世界中心、360° 环境透镜和玩家参与开关。随后再扩展双极喷发和一次性释放。先把向外运动做清楚，再增加烟纱、冲击壳与 Bloom。

白洞不应仅是“黑洞调成白色”。现有源码虽已允许核心染色并提供双极喷流，但盘纹、粒子的出生与死亡以及喷流输运仍需要新消费者。首版优先复用这些已有模块，避免一开始引入完整流体求解器或重写相对论光学。

## 物理概念与美术定义

经典白洞可理解为黑洞时空的时间反演分支；这里的物质外流不意味着引力变成负质量排斥。同质量、相应外部区域的 Schwarzschild 光学不能因为名称变成“白洞”而机械反号。因此，默认保留正质量透镜；若以后想要向外推开的空间扭曲，应另标为幻想效果。

目前没有被观测确认的标准白洞外观。亮白核心、外流盘、喷流、冲击壳是为游戏识别度设计的美术选择，不是理论白洞必定具有的结构。NASA／ESA 的黑洞喷流、星云和类星体图像可学习亮度层次、喷口、结点与长短轴构图，但不能当作“白洞照片”。量子反弹／黑转白论文也应视为理论模型，而非自然界已确认的事件。

核查依据和阅读边界见 [物理与视觉来源](physics-notes.md)；公开原文入口、访问记录和署名信息保存在 `physics-visual-sources.json`。

## 三条可以发展的路线

| 路线 | 画面识别点 | 主要新增工作 | 相对工程成本 | 建议顺序 |
|---|---|---|---|---|
| B：环形外流 | 白核、薄水平环盘；亮纹和颗粒从内向外扩散，外缘逐渐消失 | 每种盘的外流相位；内侧粒子发射、外域淡出；白核独立亮度 | 低至中，主要复用现有层 | 首版 |
| A：持续双极喷发 | 蓝白核、两个极向喷口；明亮结点沿轴向外移动，外鞘较稀薄 | 独立轴向输运、喷流脉冲、喷口粒子；可选稀薄体积外鞘 | 中至高，长喷流增加覆盖与积分成本 | 第二阶段 |
| C：蓄能后释放 | 小白核增强，释放三维膨胀壳和外散碎光，再留下余辉 | 明确事件 age、发射预算、壳半径／厚度曲线及结束语义 | 中至高，峰值与近镜头观察需专测 | 第三阶段 |

这些成本是结构上的相对判断，没有白洞 GPU 时间或帧率测量。三条路线可以共享外流粒子核、固定中心和配色；它们应有各自的时序与消费者，不能只换预设名字。

## 关键算法选择

### 1. 把发射与外流生命周期重做

现有黑洞粒子在外侧出生并向内缩半径；简单给时间或速度乘 −1，会连同出生、重生和核心淡出一起倒放。白洞应在内缘／喷口出生，向外积分，在外域与寿命结束前渐隐。

现有轨迹的可读改造是令 `q=r^(3/2)` 从 `q0` 增到 `q1`；半径 `r=q^(2/3)`。若角速度沿轨迹为 `k/q`，须积分得到转角，而不是使用 `time*omega(currentRadius)`。保留 seed、固定 ID、暂停与可复现时间；速度为零、内外半径相等、重生帧均有明确分支。这是美术外流轨迹，不是物质或流体守恒模拟。

### 2. 分开旋转、盘纹外流和喷流输运

每种盘结构分别检查径向相位，向外流通常从 `r+phase` 改为 `r−phase`，同时保持周期与接缝连续。轴向喷流用沿高度外移的结构坐标，两个极都以距喷口的正距离定义 outward；不能只让细丝旋转。盘纹输运和实际粒子位移必须各自能单独开关验证。

### 3. curl／flow noise 只负责扰动，不代替发射源

推荐阅读 psrdnoise 的旋转梯度与解析导数，以及 Bridson 的势函数旋度。径向外流负责净流出，curl 负责卷动、弯曲和小尺度扰动。叠加径向外流后，整体速度场不应继续称为无散；密度补给与消散也需明确源汇。首版不需要独立三维 Navier–Stokes 网格。

### 4. 保留体积积分与遮挡的物理单位

烟纱／喷流需按段长计算消光与发射，不能每步固定加亮。若使用独立发射系数，应在零消光极限仍能以 `emission*ds` 积分。前景盘、核心、后景与外部体积的合成责任要明确。

现有主核在透镜路径上采用特殊深度策略，不能自动作为新外喷雾的墙体遮挡证据。首版 sprite 可以复用已有深度测试；后续体积独立按可见场景深度截断，或另外实现弯曲光路与源深度的一致遮挡。

### 5. 白色核心与彩色层次分别控制

中心可以接近白，边缘、盘、喷流与外散粒子应保留冷暖色和明暗。增加发光不能把全部层冲成平白圆球；参考上轮闪电高增益截白的经验，提供分层实际材质色卡，把颜色、发射、曝光和 Bloom 分开。Bloom 是软扩散增强层，关闭后白洞主体仍应成立；它不自动照亮地形。

公开算法、源码文件、固定提交、许可与 Forge 迁移意见见 [技术资料审读](technical-notes.md) 和 `technical-sources.json`。下载的文本证据只用于复核，不代表已经移植或运行这些项目。

## 建议的配方与 UI 组织

以下只是一份字段设计草案，尚未成为可导入配方。

- **天体／行为**：黑洞／白洞，持续／释放；旧配方缺省仍为黑洞。
- **核心颜色与发光**：核心源色、边缘色、核心发射；不要把全局曝光当成核心亮度。
- **外流环盘**：旋转速度与径向外流速度分开，配合内外缘和外缘淡出。
- **粒子发射**：喷口／环盘／球面、出生半径、外域、寿命、外流与切向速度；数量有独立预算。
- **喷流**：长度、宽度、轴向流速、结点密度、两极时序；这些消费者仅在喷流路线可见。
- **释放事件**：蓄能、释放、扩张、余辉时序及壳厚；持续态不展示无效事件参数。
- **光学与后处理**：原质量透镜、玩家开关、局部 halo、可选 Bloom。幻想反向扭曲另行标明。

延续现有 UI 的作用层说明、实际颜色预览、条件可见分组和 F6 位置记忆。配方先校验完整临时对象再应用；颜色／发光的热更新不重新定位、不换 seed、不重启事件。流动方向、发射域和事件模式需要区分拓扑更新与外观更新，并保持新旧格式往返有明确规则。

## 分阶段研发与验收

1. **环盘原型**：固定 seed/time，先关闭 halo/Bloom，验证盘纹和同 ID 粒子确实向外；随后恢复白核、局部 halo 与原透镜。保存侧视、俯视、垂直和绕行对照。
2. **喷发扩展**：验证结点从两极根部往外移动，外鞘被墙挡住，观察者进入喷流后没有近裁剪爆亮。粒子和体积分别开关测差分。
3. **释放扩展**：固定 tick 驱动蓄能、壳扩张与余辉，停止后无残留；从多个帧率／时刻重放同 seed，不能仅凭一张截图判定成功。
4. **宿主回归**：地面固定中心、第一／第三人称穿域、玩家影响开关、360° 透镜、云层、resize、F3+T、stencil、停止、世界切换和旧黑洞配方全部复查。
5. **性能记录**：按屏幕覆盖、步数、同屏实例和粒子数记录 GPU／CPU 时间。长喷流与相机入域是高成本场景；首版沿用有限域和现有容量，再依据测量决定降分辨率、跳空或 LOD。

可先复用历史黑洞和闪电的固定时间夹具，但历史结果不能为新增白洞发射、体积、Bloom、同步或其他光影管线直接背书。
