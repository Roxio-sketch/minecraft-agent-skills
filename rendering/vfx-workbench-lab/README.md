# 特效调试工作台：闪电接入、水波修正与中文界面

适用 Minecraft 1.20.1 / Forge 47.4.10 / Java 17。工程目录即本文件所在目录。

## 使用

执行 `./run-workbench.ps1` 启动开发客户端，进入世界后按 F6。
F7 触发工作台上次选中的特效，F8 停止该特效；三个按键均可在“控制 → 按键设置 → 特效调试工作台”改绑。聊天、背包与菜单中不触发快捷操作。
左侧选择“水波涟漪”或“闪电与电流”，点击“显示 / 触发”。参数滑块修改当前全局状态；界面不会暂停世界。

- 水波：即时修改颜色、透明度、法线、高光、传播和衰减。网格、求解器和边界修改后点“重建 / 扰动”，重建会清空旧波场。`/waterripple rain` 切换连续雨滴。
- 闪电：模式可选环绕电流、单道落雷、多道落雷；布局可选散布和集束。共 23 个参数。几何参数修改在下一客户端 tick 重采样当前仍存活的事件，保留时间；颜色和亮度修改不重新生成拓扑。已经结束的落雷需要再次点击触发。
- “停止效果”仅停止当前选中的类型。
- 保存、读取预设使用 `config/vfxworkbench/presets/<skill>/last.json`。导出复制当前参数 JSON 到剪贴板。
- `/lightninglab orbit|strike|rain|random-strike|random-rain|off` 保留。`reload` 使用工作台当前状态重新触发，不再读取旧 `config/lightninglab/recipe.json`。

## 变更

复用闪电 Skill 的 OrbitField、BoltGeometry、RainGeometry、ImpactGeometry、LightningEnvelope、RibbonGeometry 和 bolt shader；保留固定 seed、固定 tick、射线落点与事件尾段寿命。没有重新设计闪电算法。

水波扰动现在明确以格为位置和半径单位，再换算到网格。修正雨滴位置多乘一次水面宽度的问题。法线与高度在每帧按网格节点计算一次并复用，避免每个共享顶点在四个面上重复求解；缓存仅在分辨率变化时分配。高光方向和程序天空反射使用一致的坐标空间。

中文界面包含特效名称、参数名称、分组、生效分类、枚举选项、按钮、颜色通道和主要操作消息。拾色器返回原来的特效页；控件宽度随窗口调整，屏外行不会接受点击；保留小数步长精度。

## 验证

`gradlew.bat build workbenchCheck lightningCheck --offline --console plain`

水波检查覆盖传播、对称性、运行中速度修改、限幅、网格重建与以格为单位的中心扰动。闪电检查覆盖工作台状态到原配方的桥接、确定性 seed、固定根部、延伸速度、Ribbon 连接、集束预算、击地时序和完整尾段。

编译与上述数值回归通过。开发客户端可加载两个 Schema，最新版客户端于 10:00:45 确认水波与闪电着色器均编译/加载成功，结果见 validation-result.json。尚无本轮世界内拖动参数的截图、人工视觉验收或性能测量；节点计算复用不代表已测得具体 FPS 提升。

## 边界

当前仍是全局参数、单个演示事件/水面。Selected Effect Instance 尚未实现；纹理、向量和曲线编辑器及关闭调试 UI 的生产构建尚未实现。
水面仍是独立高度场补片；天空反射是程序颜色近似，不是场景反射或折射。闪电不造成伤害或方块修改，击地电弧使用水平局部平面，火花没有碰撞。Oculus、Embeddium、Fabulous 和其它渲染器组合尚未在本轮验证。
闪电配方桥接保留默认的未暴露字段；导出的参数子集可通过 LightningRecipe/统一 ParamState 接入正式 Renderer。第三方噪声许可见 LIGHTNING_THIRD_PARTY_NOTICES.md。

## 黑洞与吸积盘

在世界中按 F6，选择“黑洞与吸积盘”，点击“显示 / 触发”，黑洞放在视线前方（默认 14 格）。形态预设可切换金色薄盘、冰蓝正面盘、紫色厚盘、暗核透镜、赤红漩涡；切换立即作用于当前黑洞，无需重新放置。形态会重置形状、配色和运动为该预设值，保留世界尺寸与放置距离，然后可继续自由调参。

31 个参数覆盖世界尺寸、距离、核心半径、盘内外半径、厚度、倾角、偏折、密度、曝光、核心/盘/粒子配色、差速旋转、径向内流、种子、背景透镜、粒子数量/尺寸/速度/亮度、三层光晕和 96/160/256 采样档位。盘内半径实际至少为核心半径 + .12，盘外半径至少为内半径 + .5，避免拖动产生退化盘。

`/blackhole world` 放置，`/blackhole form gold|ice|violet|lens|crimson` 切换，`/blackhole off` 关闭。距离在下次放置时生效；粒子数量变更会在下一次绘制重建粒子 VBO，其余视觉 uniform 每帧读取。没有加入物品材质路径，当前展示的是世界黑洞。

`./run-workbench.ps1 -BlackHoleDemo` 创建/打开独立存档 `VFX-BlackHole-Workbench-Demo`，在这个展示存档内建立棋盘背景与固定观察点，自动依次采集五种形态，结束后保留世界供调参。该开关默认关闭，不会进入或修改其它存档；它会重置展示存档内的观察点和测试背景。普通启动后也可在任意世界使用上述 UI 或命令。

复用 Skill 原有有限体积射线内核、颗粒盘、场景颜色/深度副本、粒子遮挡和状态恢复。网页 v3.2 的 layer/ribbon/cinematic 等新增独有形态没有迁移；这里的五种形态是 Forge 内核的可编辑组合预设。依然不支持 Oculus/Fabulous 的替代 framebuffer adapter、多个黑洞相互作用或服务端伤害/吸取。

黑洞本轮实际世界验收：独立展示存档、Forge 47.4.10、RTX 4060 Ti，五种形态均生成原生 before/field/after framebuffer 截图和指标 JSON，位于 `run/black-hole-lab/world-probes/`。同一中心与相机连续切换当前 ParamState，均有非零像素变化，效果范围外变化 0，深度变化 0，GL error 0；四种粒子形态均有独立粒子贡献，暗核透镜的粒子贡献为 0。截图已逐张检查形态差异。测试没有前景遮挡物，未声称本轮验证前景遮挡；切换由开发验收入口驱动，未声称进行了人工鼠标拖动验收。汇总见 validation-result.json。

启动命令：`./run-workbench.ps1 -BlackHoleDemo`。普通世界操作：F6 → 黑洞与吸积盘 → 显示 / 触发 → 形态预设。已有黑洞切换形态时保持中心；只有再次显示 / 触发才按当前视线重新放置。

## 用户配方作为默认值（2026-10-04）

`src/main/resources/assets/vfxworkbench/recipes/black-hole-default.json` 是用户 `Downloads/black-hole-recipe.json` 的完整原样副本。注册 Schema 从此文件读取支持字段的默认值；新启动时默认形态为“导入配方”，恢复默认也回到该配方。原五种形态保留旧基础参数，切换到“导入配方”则恢复用户配方；不会把新默认值混入金色薄盘等旧形态。

盘外半径上限扩大到 8，核心 .2、盘内半径 1.35、盘外半径 8、偏折 2、密度 2、旋转 1.3、内流 .93、种子 35562、曝光 .49、采样 256。原配方倾角为 -51；2026-10-05 按用户最新要求，默认及内置预设改为 0 度（水平）。粒子默认关闭、数量为 0。新增动画时间与播放开关：按配方暂停在 1071.9779999996465 秒，启动播放时从暂停位置继续。preview viewDistance=16.61 是局部单位，因此默认世界尺寸 1.6 下放置距离为 26.576 格；yaw/pitch 只描述网页观察相机，不改玩家视角。

具体映射和不支持的字段见 default-recipe-mapping.json。中间盘色、核心边缘渐变、独立光晕颜色/渐变、颗粒外观扩展、Bloom 和星云背景等浏览器字段尚未迁移，完整保留于原配方，不把它们标为生效。世界后台继续使用真实场景颜色，不能完全复现网页图像。

本轮构建和默认值/暂停恢复检查通过，尚未重新做用户配方的游戏画面验收。之前五种形态的运行时证据另存 validation-before-default-recipe.json，避免误用于证明这份新配方。正在运行的客户端需要重启加载新 Java/JAR；随后 F6 → 黑洞与吸积盘 → 导入配方或恢复默认。

## 模式分类与 F6 记忆

统一 ParamSpec 增加 visibleWhen 条件，界面只绘制当前可见参数，并按分组合并显示；没有可见参数的组不占空标题。隐藏参数保留当前值，可切换回来继续调整。

闪电：模式、种子、颜色和核心/光晕亮度及光晕宽度为通用项。环绕电流只显示电弧数量、采样、附着杆、抖动、噪声流速、动画和电流宽度等环绕项；短段脉冲 spektr 隐藏不生效的延伸速度。单道落雷显示高度、雷柱宽度和分叉概率；多道落雷另外显示布局、数量、横纵范围和击地半径。模式切换自动回到参数顶部，并终止旧滑块拖动，隐藏行不参与绘制、滚动高度或点击。

F6 记忆上次选择的特效，使用 `config/vfxworkbench/ui.json` 保存 selectedSkill，跨关闭界面和重启客户端保留。当前客户端会话内还分别记忆各项目的参数滚动位置、折叠组与项目栏横向浏览位置，F6 关闭后再打开精确恢复。调整窗口尺寸或切换项目时保证选中项目可见。若特效已经不存在，自动回到第一个已注册特效。拾色器仍返回原页面。

顶部项目入口采用单行自绘横向项目栏，按标题安排宽度，支持滚轮、拖动和左右浏览箭头；左右键、Home/End 与 Ctrl+Tab 可切换项目。新增项目不再挤压参数区。

上述 UI 已构建并包含在交付 JAR。2026-10-05 的自绘控件、即时标签对齐、布局和完整闪电配方导入验收见 `evidence/workbench-ui-20261005` 与 `evidence/lightning-skill-reimport-20261005`。

## 宽闪电光晕与固定黑洞相机（2026-10-05）

闪电光晕使用独立凸段和圆接头，在每条路径的临时深度缓冲中取最大覆盖，再把这条路径相加到场景，避免宽光带在短折线接头处反折成尖长三角片，同时避免接头重复相加导致过亮。不同路径仍相加。原颜色、亮度、物理宽度、核心路径和用户完整默认配方保留。

黑洞射线使用实际地形 view/projection 的光学眼点，包含 Minecraft 行走晃动中的投影平移；同帧锁定相机矩阵和 partial tick。黑洞、世界透镜和粒子遮挡使用一致眼点，中心仍固定在放置时的世界坐标。场景副本匹配 Forge stencil 深度附件并恢复渲染状态。

证据与限制见 `evidence/camera-glow-fix-20261005/README.md`。宽光晕已进行 15 组同配方实机前后对照，固定黑洞已进行 50 帧运动轮廓验收；开发验收入口默认关闭，只使用独立存档。

## 渐变比例、玩家透镜开关与水平预设

闪电“沿程渐变”组提供“起始色占比（%）”，启用沿程渐变时可见。0% 为全终止色，100% 为全起始色，比例越高起始色覆盖越多；50% 精确保留旧材质插值。参数 `gradientRatio` 支持即时调整、导入、导出和保存。原 60 字段 JSON 保持原样，缺此字段时使用 50%。

2026-10-06 新增 `gradientTarget=both/core/glow` 与 `gradientCoreMode=vivid/additive`，完整导出为 63 字段，旧 60/61 字段补齐 both/vivid 默认值。主雷与分叉共用渐变，选中层仍分别乘核心或光晕基础色。默认核心“保留色相”以 alpha 混合避免高增益把中段冲白，亮度增加覆盖；“传统叠加”保留旧加法外观。关闭渐变或仅对光晕渐变时，核心继续传统显示。核心、光晕各有起点/中点/终点实际材质色卡，色卡不包含增益、场景叠加和覆盖变化。运行中颜色、增益、比例和作用层变化保留树、锚点与时间，并同步所有群雷子通道；短时事件已结束后需重新触发。新实机、界面、网页与 JAR 证据见 `evidence/gradient-clarity-20261006`，此前低增益比例测试不用于证明本轮主雷显色修复。

黑洞“光与材质”组新增“透镜影响玩家”，默认关闭。关闭时保护玩家模型；开启时玩家参与透镜扭曲及核心遮盖，不再受前后位置或跨质量平面的保护限制。参数 `lensAffectsPlayer` 支持配方和预设保存，切换形态保留该选项；旧配方缺字段时恢复关闭。本次 28 帧开关对照见 `evidence/horizontal-presets-20261005/player-toggle`。

朝方块表面预览时，使用视线碰撞命中点，沿表面法线抬起核心半径加 0.05 格，避免核心埋入地面；放置后中心固定在世界坐标。未命中时沿用预览距离。六视点实际黑核心轮廓与独立球体投影验证见 `evidence/horizontal-presets-20261005/ground`。

渐变落雷的地面电弧、环、火花与闪光统一继承主闪电实际终点色，保持各自亮度和底色乘法；渐变比例为 100% 时继承起始色，关闭渐变时继承普通配色。

默认和全部 11 个内置形态的吸积盘倾角为 0°，盘面水平、平行地面。可手动调到 -90° 至 90°；真实导入的 JSON 显式角度继续生效。渐变五档实机像素验收见 `evidence/gradient-ratio-20261005`，玩家开关 28 帧对照见 `evidence/player-lens-toggle-20261005`，此前垂直预设的历史画面保留于 `evidence/vertical-presets-20261005`，不用于证明本次水平修正。新增控件通过实际界面输入及截图检查，见 `evidence/workbench-features-20261005`。
