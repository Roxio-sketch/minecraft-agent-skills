# 异火缠绕参数编辑台

当前默认是蓝白灵火：两条绕身火流，内部细亮火核、卷曲的透明外焰，以及持续脱离身体的灵火和余烬。主火与离体灵火都使用三维密度积分，转动视角会改变内部遮挡和厚度。画质版默认512步，可调到512步。

双击桌面的 `启动异火缠绕工作台.py`，或在 `启动全部工作台.py` 中选择“异火缠绕”。此入口启动参数编辑器。临时固定服务地址为 http://127.0.0.1:8819/；桌面启动器会自动使用空闲端口。

拖动预览旋转视角，滚轮拉近。先观察蓝白起点，再调整火流宽度、侵蚀留空、火舌扰动及流速。三个颜色分别控制火核、中层和外缘；“体积采样精度”只改变积分精度。观察分层、移动演示及相机仅用于预览，不进入配方。

“保存当前配方”写入本项目 `current-recipe.json`；“应用到 ASTRA-TEST”提交固定的游戏配置并等待相同nonce确认。尚未进入世界时只表示参数已读取，实际播放以游戏状态为准。游戏侧命令：`/firecoil start`、`/firecoil off`、`/firecoil reload`、`/firecoil status`。

人体是预览代理。Forge后端绑定本地玩家实际位置和身体朝向；离体粒子在世界坐标中固定20Hz推进，移动后旧粒子留在原世界。武器版从最终 ItemRenderer 持握矩阵取附着坐标，保留左右手、第一与第三人称以及自定义渲染内层的变换；原版剑的透明像素不计入范围，项目武器可直接消费真实挂点。没有伤害或服务器同步。

这是程序化三维火场，不是流体求解器。512是离体模拟容量；体积通道每帧最多绘制24个灵火，默认约11个。小余烬使用微小粒子。当前阶段按用户要求优先完成画面，未宣称解决全屏性能。

共用密度和颜色函数在 `fire.volume.core.glsl`。`build_shared.py`生成浏览器资源，Forge构建原样嵌入并记录SHA。精确36字段配方（完整v1严格升级到v2）、范围和渲染约定见 `CONTRACT.md`，真实网页及独立Minecraft验收文件在 `evidence` 与 `forge/evidence`。

当前运行库0.2.0、配方fire-coil/2。工具栏提供身体、武器、两者；九火颜色与炼丹炉共用。直达武器预览：http://127.0.0.1:8819/?view=weapon 。新增 attachment=0/1/2、weaponRadius/Width/Turns/Strength。武器近景精修依据、真实验收及边界见 evidence/WEAPON_REFINEMENT.md。

已构建的0.2.0生产包未替换ASTRA-TEST中的旧运行库；旧库不接受武器v2，编辑器会禁用应用按钮。当前优先检查画面。网页武器/人体是代理，武器离体火舌为网页演示；游戏武器当前为连续附着体积。任意自定义骨骼适配与七把宿主剑的分别验收仍需实机目标。
